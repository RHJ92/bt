# 📋 [작업가이드] 구매팀 매거진 작성법

> 🧭 이 페이지는 점주님께 매주 나가는 **옥된장 매거진**에 구매팀이 상품 이야기를 쓸 때, 대표님 글과 **서식·이모지·표·말투의 결**이 맞도록 잡아둔 작업 기준서입니다.
> 글은 노션 **「매거진 양식」 DB**에 쓰고, 쓰기 전·쓰는 중에 이 문서를 펼쳐 두세요.

## 0. 노션 서식의 원칙

노션은 글자 크기·폰트를 자유롭게 정하는 도구가 아니라 **블록(제목·본문·콜아웃·표·구분선)** 으로 위계가 정해집니다. 대표님 글도 아래 블록만으로 돼 있으니, 새 폰트·색·크기를 쓰지 말고 이 블록만 쓰면 결이 자동으로 맞습니다.

| 역할 | 노션 블록 | 입력 / 단축키 |
|---|---|---|
| 글 대제목 | 제목1 (H1) | `# ` 입력 후 띄어쓰기 |
| 섹션 제목 | 제목2 (H2) | `## ` 입력 후 띄어쓰기 |
| 도입·마무리 강조 박스 | 콜아웃 | `/콜아웃` |
| 요약 표 | 표 | `/표` |
| 구역 나누기 | 구분선 | `---` 입력 |
| 강조 | 굵게 | 글자 선택 후 Ctrl+B |
| 속마음·인용 | 기울임 | 글자 선택 후 Ctrl+I |

---

## 1. 글의 골격 (대표님 글 공통 구조)

대표님 글 네 편이 모두 같은 순서를 따릅니다. 구매팀 글도 이 순서를 지킵니다.

1. **(선택) H1 제목** — `대표 이야기` 자리에 구매팀은 → **`구매팀 이야기`**
2. **도입 콜아웃** — 주제 이모지 + 2문단
3. **`## 📋 한눈에 보는 이야기`** + 요약 표
4. **구분선 `---`**
5. **본문 섹션** `## 1️⃣ …` ~ `## 6️⃣ …` (표 항목과 1:1 대응)
6. **구분선 `---`**
7. **마무리 콜아웃 💬** — 점주님께 드리는 당부 한마디

---

## 2. 이모지 사용 규칙

대표님은 이모지를 **장식이 아니라 길잡이**로, 정해진 자리에만 씁니다.

- **도입 콜아웃 아이콘** — 글의 상품/주제를 상징하는 이모지 1개
- **요약 표 제목** — 항상 `## 📋 한눈에 보는 이야기`
- **본문 섹션 번호** — `1️⃣ 2️⃣ 3️⃣ 4️⃣ 5️⃣ 6️⃣` 키캡 숫자로 통일 (H2 제목 맨 앞)
- **마무리 콜아웃** — 항상 `💬`
- 본문 문장 안에는 이모지를 거의 쓰지 않습니다.

> 🛒 **구매팀 추천 주제 이모지** — 원물·산지 🌾 · 가격/원가 💰 · 품질·검수 🔍 · 신선도 ❄️ · 수급/물류 🚚 · 협상 🤝 · 규격/로스 📦

---

## 3. 표 구성 규칙

- 머리행 **있음**, 2열 고정: **`구분`** \| **`핵심 내용`**
- 왼쪽 칸: `1️⃣ + 짧은 제목`(명사형, 5~10자)
- 오른쪽 칸: 항목을 **한 문장**으로 요약 (`~습니다` 마침)
- 표의 행 수 = 본문 섹션 수 (보통 5~6개)

---

## 4. 말투·문체 규칙

| 항목 | 기준 |
|---|---|
| 종결 | `~습니다 / ~합니다` 정중체 통일 (반말·음슴체 금지) |
| 1인칭 | "저는 / 저희 구매팀은" |
| 점주님 호칭 | 항상 "점주님" (사장님·여러분 혼용 금지) |
| 진솔함 | "솔직히 말씀드리면", "그대로 나누겠습니다" 같은 정직한 톤 |
| 근거 | 경험·숫자로 — "원물값이 ○○% 올라", "유통기한이 하루"처럼 구체적으로 |
| 강조 | 핵심 단어·구절만 **굵게**. 한 문단에 1~2개까지 |
| 인용 | 손님·점주님 속마음은 *"기울임 따옴표"* 로 |
| 길이 | 한 섹션 2~4문장. 짧게 끊어 읽기 편하게 |

> 🎯 **구매팀 톤 = 대표님 톤 + 근거와 투명성**
> 대표님이 *'왜 만들고 왜 접는가(결정의 이야기)'* 를 다룬다면, 구매팀은 *'무엇을·어디서·어떻게·얼마에 들여오는가(상품의 이야기)'* 를 다룹니다. 같은 정중체·솔직함을 유지하되 **산지·원가·품질·수급** 같은 구매팀만의 근거를 더하면 됩니다.

> 🤝 **'점주님 이익' 관점으로 권하기** — 구매팀이 점주님께 *판매하는* 상품을 권할 때, *"서비스로 내주세요"* 처럼 들리면 안 됩니다. 점주님은 돈을 주고 들이신 상품이기 때문입니다. 대신 **매출 보타·배달 리뷰 이벤트·단골 관리**처럼 그 상품이 점주님 매장에 어떤 득이 되는지를 활용법으로 제안해 주세요. 특히 **마무리 콜아웃**에서 이 점을 꼭 지켜야 합니다.

## 5. 복붙용 골격 템플릿

아래 박스 안을 통째로 복사해, 노션 **「매거진 양식」 DB**에 새 페이지를 만들고 대괄호 `[ ]` 안만 채우세요.

```
# 구매팀 이야기

[도입 콜아웃 — 주제 이모지로 시작 / 1문단: 점주님이 궁금해할 질문을 "기울임"으로 / 2문단: 이 글의 요지를 굵게 한 줄]

## 📋 한눈에 보는 이야기
[표: 구분 | 핵심 내용 — 1️⃣~5️⃣ 행]

---

## 1️⃣ [섹션 제목]
[본문 2~4문장. 핵심은 굵게, 속마음은 "기울임".]

## 2️⃣ [섹션 제목]
## 3️⃣ [섹션 제목]
## 4️⃣ [섹션 제목]
## 5️⃣ [섹션 제목]

---

💬 [마무리 콜아웃 — 점주님께 드리는 당부 한마디]
```

## 7. 작성 전 체크리스트

- [ ] H1 = `구매팀 이야기` 로 시작했는가
- [ ] 도입 콜아웃에 주제 이모지 + 2문단을 넣었는가
- [ ] `## 📋 한눈에 보는 이야기` 표(구분/핵심 내용)를 넣었는가
- [ ] 본문 섹션이 표 항목과 1:1로 맞고 `1️⃣~` 번호가 붙었는가
- [ ] 종결을 `~습니다` 정중체로 통일했는가
- [ ] 손님·점주님 속마음을 *"기울임 따옴표"* 로 표현했는가
- [ ] 마무리 콜아웃 `💬` 으로 점주님께 당부했는가
- [ ] 맨 아래에 🔗 매장관리시스템 링크 콜아웃(공통 푸터)를 넣었는가
- [ ] 새 폰트·색·글자크기를 임의로 쓰지 않았는가
