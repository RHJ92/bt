## 현재 상태 (2026-10-15)

- 선우프레시: 견적 수령(구두). 자사가 **내부 논의 후 회신**하기로 한 상태
- HLB: 1차 유선 문의만 완료. 내부 논의 후 이상 없으면 **샘플·견적(소포장 포함) 정식 요청**
- 결정할 것: 공급처 1곳 선정 → 그 전에 **1인분 구성(대수·중량·판매가)**을 먼저 정해야 두 업체 견적을 같은 기준으로 비교할 수 있다

## 판단 포인트 (컨택 전 내부 정리)

1. **1인분 구성 확정이 선행** — HLB도 "몇 대를 얼마에 줄지 정하고 규격을 역산하라"고 조언. 결정 전에는 두 업체 견적이 비교 불가
2. **등급 vs 식감 트레이드오프** — 선우는 초이스 파이브립이라 원가가 낮지만 **9·10번이 랜덤으로 섞여 샘플이 질겼다**. 부위 구분 유통은 불가. HLB는 6·7·8번 탑초이스라 품질 기대치는 높지만 원물이 급등 중
3. **포장 요구 정리** — 자사 실제 요구는 "냉동 상태에서 1인분씩 꺼내 쓸 수 있으면 됨, 진공 필수 아님"(10/8 정리). 선우 2대 진공은 이 요구를 충족. HLB는 간지 방식으로 낱개 분리가 되는지 확인 필요
4. **수급 안정성** — 탑초이스는 양쪽 모두 물량 부족 확인. 선우는 척갈비도 시장에 거의 없다고 함(10/8) → 오픈 일정 대비 물량 확보 가능성이 단가만큼 중요
5. **단가 유효기간** — 선우 11월 말까지. 12월 재협의 가능성 있어 첫 발주 시점과 맞물림

**선우프레시 회신 (전화/카톡)**

```
주임님, 블루트렌드 구매팀입니다.
지난번 보내주신 포갈비 견적 내부에서 검토 중인데 몇 가지 추가로 여쭤보려고 연락드렸습니다.

1. 샘플 시식해보니 식감이 조금 질긴 편이었는데, 칼집이나 연육 처리로 보완 가능한 방법이 있을까요?
2. 대당 평균 150g이라고 하셨는데 실제 편차 범위(최소~최대)가 어느 정도인지, 정산은 대당 기준인지도 궁금합니다.
3. 리드타임은 며칠 정도 잡으면 되는지, 최소 발주 단위도 알려주시면 감사하겠습니다.
4. 지난번 말씀하신 호주산·캐나다산 테스트 샘플도 가능하면 같이 받아보고 싶습니다.
5. 정리된 내용으로 견적서 한 부 메일로 부탁드립니다.

검토 마치는 대로 다시 연락드리겠습니다. 감사합니다.
```
