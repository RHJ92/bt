# 인계 — 철산장 생포갈비(소) 이티엘비 소싱 (2026-11-05)

**지금 상태**

- 공급처 이티엘비(포천, 대표 조찬성)로 진행, 규격 **4.5cm 확정**(6,800원/대, 면세, 20대 2kg 진공·4팩/박스, MOQ 10박스)
- 운영 매장: 문래점 대신 **을지로점 우선 운영**으로 결정
- 초기 운영 방식: 매입사 범용 라벨로 출고 → 마켓봄 택배(리드타임 4일). 특이사항 없으면 전용 스티커로 생산 → 제때 센터 입고로 전환
- 가맹점 공급가 권장안: **7,520원/대, 1팩(20대) 150,400원(면세)**. 제때 기준과 같은 금액. 사용자는 "택배비 포함 가격"으로 정하고 시작함
  - 매입 136,000원/팩 → 총마진 14,400원(9.6%). 택배비가 1회 약 6,880원(VAT 별도) 이하이면 순마진 5% 이상
- 을지로점 운영 안내 카톡 문안 교정 완료(운영 방식·택배 포장·수령 직후 품질 확인 요청). 발송은 사용자가 직접
- 샘플 구매 영수증(10/26, 4.5cm 5대 34,000원 + 10cm 2대 37,000원 = 71,000원, 세액 0원) 대사 완료 → **견적 단가와 일치**, 면세 확인

**다음 할 일**

1. 이티엘비에 확인: 을지로점 직배송 여부, 택배비와 부담 주체, 테스트 기간 MOQ(10박스 = 800대)를 완화하거나 업체에 보관해 두고 주문 때마다 출고할 수 있는지
2. 마켓봄 상품 등록: 판매 단위 1팩(20대·2kg, 냉동), 공급가 150,400원, 면세, 리드타임 4일
3. 노션 이티엘비 검토 페이지와 README에 결정 사항 반영: 4.5cm 확정, 을지로점 우선, 마켓봄 택배 운영, 공급가 150,400원/팩 (이 세션에서는 미반영)
4. 운영해 보고 특이사항 없으면 전용 스티커를 제작하고 제때 입고를 세팅함. 이때 공급가는 7,520원/대를 유지함(제때 물류비 4.5% 반영 시 순마진 5.1%)

**막힌 것·대기 중**

- 이티엘비 회신 대기: 택배 출고 주체와 택배비, MOQ
- 사용자 확인 필요: 샘플 영수증의 공급받는 자가 **주식회사 철산장에프앤비**(조영훈)로 발행됨. 철산장이 샘플 대금을 직접 내기로 한 게 아니라면 블루트렌드로 재발행 요청
- 택배비를 본사가 부담할지, 주문금액별 배송비 정책으로 매장에 넘길지 최종 정하지 않음 (현재는 본사 부담 = 택배비 포함 공급가로 인지)
