# 포천공장 전달용 — 돼지양념갈비 요청 스펙 (2차 샘플)

> 작성 2026-09-10 구매팀 · 1차 샘플(남영돈 양념소갈비 / 이동본갈비1) 양념 평가 통과 시 전달
> 기준: 현행 사용 제품(양문한돈양념구이)의 제조사 확인 실제 배합 — 단, 대(개수) 구성은 인가공이 늘어 **kg 비율 기준으로 전환** (2026-09-10)

## 발송용

안녕하세요, 블루트렌드 구매팀입니다.

보내주신 샘플 2종 양념 평가 결과를 바탕으로, 저희가 원하는 제품 스펙을 정리해 전달드립니다. 이 스펙으로 돼지고기 투입 2차 샘플 제작 가능 여부와 견적 검토 부탁드립니다.

**1. 제품 개요**

- 품명: 철산장 전용 돼지양념갈비 (양념육 / 가열하여 섭취하는 냉동식품)
- 구성: 양념 등갈비 + 양념 목살 혼합 포장
- 원산지: 돼지고기 국내산 (한돈)

**2. 원물 스펙**

| 항목 | 내용 |
|---|---|
| 고기 구성비 | **등갈비 3 : 목살 7 (중량 기준)** |
| 등갈비 | **대 단위 컷팅** |
| 한돈 목살 | **1.5cm 두께 컷팅 후 양면 칼집** |
| 양념 | **샘플 진행에 투입된 귀사 배합 그대로 사용** |

- 고기 구성비는 개수(대)가 아닌 **kg 단위**로 맞춰주시면 됩니다
- 양념 투입 비율도 귀사 샘플 배합 기준으로 하시되, 견적서에 **완제품 기준 고기 : 양념 배합비(%)를 명시**해 주시기 바랍니다

**3. 포장**

- 포장 형태: **트레이 + 탑실링** (비닐 실링 불가)
- 팩 중량: **귀사가 취급하는 4~5kg 용기 트레이 규격에 맞춰 지정** 후 회신 부탁드립니다
- 박스 입수·파렛트 적재 기준은 귀사 표준으로 회신 부탁드립니다
- 전용 필름지: 당사가 디자인을 전달하면 귀사에서 인쇄·적용 가능한지, 가능 시 MOQ·리드타임 회신 부탁드립니다

**4. 물량·물류**

- 월 사용량: **5톤 (2026년 11월 기준)**
- 발주 단위: 파렛트 단위 가능
- 납품처: 제때 물류센터 오산 IC (경기 오산) — 물류비 포함 조건으로 견적 부탁드립니다

**5. 견적 요청**

- **kg당 단가** (VAT 별도, 오산 IC 입고 물류비 포함)
- 단가에 포함되는 범위(원물·양념·포장 자재) 및 완제품 배합비 명시 부탁드립니다

**6. 함께 회신 부탁드리는 사항**

1. 위 스펙 2차 샘플 제작 가능 여부 및 샘플 발송 가능 일정
2. 확정 팩 중량 (귀사 트레이 규격 기준)
3. HACCP 인증 여부
4. 소비기한 설정 기준 (냉동)
5. 국내산 등갈비 수급 안정성 (연중 공급 가능 여부)
6. 표시사항 — 실제 배합비 기준으로 작성 예정이며, 품목제조보고 시 협조 가능 여부

## 내부용 — 작성 근거·주의

- **대(개수) 구성 → kg 비율로 전환 (2026-09-10).** 등갈비 65g + 목살 150g을 대 단위로 맞추면 인가공이 늘어 단가가 오른다. 고기 내부 비율만 3 : 7(양문 실제 배합 650 : 1,500g과 동일)로 지정하고 개수 구성은 풀었다.
- **컷팅 스펙 지정** — 등갈비 대 단위 / 목살 1.5cm 양면 칼집. 현행 3종 세트의 칼집목살(양면)과 동일한 규격이라 매장 관능 연속성이 유지된다.
- **양념 비율은 업체 배합에 위임했다.** 대신 견적서에 고기 : 양념 배합비 명시를 요구했다 — 업체마다 양념 비중이 다르면 kg당 단가가 왜곡되므로, **견적 비교는 반드시 고기 kg당 단가로 환산해서 한다** (완제품 단가 ÷ 고기 비중). 나누리 벤치마크: 완제품 10,222원/kg ÷ 47.8% = 고기 kg당 21,385원.
- **팩 중량은 업체 트레이 규격에 위임** (4~5kg 범위). 2026-09-08 결정(트레이·5kg 이하)과 정합.
- **월 사용량은 5톤으로 안내** (11월 기준, 기존 안내치 1,575kg에서 상향). 물량이 커진 만큼 단가 협상 지렛대로 쓴다.
- **타겟 단가는 공개하지 않았다.** 벤치마크는 나누리 46,000원/4.5kg팩(kg당 10,222원, 물류 포함).
- **원물 사급(잔여 로인립) 얘기는 꺼내지 않는다** — 진행 확정 후 협의.
- 관능 평가는 문래점 프레임과 동일 — 나누리 샘플 대비 색·단맛·염도 3축.
