발신: 블루트렌드 구매팀

## 1. 요청 개요

- 당사 **철산장** 브랜드의 돼지갈비 메뉴를, 매장 조리 공정을 없앤 **양념육 완제품**으로 전환하고자 합니다.
- 귀사에서 **소스를 직접 배합**하고, **한돈목살·로인립을 해당 소스에 숙성**한 뒤 **포장·납품**하는 작업을 의뢰드립니다.
- 소스는 당사가 **레시피와 원료 매입가를 제공**하며, 귀사가 이를 기준으로 배합합니다. (당사 소스공장은 HACCP 미인증이라 소스 완제품 반입 대신 이 방식으로 진행합니다.)
- **회신은 완제품 기준 단가로 부탁드립니다.** 원가구성 양식(9항)에 항목별로 나누어 기입해 주십시오.

## 2. 제품 개요

| 항목 | 내용 |
|---|---|
| 품명 | 철산장 돼지양념갈비 (양념육, 냉동) |
| 구성 | **양념 로인립 13피스 + 양념 목살 13피스 + 양념**, 1팩 혼합 포장 |
| 규격 | **4.5kg / 팩** |
| 사용 형태 | 가맹점에서 팩을 개봉해 **바트에 그대로 부어** 사용. 매장 내 별도 양념·숙성 공정 없음 |
| 유통 | 냉동 |

**현행 방식(참고)** — 한돈목살 칼집·로인립 원물·소스를 매장에 각각 입고해 **점주가 직접 재우는** 구조입니다. 숙성 대기 시간과 작업 부담이 커 완제품 전환을 결정했습니다.

## 5. 요구 공정

1. **원물 입고·해동**
2. **정선** (필요 시) — 목살은 양면칼집 가공된 상태로 입고
3. **소스 배합** — 당사 제공 레시피 기준
4. **양념·숙성** — 목살·로인립 **각각** 양념하여 숙성. 숙성 조건(시간·온도)은 귀사 기준으로 제안해 주십시오
5. **혼합 포장** — 양념 로인립 13피스 + 양념 목살 13피스 + 양념을 1팩에 담아 진공 포장
6. **박스 포장 후 지정 물류센터 입고**
