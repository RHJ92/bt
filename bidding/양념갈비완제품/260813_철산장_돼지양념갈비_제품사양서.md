> 용도: 전용 필름지 디자인, 표시사항 작성, 가맹점 취급 매뉴얼의 기준 문서

## 2. 확정 스펙 ★

**제조사 회신 원문 (2026-08-13)**

```
[양문 한돈양념구이]
등갈비 65g*10대
목살 150g*10대
양념 2.35kg
```

| 구성 | 1대 | 팩당(10대) | 배합비 |
|---|---|---|---|
| 목살 | 150g | 1,500g | **33.3%** |
| 등갈비 | 65g | 650g | **14.4%** |
| 갈비양념소스 | 235g | 2,350g | **52.2%** |
| **합계** | **450g** | **4,500g** | **100%** |

- **목살 150g·등갈비 65g은 양념을 머금기 전 원물 평균 중량**이다 (제조사 확인). 원가 산출은 이 기준으로 한다.
- 양념 흡수 후에는 고기와 양념의 비율이 달라지며, **그 값은 때마다 변동**한다 (제조사 확인).
- 합계가 정확히 4.5kg으로 떨어져 스펙 정합성이 확인됐다.

## 3. ⚠️ 라벨 표기와 실제 배합이 다르다

양문 제품 한글표시사항의 함량 비율은 **실제 공급 스펙과 일치하지 않는다.** 제조사 설명 — 스펙이나 양념의 양을 조절하면서 라벨 표기와 차이가 생겼다.

| 구성 | 라벨 표기 | 라벨 기준 팩당 | **실제 배합** | 차이 |
|---|---|---|---|---|
| 목살 | 51% | 2,295g | **1,500g** | **−795g** |
| 등갈비 | 15% | 675g | 650g | −25g |
| 갈비양념소스 | 34% | 1,530g | **2,350g** | **+820g** |

**자사 전용 제품은 실제 배합비로 표시사항을 새로 작성해야 한다.** 제조사도 "양문과 동일 제품으로 하실 거라면 라벨의 비율을 수정하면 된다"고 회신했다. 양문 라벨을 그대로 옮기면 표시사항 부적합이 된다.

**표시사항 원재료 함량 초안**

```
돼지고기 47.8% (목살/국내산 33.3%, 등갈비/국내산 14.4%),
갈비양념소스 52.2%
```

> 원산지는 제조사 표준(국내산) 기준. **자사 수입산 로인립을 투입하는 경우 등갈비 원산지 표기가 바뀐다** — 진행 확정 후 사급·매각 협의 시 함께 확정할 것.

## 4. 포장 사양

| 항목 | 내용 |
|---|---|
| 팩 규격 | 4.5kg / 팩 (10대) |
| 박스 입수 | 4팩 / 박스 = 18kg |
| 파렛트 적재 | 32박스 / 파렛트 = 128팩 · 576kg |
| 포장 형태 | 플라스틱 트레이 + 탑실링 필름 |
| 전용 필름지 | **자사 디자인 전달 → 제조사가 직접 인쇄.** MOQ·리드타임 자사 부담 없음 (2026-08-13 확인) |

## 5. 보관·유통 조건

| 항목 | 내용 |
|---|---|
| 유통 | **냉동** |
