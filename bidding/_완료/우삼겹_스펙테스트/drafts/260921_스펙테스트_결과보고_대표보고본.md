# 우삼겹(삼겹양지) 브랜드·가공장 스펙 테스트 결과 보고

보고일 2026. 9. 21. · 구매팀 류호정 · 대표 보고용
노션 등록: 「기록」 작업 페이지 DB (2026-09-21)

## 진행 개요

- 2026년 5~6월 우삼겹 슬라이스 과지방 품질 개선 요청에 따라, 기존 브랜드·가공장 외 스펙 3종을 기간을 나눠 실제 출고하며 현장 반응을 확인함
- 지방 품질은 원물별 편차가 커 샘플 1박스로 판단이 불가하여, 스펙별 2주 이상 실출고 방식으로 진행함
- 테스트 원가 상승분: 약 120만 원 (kg당 150원 × 8,000kg)

## 스펙별 운영 내역

| 스펙 | 브랜드·가공장 | 운영 기간 |
|---|---|---|
| A | 86M | 7/1 ~ 7/31 |
| B | IBP 278 | 8/1 ~ 8/25 |
| C | 엑셀 86K | 8/26 ~ 9/13 |

- B(IBP 278)·C(엑셀 86K)는 각 브랜드에서 삼겹양지 크기가 가장 균일한 스펙으로, 타 가공장 넘버 대비 시세가 kg당 100~150원 높음
- 구매 시점이 달라 단순 비교는 어려우나, 10톤 운영 기준 원가 차이는 연 100~150만 원 수준임

## 반품 기안 내역 (테스트 기간, 입고일 기준 스펙 구분)

| 스펙 | 입고일 | 브랜드·지점 | 기안자 | 사유 | 수량 | 금액 |
|---|---|---|---|---|---|---|
| A | 7/3 | 옥된장 판교점 | 강수현 | 과지방 | 2kg | 25,800원 |
| A | 7/17 | 옥된장 교대점 | 유승진 | 과지방(부분반품) | 1kg | 12,900원 |
| B | 8/6 | 석문어 신사점 | 강동균 | 변색·이취 | 2kg | 25,800원 |
| B | 8/17 | 석문어 광교아브뉴프랑점 | 강동균 | 과지방 | 5.2kg | 67,080원 |

- 합계: 6건 / 15.2kg / 195,680원 (옥된장 4건 102,800원, 석문어 2건 92,880원)
- 스펙별: A 2건 38,700원 / B 3건 144,480원 / C 1건 12,500원

## 해석에 유의가 필요한 건

- 석문어 광교아브뉴프랑점(8/17 입고, 67,080원): 지방을 일정 기간 모아 일괄 반품 요청한 건으로, 특정 입고분 품질로 귀속하기 어려움. 해당 지점은 올해 동일 방식 3회차이며 삼겹양지 과지방 누적 반품액은 175,496원임
- 옥된장 인천운서점(8/24 입고, 51,600원): 프랩 완료 후 매장 보관 과정에서 발생한 갈변 건으로, 매장 관리 귀책 여부 확인 없이 반품 기안이 진행되어 원물 문제 여부를 확인할 수 없음

## 운영팀 회신 현황 및 기안 내역과의 차이

- 석문어 회신(기간별 문의 건수): A 3건(과지방 2, 갈변 1) / B 0건 / C 1건(과지방)
- 동일 기간 석문어 반품 기안: A 0건 / B 2건(신사점 8/6, 광교아브뉴프랑점 8/17) / C 0건
- 회신 내용과 기안 내역이 스펙 구간별로 일치하지 않음. 회신은 A 구간에 문의가 집중된 것으로, 기안은 B 구간에만 발생한 것으로 나타남
- 문의와 반품 기안이 별개로 관리되어 상호 대조가 되지 않거나, 회신 시 기간 구분이 기억에 의존해 이뤄졌을 가능성이 있음. 어느 쪽인지 확인할 수 있는 기록이 없음
- 옥된장: 기간별로 정리된 문의 내역 없음. 구매팀이 반품 기안 내역을 공유하였으며, 별도 피드백은 없음

## 결론

- 양 브랜드 모두 기간별 현장 피드백이 기록으로 관리되지 않아, 회신 자료 자체를 스펙 비교의 근거로 사용하기 어려움
- 반품 기안 기준으로도 스펙별 유의미한 차이가 확인되지 않음(A 2건, B 3건, C 1건). A 스펙은 운영 기간이 타 스펙보다 길어 단순 건수 비교도 성립하지 않음
- 균일도 상위 스펙 운영으로 매장 품질 편차가 줄어드는지 확인하려 했으나 결과를 얻지 못했으므로, 향후 우삼겹은 브랜드·가공장 구분 없이 시세 기준으로 운영함
- 연 100~150만 원의 스펙 프리미엄을 부담하는 것보다, 해당 금액을 지방 관련 인입 클레임 처리 비용으로 운용하는 것이 합리적이라 판단함

## 향후 개선 사항

- 품질 테스트 요청 시, 요청 부서에서 현장 확인 항목과 기간별 피드백 방식을 사전 확정한 후 착수하도록 프로세스를 정리할 필요가 있음
- 현장 문의와 반품 기안이 연결되어 조회되지 않아 사후 검증이 불가한 구조임. 품질 이슈는 접수 시점에 기간·스펙 정보가 함께 남도록 관리 방식 보완이 필요함
