# 우삼겹(삼겹양지) 브랜드·가공장 스펙 테스트

미국산 우삼겹 슬라이스의 **브랜드·가공장(넘버)을 바꾸면 매장 품질 편차가 줄어드는가**를 실출고로 검증한 거점. 2026년 7~9월 A·B·C 3개 스펙을 기간별로 나눠 운영했고, 그 결과를 원가 정책으로 되돌리는 것이 목적이다.

## 이 검토의 핵심 질문

"각 브랜드에서 **삼겹양지 크기가 가장 균일하다는 상위 스펙**에 kg당 100~150원을 더 주는 것이, 과지방 클레임을 줄여서 그 값을 하는가"

값을 한다면 상위 스펙 상시 운영, 아니면 시세 기준 운영 후 차액을 클레임 처리 비용으로 돌린다.

## 현재 상태 (2026-09-21)

- **종결.** 스펙 간 품질 차이를 판단할 근거를 얻지 못했고, 향후 우삼겹은 **브랜드·가공장 구분 없이 시세 기준으로 운영**하는 것으로 정리됨
- 대표 보고 완료 → 노션 「기록」 작업 페이지 DB에 정리본 등록
- 실패 원인은 상품이 아니라 설계에 있음: **스펙별 현장 피드백을 어떻게 받을지 정하지 않고 테스트를 시작**했다. 옥된장은 기간별 정리 내역 자체가 없었고, 석문어 회신은 반품 기안과 구간이 어긋나 대조가 되지 않았다

## 전제값

| 항목 | 값 | 비고 |
|---|---|---|
| 테스트 원가 상승분 | 약 120만 원 | kg당 150원 × 8,000kg |
| 상위 스펙 프리미엄 | kg당 100~150원 | 10톤 운영 기준 연 100~150만 원 |
| 공급가(Vat 포함) | 129,000원/10kg → 9월 125,000원 | 성수점 건만 125,000원 적용분 |
| 스펙 귀속 기준 | **입고일자** | 기안일·제조일 아님. 기안은 입고 후 최대 1개월까지 지연됨 |

**반품 기안의 스펙 귀속은 입고일로 잡는다.** 기안 작성일 기준으로 보면 교대점(7/17 입고 → 7/20 기안), 운서점(8/24 입고 → 8/28 기안)처럼 구간이 밀린다. 제조일 기준도 안 되는데, 판교점 건은 제조 6/22 · 입고 7/3으로 테스트 시작 전 제조분이기 때문이다.

## 스펙별 운영 내역

| 스펙 | 브랜드·가공장 | 운영 기간 | 반품 기안 |
|---|---|---|---|
| A | 86M | 7/1 ~ 7/31 | 2건 / 3kg / 38,700원 |
| B | IBP 278 | 8/1 ~ 8/25 | 3건 / 11.2kg / 144,480원 |
| C | 엑셀 86K | 8/26 ~ 9/13 | 1건 / 1kg / 12,500원 |

합계 6건 / 15.2kg / 195,680원 (옥된장 4건 102,800원, 석문어 2건 92,880원)

**건수 비교는 성립하지 않는다.** A는 운영 기간이 31일로 B(25일)·C(19일)보다 길다. 그 위에 아래 두 건은 스펙 귀속 자체가 흔들린다.

- **석문어 광교아브뉴프랑점**(8/17 입고, 67,080원) — 지방을 모아뒀다가 일괄 요청한 건. 특정 입고분에 귀속 불가. 올해 동일 방식 3회차, 삼겹양지 과지방 누적 반품액 175,496원
- **옥된장 인천운서점**(8/24 입고, 51,600원) — 프랩 완료 후 매장 보관 중 갈변. 매장 관리 귀책 확인 없이 기안이 올라가 원물 문제 여부를 확인할 길이 없음

## 운영팀 회신과 기안 내역의 불일치

석문어 회신은 A 3건 / B 0건 / C 1건, 같은 기간 반품 기안은 A 0건 / B 2건 / C 0건으로 구간이 정반대다. 문의와 반품 기안이 별개로 관리돼 대조가 안 되는 것인지, 회신 시 기간 구분이 기억에 의존한 것인지 **확인할 수 있는 기록이 없다.** 이 불일치 자체를 보고에 그대로 올렸다.

## 다음에 같은 테스트를 할 때

1. 요청 부서와 **현장 확인 항목·기간별 피드백 방식을 착수 전에 문서로 확정**한다
2. 품질 이슈 접수 시점에 **기간·스펙 정보가 함께 남도록** 한다 — 현재는 현장 문의와 반품 기안이 연결 조회되지 않아 사후 검증이 불가한 구조
3. 스펙별 운영 기간을 **같은 길이로** 맞춘다 (이번 A 31일 / B 25일 / C 19일)
