# 자숙소꼬리 (삼지상사)

소꼬리 원물 대신 **자숙(삶은) 소꼬리 완제품**으로 전환할 때의 원가 검토 거점. 삼지상사 견적서상 상품명은 **꼬리곰탕**이며, 정제수 + 자숙 소꼬리 혼합 제품이다.

## 이 검토의 핵심 질문

"매장에서 소비자에게 **바로 낼 수 있는 삶은 소꼬리 1kg**을 만드는 데 드는 원가가 어느 쪽이 싼가"

두 경로를 같은 기준으로 환산해서 비교한다.

1. 자숙소꼬리 매입 → 공급 → 매장 개봉 (고형량 비율 45%가 곧 수율)
2. 소꼬리 원물 매입 → 공급 → 매장에서 직접 자숙 (자숙 수율 50%)

정리 순서는 항상 **구매기준 원가 → 마진 유지 기준 가맹점 공급가 → 공급가에 수율 반영한 kg당 최종원가**. 견적서에 실린 다른 품목도 같은 방식으로 정리해 한 표에 올린다.

## 현재 상태 (2026-09-10)

- 견적 접수(2026-09-09) → 원가 비교 → 한글 표시사항 실물 확인까지 완료
- 결론: 9월 기준 동일 마진(25.1%)에서 자숙소꼬리가 삶은 소꼬리 kg당 **39,556원**, 원물 자숙이 **58,000원** → 자숙소꼬리가 31.8% 낮음
- 미확정: 견적서와 표시사항의 **원산지 불일치**(아르헨티나 vs 러시아산·베트남 제조), 견적서 고형량 표기 오류, 갈비탕/뼈없는갈비탕 라벨 동일 건

## 전제값 (바뀌면 전부 재계산)

| 항목 | 값 | 출처 |
|---|---|---|
| 완제품 수율 | **고형량 ÷ 내용량** (꼬리곰탕 1.35kg / 3kg = 45%) | 표시사항 실물 확인 |
| 원물 수율 | 매장 자숙 수율 50% | 사용자 확인 2026-09-10 |
| 견적 단가 단위 | ea = 규격 1개 (꼬리곰탕 3kg 1파우치 = 40,000원) | 사용자 확인 2026-09-10 |
| 마진 기준 | 총마진 25.1% (현행 소꼬리 유지) | 중간단가변경이력 2026-09-01 |
| 물류비 | 4.5% | 중간단가변경이력 순마진 산식 |

**수율은 고형량 비율로 잡는다.** 완제품은 이미 자숙된 상태로 들어오므로 고형량이 곧 매장에서 바로 쓸 수 있는 고기 중량이다. 원물은 고형량이 100%지만 매장에서 삶아야 하므로 자숙 수율 50%를 같은 자리에 놓는다 — 두 값 모두 "매장에서 바로 쓸 수 있는 고기 비율"이라 같은 축에서 비교된다.

**견적서의 「가공수율」은 쓰지 않는다.** 공장이 원물을 가공할 때 지방·수분이 빠지고 남는 원물 자체의 수율이라, 완제품을 사는 구매자와는 무관한 값이다. 그 살코기에 육수·정제염을 넣어 소꼬리 45%짜리 완제품이 나온다.

**고형량 값은 표시사항 실물 확인치를 쓴다.** 견적서 고형량 표기는 전 품목이 실제와 다르다(꼬리곰탕·갈비탕류 1.5kg → 실제 1.35kg, 우건탕 3kg → 실제 1.5kg).

## 소꼬리 원물(M02) — 비교 기준선

**비교는 9월 데이터로만 한다** (사용자 결정 2026-09-10).

| 적용 시점 | 구매기준 원가 | 가맹점 공급가 | 총마진 | 수율 50% 반영 최종원가 |
|---|---|---|---|---|
| 2026-09-01 (9월 적용) | 21,709원/kg | 29,000원/kg | 25.1% | 58,000원/kg |

직전 이력은 7~8월 매입 20,447~20,500 / 공급 27,500이었고, 8/21 결정된 인상분이 9/1자로 반영돼 현행 단가가 됐다. 비교표에는 넣지 않는다.

원물 상세(원산지 호주 AMH, 선우프레시 매입 / 신우미트 가공, 매입 16,500 + 가공비 1,430, 로트별 가공수율)는 `agent_livestock_products/` 거점과 구글시트 claude_축산품이 원본이다. 이 폴더는 **비교 결과만** 들고 있는다.
