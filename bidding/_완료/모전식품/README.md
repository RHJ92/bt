# 모전식품 비딩 — 정백선 진국육수베이스 위탁생산 검토

> 검토일 2026-08-03. 담당: 구매팀
> **결론(2026-08-03 확정): 푸드랩 자사 생산 유지. 위탁 전환은 리브랜딩 후 성장 성과 확인 시점에 재검토.** (운영 담당자와 방향 합의)

## 무엇을 결정하는가

정백선 `BF진국육수베이스(JBS/3kg)` 소스의 생산처.

| | 푸드랩 (자사 공장, 현행) | 모전식품 (위탁, 검토안) |
|---|---|---|
| 구조 | 핵심 원재료 3종 구매(로트 500kg) → 자사 생산 | 원료 제조사가 완제품까지 위탁 생산 |
| 원가 | 상대적으로 높음 | 낮음 (절감폭은 견적 대기) |
| MOQ | 원재료 500kg. **시중 범용 원재료라 소량 구매도 가능** | 완제품 1톤 (유통기한 12개월) |
| 재고 리스크 | 수요 하락 시 구매량을 따라 줄일 수 있음 | 1톤 선생산 — 수요가 꺾이면 기한초과 폐기 |

## 출고 실적 (2026-01-01 ~ 08-03, 배송수량 기준)

월별 합계(kg): 1월 255 → 2월 219 → 3월 219 → 4월 183 → 5월 165 → 6월 150 → 7월 156

- **하락 추세**: 반년 만에 -39%. 최근 3개월(5~7월) 평균 **월 157kg (약 52PK)**
- **분당수내점 4월 폐점 확정** (2026-08-03 운영 담당자 확인) — 올해 이미 1개점 이탈. 현재 3개점: 광교·상암·판교역
- 상암점이 2월 신규 진입했지만 광교(-39%)·판교역(-44%) 하락을 못 메움
- 연간 환산 출고량: 157kg × 12 ≈ **1.9톤/년** → 모전 MOQ 1톤 = 약 반년치

## 구매팀 판단 (2026-08-03 운영 담당자와 방향 합의)

**리브랜딩 후 성장 성과가 확인될 때까지 푸드랩 자사 생산 유지.** 성과 확인 시점에 위탁 전환 재검토.

1. 숫자만 보면 현 수준에서 1톤은 기한 내 소진 가능하지만, **분당수내점 이탈이 보여주듯 "현 수준 유지" 가정 자체가 낙관적**이다. 수요는 반년째 한 방향(하락)으로만 움직였다.
2. 자사 생산의 비싼 원가는 사실상 **재고 리스크에 대한 보험료**다. 원재료가 범용이라 수요가 줄면 구매를 따라 줄이면 되고, 브랜드 철수 시에도 손실이 원재료 잔량 수준에 그친다.
3. 위탁 전환의 연간 절감액은 최대 1.9톤 × kg당 절감폭. 절감폭이 확정되면 `원가비교(입력)` 시트에 넣어 철수 리스크 기대손실과 비교 — 절감액이 그걸 넘지 못하면 전환 명분이 없다.

**전환 재검토 트리거** (둘 중 하나 충족 시):
- 리브랜딩 후 월 출고 **250kg 이상이 3개월 연속** 유지 (1톤을 4개월 내 소진하는 수준)
- 모전식품이 **MOQ 분할(500kg × 2회) 또는 잔여 재고 인수 조건**을 수용 — 리우 물티슈 건의 '잔여 필름 인수 조건'과 같은 구조로 협상
