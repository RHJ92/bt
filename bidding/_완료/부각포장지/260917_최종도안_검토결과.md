# 최종 도안 검토 결과 (2026-09-17)

| 항목 | 내용 |
|---|---|
| 대상 | `김부각_패키지_out.ai`, `고추부각_패키지_out.ai` (9/17 디자이너 최종본) |
| 결론 | **규격 미달 2건 → 인쇄 전 수정 필요** — 자간·장평은 법정 기준(식품표시광고법), 바코드 크기는 유통 규격(GS1, 법 조항 아님). 표기 내용(영양정보·원재료명·알레르기·품목보고번호)은 확정값과 전부 일치함 |
| 추가 동판 | 후면 수정 위치는 이미 수정 중인 후면 먹판 안에 있음. 전면(A)을 반영할 경우 전면 먹판이 기존 수정 범위에 들어가 있는지 태백에 확인 필요 |

## 검토 방법

- 최종 AI는 글자가 아웃라인 처리돼 글자 정보가 없음 → 9/9 확정 시안 원본(글자 살아있는 AI)에서 크기·장평·자간을 추출함
- 최종본 vs 9/9 원본 픽셀 대조 결과, **후면 바코드·마크 영역 외에는 글자 내용·크기·위치 동일** 확인. 따라서 추출값이 최종본에 그대로 유효함
- 바코드는 1200~2400dpi로 렌더링해 막대 폭을 실측하고, 막대 패턴을 직접 해독함

## 1. 수정 필요 — 규격 미달

**① 바코드가 최소축소치(80%)보다 작음** — 표기 이미지 7번 · 법 조항이 아닌 GS1 유통 규격 (판독 불량·유통사 입점 검증 리스크)

| 항목 | 현재 | 최소 (80%) | 판정 |
|---|---|---|---|
| 테두리 포함 폭 | 2.98cm | — | — |
| **막대 부분 폭** | **2.19cm (70%)** | **2.51cm** | **미달** |
| **세로 (막대 위~숫자 아래)** | **1.67cm** | **1.8cm** (라코 권장 하한) | **미달** |
| 좌우 여백 | 좌 0.41 / 우 0.39cm | 좌 0.29 / 우 0.19cm | 충족 |

- 테두리가 3.0cm라 최소축소치를 맞춘 것처럼 보이지만, **3.0cm는 「막대 + 규정 여백」 기준**임. 현재는 테두리 안에 여백을 넉넉히 두고 막대를 70%로 줄여 넣은 상태임
- 테두리 크기는 그대로 두고 **안의 바코드만 키우면 해결됨** — 막대 2.51cm + 여백 좌 0.29·우 0.19cm = 2.98cm로 테두리 안에 딱 맞음. 다만 테두리 선이 여백을 침범하지 않도록 테두리를 조금 넓히거나 선을 여백 바깥으로 둘 것
- 번호·체크디지트는 정상임 — 김부각 8800254300046 / 고추부각 8800254300053 (막대 패턴 해독 결과와 숫자 일치)

**② 자간 −5% 미만 · 장평 90% 미만** — 식품표시광고법 시행규칙 별표3 제6호 (두 품목 동일)

| 번호 | 위치 | 현재 | 기준 |
|---|---|---|---|
| 1 | 유통판매원 주소 | 자간 −8% | −5% 이상 |
| 2 | 「품목보고번호」 항목명 | 자간 −10.3% | −5% 이상 |
| 3 | 식품유형 「기타가공품(유탕, 유처리식품)」 | 자간 −10% | −5% 이상 |
| 4 | 영양정보 「총 내용량당」 / 「1일 영양성분 기준치에 대한 비율」 머리글 | 자간 −8% | −5% 이상 |
| 5 | 영양정보 함량·비율 숫자 (나트륨 240mg ~ 단백질 9%) | 자간 −6% | −5% 이상 |
| 6 | 영양정보 하단 문구 「1일 영양성분 기준치에 대한 비율(%)은…」 | **장평 75%**, 자간 −8% | 장평 90% 이상 |

- 일러스트레이터 문자 패널 기준 자간 −50 = −5%임. 1~5번은 값만 −50 이상으로 올리면 됨
- 6번은 장평을 90%로 올리면 현재 2줄에 안 들어가 한 줄 정도 늘어남. 영양정보 박스와 아래 바코드·마크가 그만큼 내려가므로 하단 여유는 디자이너 확인 필요
- 영양정보 표에 장평·자간 기준을 적용하는지는 해석 여지가 있음(별표3 제5호 단서가 영양성분 세부사항을 고시로 넘김). 그러나 수정 비용이 없으므로 맞추는 쪽이 안전함

## 1-2. 추가 확인 (09-17) — 영양정보 표기 규정 위반 2건

| 위치 | 현재 | 수정 | 근거 |
|---|---|---|---|
| 트랜스지방 비율 (두 품목) | 0g **0%** | 0g (% 칸 비움) | 별지1 영양성분 표시 — 열량·트랜스지방은 1일 영양성분 기준치 비율 표시 제외 |
| 콜레스테롤 (김부각) | **0mg 0%** | **5mg 2%** | 별지1 — 가장 가까운 5mg 단위(4.82→5mg), 「0」은 2mg 미만만 가능. 검사 환산값 4.82mg |

- 두 건 모두 9/7 표기안 작성 때 놓친 것임. 트랜스지방 0%는 현행 포장지 표기를 유지값으로 넘겼고, 콜레스테롤은 검사기관 기준치표의 처리(5mg 미만→0)를 따랐으나 현행 고시는 2mg 미만만 0 표시 허용
- 콜레스테롤: 0mg 표시 시 허용오차 상한은 5mg 미만(100g당 25mg 미만 성분은 표시량 +5mg 미만). 검사 환산값 4.82mg이라 **여유 0.18mg(4%)뿐** — 재검사 편차나 건새우·멸치 로트 차이로 5mg을 넘으면 부적합. 「5mg」 표시 시 상한 10mg 미만으로 여유 충분
- 고추부각은 동물성 원료가 없어 불검출 → 0mg 0% 정확
- 나머지 수치·비율·순서·글씨(열량 굵게, 비율 굵게·함량과 같은 크기)는 규정과 일치함
- 처분 기준(시행규칙 별표7): 영양성분 표시기준 위반 → 1차 시정명령, 2차 영업정지 5일, 3차 10일

## 1-3. 열량 산출 오류 (09-17 검사서 재검토)

| 품목 | 현재 표시 | 표시값 기준 계산 | 수정 |
|---|---|---|---|
| 김부각 50g | 270kcal | 탄수 25×4 + 단백 5×4 + 지방 17×9 = **273** | **275kcal** (또는 273kcal) |
| 고추부각 70g | 415kcal | 탄수 33×4 + 단백 4×4 + 지방 30×9 = **418** | **420kcal** (또는 418kcal) |

- 「식품등의 표시기준」 별지1 — 열량은 **영양성분의 표시함량**으로 계산(탄수화물·단백질 4kcal/g, 지방 9kcal/g) 후 그대로 또는 가장 가까운 5kcal 단위로 표시
- 검사기관 기준치표가 이미 이 방식임: 김부각 40g 20·4·13g → 213 → 215 표시(「213 표시가능」), 100g 50·11·33g → 541 → 540(「541 표시가능」), 고추부각 50g 23·3·21g → 293 → 295(「293 표시가능」)
- 9/7 표기안에서 「검사 원값을 5kcal 단위로 내림」으로 잘못 역산함. 원값 내림이 우연히 같은 결과를 낸 것이었음
- 전면 「(○○kcal)」도 같이 바꿔야 함 → 두 품목 전면 동판 수정 필요
- 실측 허용오차(120% 미만)로는 적합이나, 표시값끼리 곱해보면 바로 드러나는 불일치라 표시 점검에서 눈에 띄기 쉬움

## 2. 판단 필요 — 전면 원재료 함량 글씨 크기 (A)

| 항목 | 현재 | 규정 |
|---|---|---|
| 김부각 「찹쌀(국내산) 52%, 김(국내산) 38%」 | 12.0pt, 장평 90% | 아래 참조 |
| 고추부각 「고추(국내산)58%」 | 12.0pt, 장평 94% | 아래 참조 |

- 「식품등의 표시기준」 별지1 1.바(원재료명) 항목 — 원재료명을 주표시면에 표시하면 **12pt 이상** → 현재 충족(여유 0)
- 같은 별지1 1.가.3)가) — **제품명에 원재료명을 사용하면** 해당 원재료명과 함량을 주표시면에 **14pt 이상** → 김부각의 「김」, 고추부각의 「고추」가 해당되면 미달
- 다만 1.가.3)나) — **요리명을 제품명에 쓴 경우 함량표시를 생략할 수 있음**(예: 불고기○○, 짬뽕○○). 「김부각」「고추부각」을 요리명으로 보면 14pt 규정 적용 대상이 아님
- **권장: 「김(국내산) 38%」「고추(국내산) 58%」 부분만 14pt로 올릴 것.** 2년치 인쇄 건이라 해석 논란을 남기지 않는 편이 안전함. 단, 전면 먹판이 기존 동판 수정 범위 밖이면 판 1개가 추가될 수 있어 태백 확인 후 결정
