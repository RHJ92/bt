# 영양성분 검사서·품목제조보고서 검토 (2026-09-07)

검토 대상은 `reference/서류/` 6건. 손수식품이 만드는 「손수고 한입김부각 스위트」·「손수고 고추부각」에 포장지만 옥된장으로 바꿔 별도 품목제조 신고를 한 구조라, 양쪽 신고 데이터를 대조함.

---

## 1. 영양성분 검사서로 본 포장지 수정 사항

검사기관은 ㈜동진생명연구원. 두 건 모두 실측값은 확보됐으나, **검사서의 기준량이 우리 포장 내용량과 다름**에 유의할 것.

| 품목 | 검사서 기준량 | 우리 포장 내용량 |
|---|---|---|
| 김부각 | 40g / 100g | **50g** |
| 고추부각 | 50g (손글씨로 60g 환산 병기) | **70g** |

### 김부각 — 100g당 실측을 50g으로 환산

| 항목 | 현행 포장지 | 검사서 환산(50g) | 판정 |
|---|---|---|---|
| 열량 | 270kcal | 272.07 | 유지 가능 |
| 나트륨 | **238g** | 239.40mg | **단위 오류 + 수치 정정** |
| 탄수화물 | 25g | 25.08 | 유지 |
| 당류 | 4g | 3.70 | 유지 |
| 지방 | **16g** | 16.73 | **17g로 정정 검토** |
| 포화지방 | 2.8g | 2.77 | 유지 |
| 트랜스지방 | 0g | 0 | 유지 |
| 콜레스테롤 | 0mg | 4.82 | 유지 (5mg 미만) |
| 단백질 | 5g | 5.30 | 유지 |

지방을 17g으로 올리면 1일 기준치 비율도 30% → 31%로 바뀜.

### 고추부각 — 100g당 실측을 70g으로 환산

| 항목 | 현행 포장지 | 검사서 환산(70g) | 판정 |
|---|---|---|---|
| 열량 | 416kcal | 415.66 | 415로 정정 검토 |
| 나트륨 | **295g** | 294.97mg | **단위 오류** (수치는 일치) |
| 탄수화물 | 33g | 32.82 | 유지 |
| 당류 | 5g | 4.82 | 유지 |
| 지방 | 30g | 29.86 | 유지 |
| 포화지방 | 4.5g | 4.50 | 유지 |
| 콜레스테롤 | 0mg | 불검출 | 유지 |
| 단백질 | 4g | 3.90 | 유지 |

고추부각은 나트륨 단위(g → mg)만 고치면 나머지는 실측과 맞음. 현행 표기가 70g 기준으로 정확히 산출돼 있었음이 확인됨.

### 검사기관에 요청할 것

표시량의 반올림은 검사기관이 표시기준에 맞춰 산출한 값을 쓰는 것이 안전함. 현재 받은 기준치표가 우리 내용량과 달라 그대로 옮겨 쓸 수 없음.

- **김부각 50g당 / 고추부각 70g당 「영양소 기준치표」 재발급 요청** — 실측 데이터는 이미 있으므로 기준량만 바꾸면 됨
- **김부각 검사성적서 원본 확보** — 현재 영양소 기준치표 2장만 있고 성적서 본문이 없음. 고추부각은 성적서(FDB240215-023) 있음

### 확인이 필요한 두 가지

- 고추부각 검사성적서의 의뢰 업체명이 **㈜옥된장에프엔비**(성남시 중원구 산성대로 134, 대표 조영훈)임. 현행 포장지의 유통판매원은 **㈜블루트렌드**라 다름. 법인 변경 이력인지 확인할 것
- 고추부각 검사서 여백에 **60g 환산값이 손글씨**로 적혀 있음. 이는 손수 신고 기준(60g)이며 우리 70g과 다름. 내용량 변경 계획이 있는지 확인하고, 없다면 혼선 방지를 위해 무시할 것

## 2. 손수식품 신고 vs 옥된장 신고 대조

두 제품군 모두 보고인(이석준)·영업소(손수, 등록번호 20240893141)·소재지·식품유형(기타가공품)·소비기한(제조일로부터 12개월)·위탁생산(아니오)·살균여부(비살균)·보관방법(실온, PE)·용도(간식 및 반찬용)는 동일함. 영양성분 표시의무 식품 해당 여부도 양쪽 모두 「아니오」로 신고돼 있음.

### 김부각 계열

| 항목 | 손수고 한입김부각 스위트 | 옥된장 김부각 |
|---|---|---|
| 품목제조보고번호 | 202408931416 | 2024089314112 |
| 보고일 / 처리일 | 2024-10-07 / 10-10 | 2024-04-08 / 04-24 |
| 제품 성상 | 동일 | 동일 |
| **원재료 순서** | 찹쌀52%, 김38%, **설탕(3번)**, 천일염, 건새우, 건조멸치, 건조다시마, 대파, 무, 볶은참깨, 옥수수기름 | 찹쌀52%, 김38%, 천일염, 건새우, 건조멸치, 건조다시마, 대파, 무, 볶은참깨, 옥수수기름, **설탕(11번)** |
| 포장단위 | 밀봉포장 10g 단위로 포장 | 밀봉포장 50g |
| 영양성분 기재 | ① 총 내용량당 (40g) | ② 100g당 (총 내용량 50g) |

**핵심 차이는 설탕의 순서임.** 원재료명은 배합비율이 높은 순으로 적어야 하는데, 옥된장 신고서만 설탕이 맨 끝(11번)에 있음. 손수 신고서와 **우리 현행 포장지 표기**는 둘 다 3번임. 즉 옥된장 신고서 쪽이 잘못된 것이며, 서류에도 손글씨로 「3번으로 기입」이라고 표시돼 있음.

→ **옥된장 김부각 품목제조 변경신고로 설탕을 3번으로 정정할 것.** 지금 상태로는 포장지 표기와 신고 내용이 어긋남.

### 고추부각 계열

| 항목 | 손수고 고추부각 | 옥된장 고추부각 |
|---|---|---|
| 품목제조보고번호 | 202408931415 | 2024089314113 |
| 보고일 / 처리일 | 2024-04-08 / 05-09 | 2024-04-08 / 05-09 (동일) |
| 원재료 구성·순서 | 고추58%, 밀가루, 옥수수전분, 찹쌀, 설탕, 볶은참깨, 정제소금, 옥수수기름 (8종) | 동일 |
| 옥수수전분 표기 | 옥수수전분 [외국산:헝가리,세르비아,러시아등] | 옥수수전분 [**옥수수**(외국산:헝가리,세르비아,러시아등)] |
| 포장단위 | 밀봉포장 50g~500g | 밀봉포장 70g |
| 영양성분 기재 | ① 총 내용량당 (**60g**) | ② 100g당 (총 내용량 **70g**) |
| 용도·용법 | 간식 및 반찬용 | 간식 및 **반창용** (오타) |

원재료 구성과 순서는 동일함. 옥수수전분 표기는 옥된장 쪽이 원료 원산지를 더 정확히 적은 형태이며, 현행 포장지 표기와도 일치함.

→ **옥된장 고추부각 신고서의 「반창용」 오타를 변경신고 시 함께 정정할 것.**

## 3. 조치 목록

| 순번 | 조치 | 대상 | 비고 |
|---|---|---|---|
| 1 | 품목제조 변경신고 — 원재료 순서에서 설탕을 3번으로 | 옥된장 김부각 | 포장지·손수 신고서와 불일치. 도안 확정 전에 정리할 것 |
| 2 | 품목제조 변경신고 — 용도·용법 「반창용」→「반찬용」 | 옥된장 고추부각 | 1번과 함께 처리 |
| 3 | 영양소 기준치표 재발급 요청 (김부각 50g당 / 고추부각 70g당) | 동진생명연구원 | 표시량 반올림은 기관 산출값을 쓸 것 |
| 4 | 김부각 검사성적서 원본 확보 | 손수식품 | 현재 기준치표만 있음 |
| 5 | 포장지 영양정보 수정 — 김부각 나트륨 238g→240mg, 지방 16g→17g(30%→31%) | 마케팅팀 디자인 요청서 | 3번 회신 후 최종 확정 |
| 6 | 포장지 영양정보 수정 — 고추부각 나트륨 295g→295mg, 열량 416→415 검토 | 마케팅팀 디자인 요청서 | 3번 회신 후 최종 확정 |
| 7 | 검사성적서 의뢰업체(㈜옥된장에프엔비)와 유통판매원(㈜블루트렌드) 상이 건 확인 | 내부 | 법인 변경 이력 여부 |
| 8 | 내용량 변경 계획 확인 (고추부각 70g 유지 여부) | 내부 | 변경 시 품목제조 변경신고 필요 |

**표시사항 수정 항목 갱신** — 기존 7건에 위 5·6번(영양성분 수치 정정)이 흡수되고, 품목제조 변경신고 2건이 별도 선행 과제로 추가됨. 변경신고는 도안 확정 전에 끝나야 하므로 9월 중 착수할 것.
