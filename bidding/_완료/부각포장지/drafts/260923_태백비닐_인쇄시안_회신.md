# 태백비닐 회신 — 인쇄 시안 확인 (2026-09-23)

근거: `260923_인쇄시안_검토결과.md`

```
안녕하세요, 블루트렌드 구매팀 류호정입니다.

인쇄 시안 잘 받았습니다. 표기 내용은 저희가 보내드린 최종 도안과
전부 일치하는 것으로 확인했습니다. 아래 몇 가지만 확인 부탁드립니다.

1. 앞서 요청드린 후면 영양정보 3가지가 시안에는 반영되지 않은 것 같습니다.
   제판 단계에서 가능하시면 반영 부탁드리고, 어려우시면 그대로 진행하겠습니다.
   · 트랜스지방 줄 오른쪽 비율 칸의 「-」 삭제 (빈칸으로)
   · 하단 문구 「은  2,000kcal」의 두 칸 공백을 한 칸으로
   · 김부각 「단백질 5g」의 5와 g 사이 간격을 다른 줄과 같게

2. 시안 상단에 김부각 수정 5판, 고추부각 수정 6판(백·무광 제외)으로 기재돼 있습니다.
   이 기준으로 동판수정비는 김부각 890,000원(VAT 별도), 고추부각 귀사 부담이
   맞는지 확인 부탁드립니다. 변동이 있으면 알려주세요.

3. 시안에 적힌 「옥된장 엄마 고추부각 겸용」과 「돔보무시하고 인쇄」가
   어떤 의미인지 알려주시면 감사하겠습니다.

4. 후면 하단의 HACCP·분리배출 마크가 밑지 접히는 구간에 일부 걸쳐 보입니다.
   완성품에서 마크가 가려지지 않는지 확인 부탁드립니다.
   가려질 우려가 있으면 마크를 왼쪽으로 옮겨 다시 보내드리겠습니다.

5. 납기(입고 가능일)와 실제 생산 수량의 변동 허용 범위도 함께 알려주세요.
   발주 수량은 품목당 29,500매입니다.

위 사항 확인되면 바로 OK 드리고 동판 진행 부탁드리겠습니다.
감사합니다.

블루트렌드 구매팀 류호정 드림
```

## 회신 후

- 4번이 "문제없음"이면 즉시 OK → 동판 → 인쇄
- 4번이 "가려질 수 있음"이면 디자이너에게 마크 좌측 25~30mm 이동 요청 (곡선 여유 확보)
- 2번 회신은 발주서 근거로 보관
