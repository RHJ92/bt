# 태백비닐 요청 사항 (2026-09-04)

부각 포장지 신규 제작 건으로 기존 생산처 태백비닐에 요청할 내용. **1차는 지금 바로**(현황 자료), **2차는 도안 확정 후**(정식 견적) 두 번에 나눠 진행함.

도안이 아직 확정 전이라 정식 견적은 받을 수 없으나, 현황 자료는 지금 받아야 오원색 견적이 들어왔을 때 비교 기준이 생김.

---

## 1차 요청 — 현황 자료 (지금)

발송 문안은 아래 「발송용 문안」 참조.

| 구분 | 요청 항목 | 왜 필요한가 |
|---|---|---|
| 단가 | 김부각·고추부각 **장당 현행 단가**, 최근 적용일 | 오원색 견적 비교의 기준값. 현재 우리 쪽에 확보된 값이 없음 |
| MOQ | 품목별 최소 발주 수량 | 연간 소요가 김부각 18,540장·고추부각 14,860장이라, MOQ가 이보다 크면 협상 포인트가 됨 |
| 리드타임 | 발주~납품 소요일. 동판 수정이 있는 경우와 없는 경우 각각 | 12월 중순 입고 역산의 근거 |
| 동판 | 품목별 **보유 동판의 도수·판 수**, 제작 연월, 보관 상태 | 수정 범위와 비용 발생 여부 판단의 전제 |
| 사양 | 규격(가로×세로), 재질·층 구성, **두께(㎛)**, 인쇄 도수 | 두께 하향 검토와 견적요청서 공통 스펙 작성에 필요 |

## 2차 요청 — 정식 견적 (도안 확정 후, 10월 중)

**반영할 표시사항 수정** — Made in Korea 문구 추가 / HACCP·할랄 마크 추가 / 나트륨 단위 g → mg 정정 / 영문 제품명 병기(대표 확정 시) / 알레르기 표기(방침 확정 후).

**견적서에 반드시 분리해 받을 항목**

| 항목 | 요구 사항 |
|---|---|
| 동판 | 수정 범위와 **동판비 발생 여부를 서면으로 명시**. 무상이면 무상이라고 기재. 단가에 녹여 받지 않음 |
| 두께 | **2안 병기** — 현행 유지 / 한 단계 하향. 각각의 장당 단가 |
| 수량 구간 | **2안 병기** — 연간 일괄(김부각 18,540장, 고추부각 14,860장) / 반기 2회 분할. 각각의 장당 단가 |
| 부대비용 | 필름비·판비·기타 부대비용을 항목별로 분리 |
| 조건 | 장당 단가 기준, VAT 별도, 가맹점 도착 기준 여부 명시 |

## 샘플 요청

- 두께 **한 단계 하향** 사양 샘플. 실링 테스트용으로 품목별 각 100장 내외
- 무지 또는 현행 도안 어느 쪽이든 무방. 소요 기간과 비용 회신 요청
- 목적: 손수식품에서 현재 실링 온도 200도에도 불량이 한 개씩 발생하고 있어, 두께가 원인인지 확인하려는 것

## 일정 (회신 기한)

| 시점 | 내용 |
|---|---|
| 9월 하순 | 1차 현황 자료 회신 |
| 10월 중 | 확정 도안 전달 → 정식 견적 요청 |
| 11월 중순 | 견적 마감·업체 선정 |
| 11월 하순 | 발주 |
| 12월 중순 | 포장지 입고 (가능 여부 확약 요청) |

---

## 내부 유의 사항 (발송하지 않음)

- **동판 이관 가능 여부는 지금 묻지 않음.** 이관을 문의하는 순간 다른 업체로 옮길 뜻이 있다는 신호가 됨. 오원색 견적을 받아 비교한 뒤, 실제 전환을 검토하는 단계에서 문의함
- **오원색 견적을 병행 중이라는 사실을 먼저 밝히지 않음.** 현 시점 요청은 「표시사항 수정에 따른 재견적」이라는 명분으로 충분함
- 태백비닐 유지 시 동판이 수정 수준이라 비용이 들지 않는다는 점은 우리 쪽에 유리한 조건이나, 이를 근거로 단가 인하를 요구하는 것은 오원색 견적을 확보한 뒤에 함
