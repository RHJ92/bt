# 디자인 시안 2차 검토 (2026-09-09)

검토 대상은 2026-09-09 수령한 2차 시안 — `reference/시안_260909/`. 9/9 발송한 2차 수정 요청 5개 항목과 대조함.

**요청 4건 전부 반영됨. 다만 김부각 원재료명에서 쉼표 1개가 새로 빠졌고, 김부각 AI 원본 파일이 갱신되지 않았음.**

## 2. 새로 발견한 것

### 김부각 원재료명 — 설탕 뒤 쉼표 누락

```
현재 : ... 김(국내산) 38%, 설탕(원당 100%) 천일염(국내산), 건새우(국내산) ...
수정 : ... 김(국내산) 38%, 설탕(원당 100%), 천일염(국내산), 건새우(국내산) ...
```

1차 때 고추부각에서 났던 것과 같은 유형의 실수가 이번엔 김부각으로 옮겨 왔음. 고추부각은 고쳐졌고 김부각에서 새로 빠짐. 줄바꿈 위치와 겹쳐 있어 눈에 잘 띄지 않으니 확대해 확인할 것.

### 고추부각 — 콜론 뒤 띄어쓰기 불일치 (경미)

같은 면 안에서 표기가 갈림.

| 위치 | 현재 |
|---|---|
| 옥수수전분 | 옥수수(외국산 **:헝**가리 … — 콜론 뒤 붙임 |
| 옥수수기름 | 옥배유(외국산 **: 헝**가리 … — 콜론 뒤 띄움 |

법적 문제는 아니나 같은 라벨 안에서 다르면 어색함. **1차 시안에도 동일하게 있었으나 1차 검토에서 잡지 못한 건임** — 디자이너가 새로 만든 오류가 아님.

## 3. 파일 이슈 — 김부각 AI 원본이 갱신되지 않음

수령 파일을 1차본과 대조한 결과임.

| 파일 | 1차 대비 |
|---|---|
| 김부각 패키지_앞면.jpg | 변경됨 |
| 김부각 패키지_뒷면.jpg | 변경됨 |
| 고추부각 패키지_앞면.jpg | 변경됨 |
| 고추부각 패키지_뒷면.jpg | 변경됨 |
| 고추부각 패키지.ai | 변경됨 |
| **김부각 패키지.ai** | **1차 파일과 완전히 동일** (MD5 일치, 타임스탬프도 9/8 그대로) |

JPG는 수정본인데 AI만 1차 파일이 그대로 왔음. **인쇄에 넘기는 최종 파일은 AI이므로 이대로 발주하면 수정 전 도안이 찍힘.** 3차 회신 때 김부각 AI를 반드시 다시 받을 것.
