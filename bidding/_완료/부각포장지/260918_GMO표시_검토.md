## 1. 통화 요지 (STT 정리)

- 옥수수전분뿐 아니라 **튀김 기름(옥수수기름)도 옥수수 원료**임
- 옥수수유 공급업체 확인 결과, 예전에는 수입 원료가 유통 과정에서 GMO/Non-GMO 구분이 안 돼 표기를 못 했으나 **「올해 말부터 식용유도 GMO 표기」** 하라고 들었다고 함
- 공급업체 옥수수가 **GMO**라고 함
- 그래서 **「고추부각은 Non-GMO가 아니라 GMO로 표기돼야 할 것 같다」**는 의견
- 앞서 받은 「옥수수전분은 Non-GMO」 답변과 겹치는 부분 — 통화의 GMO 언급은 **옥수수기름 공급업체의 옥수수**에 관한 내용으로 읽힘. 전분과 기름을 구분해 서류로 확정할 것

## 2. 법령 현황

**현행 「유전자변형식품등의 표시기준」** — GMO 원재료를 썼더라도 **최종 제품에 유전자변형 DNA·단백질이 남아 있을 때만** 표시 의무 (식품위생법 제12조의2 단서)
- 고도 정제로 DNA가 없는 **식용유·간장·당류는 표시 제외**
- 비의도적 혼입 3% 이하 + 구분유통증명서·정부증명서·검사성적서 보유 시 표시 제외
- 표시 방법: 주표시면에 「유전자변형식품」「유전자변형 ○○ 포함 식품」, 또는 원재료명 바로 옆 괄호로 「(유전자변형)」「(유전자변형된 ○○)」. GMO 여부를 확인할 수 없으면 「유전자변형 ○○ 포함 가능성 있음」

**GMO 완전표시제 (고시 개정안, 2026-02-27 행정예고)**
- DNA가 남지 않아도 표시하도록 확대. 표시대상 품목은 식품유형 기준으로 **간장 / 당류 / 식용유지류** 3개
- 시행: 간장 **2026-12-31**, 당류·식용유지류 **2027-12-31**
- 2026-09-18 현재 확정 고시 여부는 확인되지 않음 (의견제출 2026-04-30 마감 후 후속 절차 중으로 보도됨)
- 농어업·농어촌특별위원회 GMO 표시제 TF(2026-04-10)는 **두유·두부·소스류 추가, 전체 24개 식품군 단계적 확대 로드맵**, 비의도적 혼입치 3% → **0.9%** 하향을 권고함

## 3. 우리 제품 적용

| 원재료 | 해당 제품 | 현행 기준 | 완전표시제(개정안) | 판단 |
|---|---|---|---|---|
| **옥수수기름(옥배유)** | 김부각·고추부각 | 정제유로 DNA 없음 → **표시 대상 아님** | 표시대상은 **식품유형이 「식용유지류」인 제품**(공급사의 옥배유 제품 자체). 우리 부각은 「기타가공품」이라 **대상 아님** | **표시 불필요** |
| **옥수수전분** | 고추부각만 | 전분은 DNA가 남을 수 있어 **GM이면 지금도 표시 대상** | 변동 없음 | **Non-GMO 증빙이 있으면 불필요, 없으면 표시 필요** |

- 대표님 말씀 「식용유도 올해 말부터 표기」 = **옥배유 공급업체가 자기 옥배유 제품에 GMO 표시를 하게 된다**는 내용. 시기는 개정안상 2027-12-31(올해 말 시행은 간장)
- 김부각은 옥수수 원료가 옥배유뿐이라 **현행·개정안 모두 GMO 표시 불필요**
- 고추부각에 GMO 표시가 필요한 경우는 **옥수수전분이 GM일 때**임. 대표님 판단이 맞는지는 전분 원료에 달림

## 4. 조치

| # | 조치 | 누구 | 시점 |
|---|---|---|---|
| 1 | **옥수수전분 원료의 GM 여부 + 구분유통증명서(또는 정부증명서·GMO 불검출 검사성적서) 사본 요청** | 손수식품 | **디자이너 발송 전** |
| 2 | 1번 결과가 Non-GMO + 서류 확보 → 이번 디자이너 요청에 GMO 항목 추가 없음 | — | — |
| 3 | 1번 결과가 GM 또는 서류 없음 → 고추부각 원재료명 수정 추가: 「옥수수전분[옥수수(외국산 : 헝가리, 세르비아, 러시아 등), **유전자변형 옥수수 포함**]」 (확인 불가 시 「유전자변형 옥수수 포함 가능성 있음」) | 디자이너 | 이번 요청에 합쳐서 |
| 4 | 완전표시제 확정 고시 및 **기타가공품 확대 시기** 모니터링. 포장지 사용기간(~2028년 하반기)과 겹칠 수 있음 → 대상 편입 시 유예기간 내 포장 변경 | 구매팀 | 2027 상반기 재확인 |
| 5 | 「Non-GMO」·「비유전자변형」 강조 표시는 하지 않음 (현행 0% 기준, 서류 부담 큼) | — | — |

## 5. 보충 (2026-09-18 추가 질의)

**「옥수수기름도 2027년부터 표기 의무」에 대해**
- 2027-12-31부터 의무가 되는 대상은 식품유형이 「식용유지류」인 제품(공급업체의 옥배유 자체). 개정안 제3조제2항은 간장류·당류·식용유지류를 식품유형으로 열거함
- 우리 부각(기타가공품)이 옥배유를 원재료로 쓴다고 해서 표시 의무가 생기지는 않음 — 개정안 기준
- 단 확정 고시 전이고 정부 TF가 전체 식품군 확대를 권고한 상태 → 포장지 사용기간(~2028 하반기) 중 범위 확대 가능성 있음. 2027 상반기 확정 고시 확인

**「Non-GMO 서류가 없으면 무조건 『포함 가능성 있음』?」에 대해**

| 원재료 | 서류 없을 때 |
|---|---|
| 옥수수기름 | 표시 불필요 (현행 기준 표시대상 아님) |
| 옥수수전분 | 구분유통증명서 / 정부증명서 / **GMO 검사성적서(식품위생검사기관)** 중 하나 있으면 면제. 셋 다 없으면 표시 — GM 확인 불가 시 「유전자변형 옥수수 포함 가능성 있음」, GM 확실 시 「유전자변형 옥수수 포함」 |

- 권장 순서: ① 손수식품에 전분 구분유통증명서 요청 → ② 없으면 고추부각(또는 전분) GMO 검사 의뢰 → ③ 둘 다 불가 시 문구 표시
- 옥배유에 「유전자변형 옥수수 포함」을 선제 표시하는 것은 사실에 부합하면 위법은 아니나 의무 아님. 소비자 인식상 불리해 현재는 넣지 않고 2027 상반기 확정 고시 확인 후 판단하기로 권고

## 6. 결정 (2026-09-18)

- 손수식품 확인 결과 **옥수수전분 Non-GMO** → 고추부각 GMO 표시 불필요
- 옥수수기름은 현행 기준 표시대상 아님 → 두 품목 모두 **GMO 관련 문구 없이 인쇄 진행**
- 남은 일: 손수식품에서 **옥수수전분 구분유통증명서 최신본 사본 수령·보관** (로트 변경 시 갱신) / 2027 상반기 완전표시제 확정 고시·범위 재확인
