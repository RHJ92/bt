각 1,000개 발주 기준 절감액 — 국그릇 350,000원 / 김치찜 접시 4,300,000원. 발주금액(VAT 별도)은 국그릇 5,950,000원 · 접시 2,350,000원.

**거래조건** — MOQ 100개 / 납기 영업일 7일 / 포장 국그릇 80ea·접시 100ea per Box / 명화주방 보관 후 주문 시 **착불택배** 출고 / **1,000개·2,000개 단가 동일(수량 할인 없음)**

**샘플 검토 결과 (2026-10-01)** — 운영팀(서지윤 과장) 확인 완료. 기존 각인품을 쓰는 운영 매장에서 혼재 가능성은 있으나 식기류는 신규 오픈점 초도 주문에 집중되므로 **도입 문제 없음**. 국그릇 깊이 차이(H45 → H36) 건은 이것으로 해소.

**소재 확정 (2026-10-02)** — 명화주방 회신으로 **전 품목 SUS 304** 확인. 견적서 시트명 「SUS 201」은 표기 오류이며 기존품과 같은 소재임.

**주문·납기 조건 조정 (2026-10-02)** — **각 1,000개 선결제 → 선생산 → 명화주방 보관 → 주문 즉시 출고.** 매 주문마다 7영업일을 기다리지 않고, 삼보물류 입고 단계도 생략됨. 대신 대금 9,130,000원(VAT 포함)이 먼저 집행되고, **보관분은 당사 소유 재고이므로 통합 재고관리 파일에 로트 등록·월말 대사 대상에 포함해야 함**.

**남은 절차** — 옥된장 **로고 각인 샘플** 1회 확인 → 이상 없으면 **매입 확정**

그 외 확인사항(레이저인쇄=로고 여부, 착불 부담 주체, 보관 조건, 접시 단가 하락 사유, 접시 판매가 재검토, 출고처 전환 시점)은 견적비교 파일 「3.확인사항」 시트에 정리.

**샘플** — 당사 실물 샘플 9/21 발송 / 명화주방 샘플 수령(10/1 대조 완료). 측면 대조에서 명화 국그릇이 유진·현대기물보다 눈에 띄게 얕음을 확인 — 견적 H36 표기와 일치.
