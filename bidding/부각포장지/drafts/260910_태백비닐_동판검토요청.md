# 태백비닐 동판 검토 요청 (2026-09-10)

기존 생산처인 태백비닐에 도안 변경 내용을 전달하고, **동판 비용을 최소화하는 방향으로 검토·제안**을 요청하는 건. 첨부는 `reference/수정표기/260910_부각포장지_동판수정위치_4면.pdf`.

---

## 1. 왜 이렇게 묻는가

전면과 후면의 변경 성격이 다르다.

| 면 | 변경 성격 | 동판 관점 |
|---|---|---|
| 전면 | 텍스트 **추가**만 (영문명, Made in Korea, 고추부각 열량 수정) | 기존 레이아웃 그대로라 부분 수정 가능성이 높음 |
| 후면 | 텍스트 수정 + **배열 변경** | 부제 2줄이 빠지면서 표시사항 표가 위로 올라감. 판을 다시 떠야 할 수 있음 |

후면 배열이 바뀐 원인은 **제품명 아래 부제 2줄 삭제** 하나다. 이것만 되돌리면 후면 변경은 「텍스트 일부 교체 + HACCP 마크 추가」로 줄어든다.

**원재료명 줄 수는 두 품목 모두 현행과 같은 4줄**이므로, 부제만 되살리면 표 위치·크기가 현행과 동일해진다. 텍스트 교체 수준으로 처리될 여지가 있다는 뜻이다.

---

## 2. 물어볼 것 4가지

| 번호 | 질문 | 의도 |
|---|---|---|
| 1 | 후면처럼 배열이 바뀌면 기존 동판 수정이 가능한가, 신규 제작해야 하는가 | 가능 여부부터 확정 |
| 2 | 수정 동판과 신규 제작의 비용 차이 | 판단 근거 확보 |
| 3 | 후면 배열을 현행 유지하고 텍스트 수정 + HACCP 마크만 반영하면 최소 비용으로 되는가 | **핵심 질문.** 도안을 되돌릴지 결정하는 근거 |
| 4 | 도수별로 어느 판을 다시 떠야 하는가 | 신규 색상은 없고 HACCP 마크만 청록·노랑 2색 |

## 3. 발송용 문안

```
안녕하세요, 블루트렌드 류호정입니다.

옥된장 김부각·고추부각 포장지 도안을 수정하게 되어 동판 검토를 요청드립니다.
첨부 PDF에 현행과 수정안을 나란히 놓고 변경 위치를 표시해 두었습니다.
(빨간색 = 변경·추가된 부분, 파란색 = 현행에는 있으나 수정안에서 빠진 부분)

■ 변경 성격

· 전면 — 텍스트 추가만 있습니다
   - 영문 제품명 2줄 추가 (Gim Bugak / Gochu Bugak)
   - Made in Korea 문구 추가
   - 고추부각만 열량 표기 416 → 415kcal 수정
   레이아웃과 사진·로고는 그대로입니다.

· 후면 — 텍스트 수정에 더해 배열이 바뀝니다
   - 제품명 아래 부제 2줄이 빠지면서 표시사항 표가 위로 올라갔습니다
   - 원재료명 문구 변경 (고추부각은 원재료 표기 순서도 변경)
   - 영양정보 수치·단위 수정 (나트륨 g → mg 등)
   - 제조시설 문구 수정
   - HACCP 마크 신규 추가 (청록·노랑 2색)

■ 검토 요청

1. 후면처럼 배열이 바뀌는 경우, 기존 동판 수정으로 반영이 가능한지
   아니면 동판을 새로 제작해야 하는지 알려주시기 바랍니다.

2. 수정 동판으로 되는 경우와 신규 제작하는 경우의 비용 차이가
   어느 정도인지 알려주시면 판단에 참고하겠습니다.

3. 만약 후면 배열(부제 2줄과 표 위치)을 현행 그대로 두고
   텍스트 일부 수정과 HACCP 마크 추가만 반영한다면,
   최소 동판 비용으로 해결이 가능한지도 함께 봐주시기 바랍니다.
   비용 차이가 크다면 저희가 도안을 그 방향으로 되돌릴 생각입니다.

4. 도수별로 어느 판을 다시 떠야 하는지도 알려주시면 좋겠습니다.
   신규 색상 추가는 없고, HACCP 마크만 청록·노랑이 들어갑니다.

■ 요청드리는 방향

어느 쪽이든 동판 비용을 최소화하는 기준으로 검토해 주시고,
가장 유리한 안을 제안해 주시면 그에 맞춰 도안을 조정하겠습니다.

납품은 12월 중순 입고를 목표로 하고 있습니다.
발주부터 납품까지 소요일도 함께 알려주시면 감사하겠습니다.

감사합니다.
```

## 4. 회신 후 분기

| 태백비닐 회신 | 우리 조치 |
|---|---|
| 후면도 수정 동판으로 가능, 비용 미미 | 현재 확정 도안 그대로 진행. 부제 삭제는 디자이너에게 의도 확인만 |
| 신규 제작 필요, 비용 큼 / 배열 유지 시 최소 비용 | **부제 2줄을 되살리는 방향으로 도안 수정 요청.** 디자이너 재작업 1회 발생하나 동판비를 아끼는 편이 유리 |
| 어느 쪽이든 전판 재제작 | 오원색과 조건이 같아지므로 순수 단가 경쟁으로 전환. 이관 가능 여부도 이때 문의 |

---

## 5. 내부 메모

- 3번 질문이 이번 요청의 핵심임. 부제 삭제는 우리가 요청한 적 없는 변경이므로 되돌려도 잃는 것이 없고, 그것만으로 동판비가 크게 줄어든다면 되돌리는 편이 낫다
- 회신 내용은 오원색 견적과 비교할 기준값이 됨. 오원색은 6도 전판 신규 제작이라 태백비닐 유지 시 비용 격차가 그대로 전환 장벽이 됨
- 동판비를 단가에 녹여 받지 않도록, 회신은 반드시 **별도 금액**으로 받을 것
- 이 건 회신 전까지 디자이너에게 부제 관련 재작업을 요청하지 말 것 — 방향이 정해진 뒤 한 번에 처리
