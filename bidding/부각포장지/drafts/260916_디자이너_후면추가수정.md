# 디자이너 전달 — 후면 추가 수정 (2026-09-16)

도안 마지막 수정 건. **후면 바코드·마크 배치 정리 1건**이며, 이것으로 도안을 확정함.

## 확정된 전제

| 항목 | 상태 |
|---|---|
| 후면 부제 2줄 | **삭제 확정** — 현 시안대로 두고 되살리지 않음 |
| 표시사항 수정 7건 | 3차 시안에서 전부 반영 완료 |
| 생산업체 | 태백비닐 확정 (2026-09-16) |
| 남은 수정 | 후면 바코드 축소 + HACCP·비닐류 마크 위로 이동 |

## 왜 고치는가

현재 HACCP 마크와 비닐류(OTHER) 마크가 후면 오른쪽 아래 접지면 쪽 구석에 떨어져 있어, 영양정보·바코드와 따로 노는 느낌임. 바코드를 줄여 생긴 공간만큼 두 마크를 위로 올려 한 덩어리로 정리함.

접지면·실링선에 가까우면 인쇄나 접힘 과정에서 마크가 눌리거나 잘릴 수 있다는 실무적 이유도 있음.

## 규격 제약 — 줄일 때 지켜야 할 선

| 항목 | 기준 | 근거 |
|---|---|---|
| 바코드 | 표준 3.73×2.63cm / **최소축소치 3.0×2.1cm**, 최소축소치에서 세로는 1.8cm까지 | 라코 바코드 등록 안내. GS1 허용 배율 80~200% |
| 분리배출 마크 | 가로·세로 각 **8mm 이상** | 환경부 「분리배출 표시에 관한 지침」 법정 최소 크기 |
| 표시사항 글씨 | **10포인트 이상, 장평 90% 이상, 자간 -5% 이상** | 식품표시광고법 시행규칙 별표3. 공간 확보하려고 줄이면 위반 |

분리배출 마크 위치는 지침상 「정면·측면 또는 바코드 상하좌우」이므로, 바코드 옆·아래로 붙이는 배치는 규정에 부합함.

### 바코드 — 세로를 얼마나 줄일 수 있는가 (2026-09-16 조사·실측, 라코 기준 반영)

> **이 절은 내부 근거용임.** 디자이너에게는 표준규격·최소축소치·세로 하한 1.8cm·좌우 여백 4가지만 전달하고, 실제 크기 결정은 디자이너 판단에 맡김. 구매팀이 도안 파일을 세부 검증할 수 없으므로 배율·mm 단위 지시는 전달 범위를 넘음.

**기준 출처**

- GS1 표준 사용자 매뉴얼(gs1kr.org) — 절단(세로만 축소)은 「표준 크기 인쇄가 불가능할 때만」 허용되는 예외이며, 하한값은 공표하지 않음
- 라코 바코드 등록 안내(lako.co.kr/customer/barcode_regis.php) — **「EAN코드의 배율은 가로와 세로가 비례하여 확대·축소되어야 하는 것은 아니며, 최소 축소치에서 세로의 길이는 1.8cm까지 사용 가능(권장사항)」**
- 두 기준은 충돌이 아니라 보완 관계임. GS1이 비워 둔 절단 하한을 국내 대행기관이 1.8cm로 명시해 준 것임. **세로 축소는 근거 안에서 가능함**

**표준 치수 (여백 포함, 라코 기준)**

| 배율 | 가로 | 세로 |
|---|---|---|
| 200% 최대확대 | 7.46cm | 5.26cm |
| 100% 표준 | 3.73cm | 2.63cm |
| 80% 최소축소 | 2.98cm (라코 표기 3cm) | 2.10cm |
| 80% + 세로 최대 축소 | 2.98cm | **1.8cm (권장 하한)** |

**현행 실측값 (디자이너 제공, 일러스트레이터 변형 패널)**

| 항목 | 실측 | 100% 표준 | 환산 |
|---|---|---|---|
| 바 부분 폭(여백 미포함) | 39.341mm | 31.35mm | **125.5%** |
| 여백 포함 폭 | 46.58mm | 37.29mm | 124.9% |
| 전체 높이(숫자 포함) | 26.276mm | 26.3mm | **100%** |

- **현행은 세로가 표준 100% 그대로이고 가로만 125%로 늘려 놓은 상태임.** 폭 대비 비율로는 81%에 해당하나, 절대 높이는 정상임
- 폭 차이 7.24mm는 좌우 여백(quiet zone)이며 규정값(125% 기준 7.46mm)과 거의 일치함 — 여백은 정상임
- 세로 차이 4.36mm(30.631 − 26.276)는 여백이 아니라 바깥 테두리 사각형의 위아래 여유임. EAN-13에 세로 여백 규정은 없음

**축소안 3가지 — 디자이너 전달용**

| 안 | 가로(여백 포함) | 가로(바만) | 세로 | 현행 대비 확보 | 판독 |
|---|---|---|---|---|---|
| 현행 | 4.66cm | 3.93cm | 2.63cm | — | — |
| **① 85% 비례** | **3.17cm** | **2.66cm** | **2.24cm** | 가로 1.49 / 세로 0.39cm | 최상 |
| **② 80% 비례** | **2.98cm** | **2.51cm** | **2.10cm** | 가로 1.68 / 세로 0.53cm | 양호 |
| **③ 80% + 세로 축소** | **2.98cm** | **2.51cm** | **1.8cm** | 가로 1.68 / **세로 0.83cm** | 전방향 저하 |

**적용 순서 — ② 우선, 자리 부족 시 ③**

- ③이 국내 권장 기준상 세로를 가장 많이 줄이는 한계치임. 세로 0.83cm가 비는데, 8mm 마크 하나가 통째로 들어갈 높이임
- ③은 **가로를 반드시 최소축소치(80%)까지 먼저 줄인 상태**여야 함. 라코 문구가 「최소 축소치에서」를 전제로 하므로, 가로를 안 줄이고 세로만 1.8cm로 깎는 것은 근거 밖임
- ③은 계산대에서 방향 상관없이 읽히는 성능이 떨어짐. 29,500매 = 2년치 건이므로 ②로 배치가 해결되면 ②를 쓸 것
- 세로 1.8cm 미만은 어느 기준으로도 근거가 없음. 절대 하한임

**반드시 지킬 것**

- 바코드 **좌우 밝은 여백은 반드시 인쇄**되어야 함 — 판독기가 여백으로 바코드의 시작·끝을 인식함. 80% 기준 좌 2.90mm / 우 1.85mm
- 바깥 **테두리 사각형이 이 여백 안으로 들어오지 않게** 할 것
- **코너마크는 인쇄 불필요** — 바코드 원판(필름마스터)에 표시되는 것일 뿐임
- 숫자(HRI)는 EAN-13 필수 요소라 삭제 불가함
- 치수 확인은 **테두리 사각형을 뺀 바코드 아트만 선택**한 상태에서 할 것. 현행 46.58 × 30.631은 테두리까지 잡힌 값임

## 회신 후 처리 순서

1. 디자이너 수정본(AI + JPG) 수령 → 확정 도안과 대조
2. **수정 AI를 태백비닐에 전달** → 태백비닐이 교정 시안 재발행
3. 교정 시안 확인 후 OK → 동판 작업 → 인쇄

> 태백비닐이 이미 교정 시안을 보내온 상태이므로, 디자이너 수정본만 받고 끝내면 안 됨. **반드시 태백에 다시 넘겨 교정 시안을 새로 받을 것.** 2차 시안 때 JPG는 수정본인데 AI만 이전 버전이 온 전례가 있어, 인쇄에 넘어가는 파일이 최종본인지 실물로 확인해야 함.

## 함께 확인할 것

- 현재 원재료명이 빽빽해 보임. 디자이너에게 **현행 글씨 크기·장평이 법정 기준 안에 있는지** 함께 확인받으면 이번에 한꺼번에 정리됨
- 29,500매는 김부각 1.6년·고추부각 2.0년치임. 도안이 틀리면 2년간 그대로 유통되므로 교정 시안 단계에서 마지막으로 전수 대조할 것
