## 3. 영문 표기 — Gim으로 확정

손수식품에서 「김」의 영문 표기를 Kim이 아니라 **Gim**으로 확인해 보라는 의견을 줬고, 확인 결과 **Gim이 맞음**.

| 근거 | 내용 |
|---|---|
| 로마자 표기법 | 문화체육관광부 고시 「국어의 로마자 표기법」상 어두의 ㄱ은 g로 적음. 따라서 김 = **gim**. Kim은 사람 이름에 한해 관용 표기를 허용한 예외이며 식품명에 적용할 근거가 아님 |
| 정부 정책 | 해양수산부가 김 수출 표준 영문 명칭을 **Gim**으로 통일해 사용 중. 일본 nori, 중국 haitai와 구분해 한국 김을 고유명사로 세우려는 방향 |
| 업계 흐름 | 손수식품도 같은 판단으로 전환 중 |

**반대 논거는 소비자 인지도 하나뿐임.** 해외 소비자에게 Gim은 낯설지만, 이는 설명 문구 병기로 해결됨. 손수식품도 `SonSooGo Crispy Rice Seaweed Chips`처럼 설명형을 함께 썼음.

### 확정 표기안

| 구분 | 표기 |
|---|---|
| 브랜드 | **Okdoenjang** — 된장이 국제적으로 doenjang으로 통용되므로 일관됨 |
| 김부각 | **Gim Bugak** (설명: Crispy Seaweed Chips) |
| 고추부각 | **Gochu Bugak** (설명: Crispy Pepper Chips) |

부각은 로마자 표기법상 bugak, 고추는 gochu임(고추장이 gochujang으로 통용되는 것과 일관).

**정부 자료 직접 확인 완료 (2026-09-07)** — 해양수산부 「김 산업 경쟁력 강화방안」(2024-10-31)에서 K-김·GIM 통일 방침을 밝혔고, 2025년 11월 제48차 CODEX 총회에서 김 규격 신규작업이 승인될 때도 공식 영문 명칭으로 Gim을 사용함. 로마자 표기법(김포 Gimpo, 김해 Gimhae)과도 일치함. **확정안 그대로 진행.**

## 5. 확정 전 남은 조건

- 김부각 원재료 순서 — 손수식품 품목제조 변경보고 처리 완료 확인 후

- HACCP 마크 — 파일 확보 완료. 단 손수식품 인증서에 김부각·고추부각이 인증 품목인지 확인 후 사용
- 할랄 마크 — 제외 확정. 할랄 인증은 품목별 등록제이며 옥된장 부각 2종은 등록 품목이 아니어서 사용 불가
