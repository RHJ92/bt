## 4. 판단

**① 9월 결품 위험 — 김부각.** 9/1 재고 105박스로 9/29 입고까지 28일을 버텨야 하는데 추석(9/25) 성수기가 겹침. 명절 시나리오에서 9/28 잔여가 15박스까지 떨어짐. 입고가 며칠만 밀려도 결품이므로 9/29 입고일 확약을 먼저 받아둘 것. 포장지가 아니라 완제품 생산 일정 문제임.

**② 발주 데드라인은 고추부각이 잡음.** 총 가용량 소진이 김부각 2027-03, 고추부각 2027-01로 두 달 빠름. 고추부각 소진 시점이 2027년 설(2/6) 직전이라 실제로는 더 당겨짐. 두 품목을 한 번에 묶어 발주하는 편이 유리하므로 일정은 고추부각에 맞춤.

**③ 역산 일정.** 11월 중순 견적 마감·업체 선정 → 11월 하순 발주 → 12월 중순 포장지 입고. 고추부각 완제품이 12/8~12/21에 바닥나고 그때부터 포장지 잔여 1,400장(70박스분)으로만 버티기 때문임.

**④ 발주 수량 기준.** 연간 소요는 김부각 927박스(18,540장 ≈ 9.3박스), 고추부각 743박스(14,860장 ≈ 7.4박스), 합계 33,400장임. 업체별 MOQ·수량 구간 단가를 연간 1회 발주와 반기 2회 분할 두 가지로 받아 비교함.

## 5. 표시사항·사양 수정 7건

1~6번은 2026-08-27 손수식품 윤슬기 상무 협의분, 7번은 자체 발견 사항임.

| 항목 | 수정 내용 | 근거 | 상태 |
|---|---|---|---|
| 1. Made in Korea | 전면 또는 후면에 문구 추가 | 수출 대비. 손수도 이번 변경 때 추가 | 반영 확정 |
| 2. 돼지고기 문구 삭제 | 제조시설 공유 문구에 돼지고기가 있으면 삭제 | 돼지고기 표기 시 인도 수출 제한 | **해당 없음** — 현행에 돼지고기 없음 (9/4 확인) |
| 3. 알레르기 표시 | 「함유」 표시는 현행 유지. 제조시설 공유 문구만 「새우, 밀」로 통일 | 같은 라인에서 김부각(새우)·고추부각(밀)을 함께 생산 | **확정** (2026-09-07) |
| 4. HACCP·할랄 마크 | **HACCP만** 추가 | 할랄은 품목별 등록제이며 옥된장 부각 2종은 등록 품목이 아님 | HACCP 반영 확정 / **할랄 제외 확정 (9/9)** |
| 5. 영문 제품명 병기 | 전면 국문명 아래·주변에 Gim Bugak / Gochu Bugak | 수출 대비 | **반영 확정** — 대표 승인 (2026-09-07) |
| 6. 포장지 두께 하향 | 한 단계 얇은 사양으로 샘플 요청 | 실링 온도 200도에도 불량 발생 | 샘플 후 실링 테스트 |

**짚고 갈 것**

- HACCP 마크 — 손수식품이 인증을 취득해 표기 근거가 생김. 인증서 사본으로 김부각·고추부각이 인증 품목에 들어가 있는지만 확인하면 됨. 할랄은 등록 품목이 아니어서 제외 확정(9/9)
- 두께를 낮추면 실링은 나아지나 너무 얇으면 핀홀·유통 중 파손 위험이 생김. 샘플은 실링 테스트와 낙하·적재 확인까지 하고 확정할 것
- 알레르기 통일은 손수 기준을 그대로 옮기면 없는 알레르겐을 표기하는 셈이 됨. 손수에 두 품목 모두 새우·밀로 통일한 이유를 확인한 뒤 판단할 것

## 8. 동판 조건 — 생산처에 따라 갈리므로 견적으로 확인

동판 부담은 어디서 생산하느냐에 따라 세 갈래로 갈림. 현재는 생산처가 정해지지 않아 미리 계산할 수 없으므로, 견적 요청 시 세 경우를 모두 질의해 확인함.

| 시나리오 | 동판 | 견적 시 확인할 것 |
|---|---|---|
| 태백비닐 유지 | 기존 동판을 수정하는 수준이라 동판비가 발생하지 않음 | 수정 범위와 무상 여부를 서면으로 확인 |
| 오색원 신규 제작 | 6도 전판을 새로 제작해야 하므로 동판비가 전액 발생 | 도수별 단가와 총액, 무상 또는 물량 조건부 면제·분할 상각 가능 여부 |
| 태백비닐 동판을 오색원으로 이관 | 이관 가능 여부에 따라 조건이 완전히 달라짐 | 이관 가능 여부, 이관비, 오색원 설비와의 호환 여부 |

- 동판비는 견적서에 별도 항목으로 받음. 단가에 녹여 받으면 업체 간 비교가 되지 않음
- 오색원에는 동판비 무상 또는 일정 물량 발주 시 면제·분할 상각 조건을 먼저 타진함
- 동판은 디자인을 다시 바꾸면 죽는 자산임. 이번에 표시사항 7건을 한 번에 반영해 향후 2~3년은 재제작이 없도록 확정하고 발주함
- 실단가가 들어오면 연간 33,400장 기준으로 총원가를 업체별로 비교함

## 9. 진행 순서

1. 손수식품 자료 수령 — 품목제조보고서, 영양성분 검사서 최신본 (요청 완료, 회신 대기)
2. 표시사항 최종안 확정 — 수정 7건 + 검사서 수치 반영. 나트륨은 검사서 값을 mg 단위로 옮겨 적을 것
3. 마케팅팀에 디자인 수정 요청서 전달 → 수정 반영본 수령
4. 확정 디자인으로 양사 견적 요청. 태백비닐도 재견적 대상이며, 동판 조건은 세 시나리오를 모두 질의함
5. 업체 선정 → 발주. 견적 마감 11월 중순, 포장지 입고 12월 중순

## 10. 대표 확인 요청 — 포장지 상품명 영문 표기

**1. 요청 사항**

부각 포장지를 신규 제작하면서 상품명 영문 표기를 함께 반영할지 결정을 요청드림. 견적 마감 11월 중순, 표시사항 확정 10월 내 일정이라 **9월 중 회신**이 필요함.

**2. 판단 근거**

이번에 표시사항 7건을 수정하면서 포장지 도안을 새로 정리함. 영문 표기를 같은 시점에 반영하면 한 번의 개정으로 마무리되고, 이후 별도로 넣으려면 도안을 다시 손봐야 함.

제조사 손수식품도 이번 자사 포장지 변경 때 영문명과 Made in Korea를 함께 반영했으며, 수출을 염두에 두면 지금 넣어두는 편이 좋다는 의견임.

**3. 선택지**

| 안 | 내용 | 적합한 경우 |
|---|---|---|
| A | 이번에 함께 반영 | 수출 검토가 2~3년 내 있는 경우 |
| B | 반영하지 않음 | 영문 브랜드 표기 방향이 정해지지 않은 경우 |
| C | 다음 개정 때 반영 | 수출 계획이 불확실해 검토 시간이 더 필요한 경우 |

A안으로 진행할 경우 브랜드 로마자 표기(옥된장), 제품명 영문(엄마 김부각·엄마 고추부각), 표기 위치를 함께 확정해 주시면 됨.

**참고 — 손수식품 적용 사례**

`reference/img/참고_손수식품_통찹쌀김부각_영문병기.png`

손수식품 「손수고 통찹쌀 김부각」은 국문 제품명 바로 아래에 `SonSooGo Crispy Rice Seaweed Chips`를 한 줄로 병기함. 별도 공간을 만들지 않아 기존 도안의 균형을 유지할 수 있어 「엄마 김부각」·「엄마 고추부각」에도 같은 방식으로 적용 가능함. 이 포장지의 영양정보는 나트륨을 **80mg**으로 표기하고 있어 현행 표기의 단위 오류와 대비됨.

## 11. 영문 표기 확정 (2026-09-07)

대표 승인으로 전면 한글 상품명 아래·주변에 영문 병기가 확정됨. 손수식품이 「김」을 Kim이 아닌 **Gim**으로 확인해 보라는 의견을 줬고, 확인 결과 Gim이 맞음.

| 근거 | 내용 |
|---|---|
| 로마자 표기법 | 문체부 고시 「국어의 로마자 표기법」상 어두 ㄱ은 g → 김 = gim. Kim은 사람 이름 관용 표기 예외일 뿐 식품명 근거가 아님 |
| 정부 정책 | 해양수산부가 김 수출 표준 영문명을 Gim으로 통일. 일본 nori·중국 haitai와 구분해 고유명사화하려는 방향 |
| 업계 흐름 | 손수식품도 같은 판단으로 전환 중 |

| 구분 | 확정 표기 |
|---|---|
| 브랜드 | **Okdoenjang** (된장이 doenjang으로 통용되므로 일관) |
| 김부각 | **Gim Bugak** — 설명 `Crispy Seaweed Chips` 병기 권장 |
| 고추부각 | **Gochu Bugak** — 설명 `Crispy Pepper Chips` 병기 권장 |

반대 논거는 해외 소비자 인지도뿐이며 설명 문구 병기로 해결됨.

**정부 자료 직접 확인 완료 (2026-09-07)**

| 근거 | 내용 |
|---|---|
| 해양수산부 「[김 산업 경쟁력 강화방안](https://www.korea.kr/news/policyNewsView.do?newsId=156657951)」 (2024-10-31) | 일본식 Nori·영어 Seaweed로 불리던 것을 K-김으로 통일해 확산. 코덱스 국제표준도 우리 김 중심으로 추진 |
| 해양수산부 보도자료 「[검은 반도체 김(Gim), 세계 규격 제정을 위한 첫 발](https://www.mof.go.kr/doc/ko/selectDoc.do?docSeq=63810&listUpdtDt=2025-11-07++10%3A00&menuSeq=971&bbsSeq=10)」 (2025-11) | 제48차 CODEX 총회에서 김 규격 신규작업 제안 승인. 공식 영문 명칭 Gim 사용 |

정부가 CODEX 규격 제정까지 밀고 있는 표기라 향후 수출 시에도 정합성이 유지됨. **확정안 그대로 진행.**

## 12. HACCP·할랄 마크 (2026-09-09 확정)

HACCP은 반영, 할랄은 제외로 결론남.

| 구분 | 확보 경로 | 비고 |
|---|---|---|
| HACCP 마크 | [한국식품안전관리인증원 인증마크 페이지](https://www.haccp.or.kr/user/content.do?pageId=PAGE_000000000000158)에서 **이미지파일·AI파일 직접 다운로드** | 5종 중 「HACCP 적용작업장·업소」가 해당분. 색상·크기 조정 가능, 심벌 내부 「식품안전관리인증」 표기 가능. 문의 1599-1102 |
| 할랄 마크 | **사용 불가 — 제외 확정 (9/9)** | 할랄 인증은 품목별 등록제. 손수 공장이 인증을 받았어도 옥된장 부각 2종은 등록 품목이 아니어서 마크를 쓸 수 없음 |

- 향후 수출 등으로 할랄이 필요해지면 손수식품을 통해 해당 품목을 할랄에 등록한 뒤 다음 개정 때 반영해야 함. 그 시점에 동판을 다시 떠야 하므로, 할랄이 필요한 시장 계획이 있다면 미리 판단해둘 것
- 근거 없이 마크를 넣으면 표시광고 문제가 되므로 이번 도안에서는 완전히 제외함
- HACCP 마크는 우리가 받아 넣되, **손수식품 HACCP 인증서에 김부각·고추부각이 인증 품목으로 들어가 있는지**를 먼저 확인할 것. 파일 확보와 사용 자격은 별개임
