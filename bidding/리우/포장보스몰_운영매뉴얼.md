**신규 가맹점 계정 만들기**
1. 로그인 화면 하단 [매장 가입] 클릭
2. 해당 브랜드 코드 입력 → [브랜드 코드 인증하기]
3. 사업자 정보 입력 (세금계산서 발행용) → 가입 후 로그인

**주문·배송 기준**
- 상품 찾기: 로그인하면 브랜드 전용몰이 열림(카테고리별 진열). 검색 없이 좌측 상단 **'전체 카테고리 > 전체 보기'**에서 해당 브랜드 전 품목 확인 가능. 공급가는 상품 화면에 표기(부가세 별도)
- **당일 출고 기준 (가맹점 안내용 단일 규칙): 평일 13시 이전 결제 완료 → 전 품목 당일 출고**
  - 몰 공식 기준은 평일 15시 이전 결제 완료 분 당일 출고, 단 재고 상황에 따라 일부 상품은 13시 이전 결제 분만 당일 출고 — 품목별로 13시/13시 10분/15시가 섞여 있어(출고처 상이, 통합 불가) 가맹점에는 13시로 통일 안내하는 게 안전
  - 기준은 **주문 시각이 아니라 결제 완료 시각** — 가상계좌는 입금 확인 시각 기준이므로 주문만 넣고 입금이 늦으면 당일 출고 불가
  - 주말·공휴일은 출고 없음 (다음 평일 출고)
- 마감 내 주문 → 당일 택배 출고 → 도착 2~5일. 배송 희망일이 있으면 출고일 + 3일로 계산해 발주 권장
- 배송비: 무료 (도서산간은 박스당 추가, 포장보스 공지 참조). 상품은 개별 배송되어 박스별 도착일이 다를 수 있음
- 결제: 선결제 — 보스페이(카드 간편결제) / 신용카드 / 가상계좌 / 충전금. 결제 완료 후 출고
  - 가상계좌: 주문 시점에 임시 가상계좌(예금주 주식회사 리우) 발급 → 입금 확인 후 결제 완료·출고. 입금 기한 내 미입금 시 주문 취소될 수 있음
  - 충전금: 마이페이지 > 충전금 관리 > 전용 가상계좌 발급 후 충전 (1원 단위, 잔액 부족 시 결제 불가)
  - 현금·충전금 결제 시 등록 사업자 정보로 세금계산서 자동 발행

**본사 주문 조회**
- 가맹본부용 링크(관리자) > [주문정보] > "주문자 정보" 컬럼에서 매장별 주문 내역 확인 (가맹점몰 주문 조회에는 매장명 없음)

**공급가 조정 절차**
- 리우는 협의되지 않은 단가를 임의 변경하지 않음. 시장·제조사 단가 변동 시 단가 조정안을 가맹본부(본사)로 먼저 안내 → 본사 검토 후 적용
- 가맹점 공지가 필요하면 본사가 리우에 요청 → 브랜드몰 팝업 등으로 가맹점 안내 병행
- 현재 마진 기준: 전용 냅킨 50,000원 고정 / 물티슈 5% / 그 외 3% (리우가 가맹점 판매 후 본사에 페이백)
- 예정 사항: 옥된장 손잡이봉투 9월 121,000원 동결 → 10월부터 가맹본부가 135,000원 기준 인상 예정 (9월 중 가맹점 안내문 발송 필요)
