# 쌈장 자체 개발 — 해내음 (콩된장 박스 재활용 리뉴얼)

**노션 기록:** https://app.notion.com/p/3fe0bbc5ac2681a69ed6fdeca91f3743 (진행 현황 원본)
**관련 회의록:** https://app.notion.com/p/3f80bbc5ac2681f398a2e23cfa05f9cf (10/13 해내음 통화)

**배경**
- 해내음 '콩이 살아있는 된장'(14kg 업소용) 판매 저조로 운영 중단 결정함
- 14kg 전용 박스 기제작분 소진을 위해 쌈장으로 재개발, 뒷면 한글표시사항 스티커 부착해 리뉴얼 공급 예정
- 담당: 해내음 김지나 팀장(글로벌무역)

**자사 니즈 (해내음 전달분)**
- 블루트렌드 전용 쌈장, 14kg 벌크라 보존 용이성 필수
- 된장·고추장(고춧가루) 맛 비중 높은 쌈장 — 해내음 기존 쌈장 배합 조정 방식도 가능
- 기준 조합: 된장+고추장+마늘+참기름 (참기름은 매장 후첨)
- 관능: 대표님 요청 '집에서 만든 맛'(단맛·조미료 저감), 시판 쌈장 맛은 완전 배제하지 않음

**경과**
- 10/13 카톡·통화 — 개발 요청, 콩된장 발주 중단 통보, 샘플링 선행 합의
- 10/14 해내음 회신 — 스티커 부착 가능, 고춧가루·고추장 함량 추가(더 매울 수 있음), 10/21~22 샘플 발송 → 자사 진행 요청함

**다음**

- 박스 재고 수량 확인, 앞면 제품명(된장)↔뒷면 식품유형(혼합장) 불일치 여부 확인
