# 육직구 시즈닝 전용화 — 단가 검토

배달 삼겹 브랜드 **육직구**의 돼지고기를 가공장 선-시즈닝 완제품으로 전환하는 건.
매장에서 하던 시즈닝을 가공장으로 넘겨 **전용 상품화 → 사입 방지 → 공급가 설계 여지 확보**가 목적.

상대는 **정담(박주효 대표)**. 노션 「회의 정리」 DB에 통화 기록이 3건 있고, 이 건은 2026-08-11 통화가 시작점이다.
※ 같은 정담이지만 **철산장 돼지갈비 양념육**(08-06)·**돼지머리 부산물**(08-07) 건과는 별건.

## 진행 상태 (2026-08-12, 2차 통화 반영)

| 항목 | 상태 |
|---|---|
| 가공 가능 여부 | 확인됨 — 정담 과거 수행 이력 보유 |
| **텀블링** | **불가** — 정담 텀블러 미보유. 보유 설비는 분쇄가공육용 믹서기(정육 투입 시 찢어짐) |
| **시즈닝 형태** | 가루형 **사실상 배제** → **액상 2안**(분무기 도포 / 염지액 충진)으로 축소 |
| 면세 적용 | **불가 판정** (정담 08-12) — 푸로짐 에스의 인산염이 결정적 |
| 견적 | 세절+염지 **9,600원/kg**, 원물 매입가 7,200원 기준 (구이삼겹살 1건만) |
| 액상 염지 원가 | 정담이 별도 반영하기로 함 — 회신 대기 |
| 샘플 | 액상 방식 선택 + 내부 판단 후 진행 |

### 공정 방식 (2026-08-12 2차 통화에서 확정)

**텀블링은 안 하는 게 맞다는 데 양측이 동의했다.** 정담이 설비가 없기도 하지만, 애초에 필요가 없다는 판단이다.
염지액이 아닌 소량 분말이고 원료육이 이미 얇아 겉면 도포만 균일하면 속까지 들어간다. 오히려 텀블링하면 얇은 고기가 찢어진다.
→ 작업은 **수작업 도포**. 작업대에서 살포·혼합 반복, 정해진 투입량을 전량 소진할 때까지 뿌리는 방식.

**가루형은 배제됐다.** 전달한 레시피의 분말 비중이 너무 낮아 균일 도포가 불가능한 수준으로 확인됐다.
남은 선택지는 액상 2안이다.

| 안 | 방식 | 비고 |
|---|---|---|
| ① 분무기 도포 | 액상을 분무기로 살포하며 작업 | 투입량이 극소량인 품목에 써 온 방식 |
| ② 염지액 충진 | 포장 시 염지액을 함께 충진, 매장 해동 중 염지 | 정담 과거 사례 있음 |

삼겹양지(2mm 슬라이스)처럼 얇은 품목일수록 액상이 유리하다.
**도포 균일도가 테스트에서 문제되면 텀블러 보유 업체를 다시 봐야 한다** — 현 시점 조건부 리스크.

## 핵심 숫자

현행 구이삼겹살은 매입 8,000 / 공급 12,000 / **마진 33.3%** 로, 내부 기준인 **축산 마진 상한 15%를 이미 초과**한 상태다.
따라서 시즈닝 전환의 효과는 «현행 실제»가 아니라 «상한을 지켰을 때»와 비교해야 한다.

| | 매입가 | 공급가 | 순마진/kg | 월 순마진(1개점) |
|---|---|---|---|---|
| ② 시즈닝 전 · 마진 15% | 8,000 | 9,412 | 988 | 269,788 |
| ④ 시즈닝 후 · 마진 15% | 9,600 | 11,294 | 1,186 | 323,746 |
| **증감** | +1,600 (+20%) | +1,882 (+20%) | **+198 (+20%)** | **+53,958** |

**마진율 상한이 고정이면 원가를 올리는 것이 곧 마진 확대 수단이 된다.** 시즈닝 전용화가 노린 구조가 이것이다.
다만 상한을 안 지키는 현행(순마진 3,460원)과 비교하면 여전히 큰 폭의 감소라, **어느 쪽을 기준선으로 삼을지가 보고의 핵심**이다.

점주 입장 — 마진 15% 적용 시 공급가 11,294원 + VAT = **12,423원**. 현행 12,000원 대비 +423원(+3.5%).
가맹점이 일반과세자면 매입세액 공제로 실부담은 **11,294원**이라 오히려 인하다.

### 엑셀 구조

`단가검토` 시트 — **파란 셀만 고치면 전체가 자동 재계산**된다.

| 블록 | 내용 |
|---|---|
| [1] 기본 가정 | 수율·물류비율·마진 상한·부가세율·월 사용량 |
| [2] 시즈닝 배합 원가 | 원료 3종 포장단가 입력 → 육류 1kg당 시즈닝 원가 산출 |
| [3] 정담 제시가 역산 | 9,600원에서 원물·시즈닝을 빼 **가공비를 역산** |
| [4] 공급가·마진 시나리오 | 5개 시나리오 비교 |
| [4-1] 실질 효과 | ② 대비 ④ — 같은 마진 상한 조건에서의 증감 |
| [5] 과세 전환 영향 | VAT, 점주 실부담 (일반과세자 vs 간이) |
| [6] 월간 금액 영향 | 1개점·2개점 매입원가 증가액 |
| [7] 6종 확장 | 나머지 5종 견적 오면 원물가·제시가만 넣으면 자동 계산 |

`품목현황` 시트 — 대상 6종의 원산지·브랜드·세절 규격·현행 단가.

## 미확인 — 채워야 할 값

1. **액상 배합 구성** — 가루형이 배제되면서 배합 자체를 다시 설계해야 한다. 엑셀 [2] 블록은 가루 배합 전제로 짜여 있어, 액상 확정 시 구조를 손봐야 한다
2. **수율** — 95% 가정. 정담에 미확인. 90%면 원물원가가 kg당 약 400원 오른다. **원가에 가장 민감한 값**
3. **9,600원의 범위** — 원물 포함가인지 작업비만인지 불명확. 자사 질의는 **원재료비 배제 기준**이었는데 정담은 **원물가 7,200원을 전제로** 답했다. 작업비만 9,600원이면 원물보다 비싸 성립하지 않으므로 **원물 포함으로 가정**했으나 명시 확인이 필요하다
4. **시즈닝 원료 3종 포장단가** — 맛소금(2kg)·후추(1kg)·푸로짐 에스(1kg). 비어 있어 현재 역산 가공비가 과대 표시된다
5. **도포 균일도** — 수작업 도포라 편차가 생길 수 있다. 테스트로 검증해야 한다
6. **월 사용량** — 273kg은 입고량 기준이라 실사용량보다 과대 가능. 재고 대사 후 확정 필요

## 배합비 관련 경과

제작의뢰서(BT-시즈닝-2026-08) 기준 배합은 **맛소금 750g : 후추 1,000g : 연육제 500g**, 투입량은 고기 3kg당 1온즈(약 0.95%).
출처는 **육직구삼겹 차주혁** 제공(2026-08-07 카톡 협의).

포장 단위가 맛소금 2kg / 후추 1kg / 연육제 1kg인데 맛소금만 750g으로 어중간해 **봉 단위 오기 가능성**을 검토했으나,
2026-08-12 확인 결과 **후추 투입량은 맞다**는 답을 받았다(고기에 후추 맛을 강하게 내는 컨셉).
정담도 "후추가 다른 재료보다 훨씬 많이 들어가는 건 통상과 다르다"고 짚었던 부분이라, 이 지점은 정리됐다고 본다.
맛소금 750g의 진위는 여전히 미확인이며, **관능 이슈 발생 시 배합비 제공 측에 확인을 요청**하는 것으로 정리했다.

다만 2차 통화에서 **비율이 아니라 절대량이 문제**로 드러났다. 고기 1kg당 9.45g(0.95%)은 분말을 골고루 묻히기에 너무 적은 양이라는 것이
정담 판단이고 자사도 동의했다. 배합비를 고치는 문제가 아니라 **전달 매체를 액상으로 바꾸는 문제**라는 뜻이며, 이것이 액상 2안으로 넘어간 배경이다.
