# 냉면육수 (카우스토리) — 철산장

철산장 냉면육수 생산처를 **카우스토리**(https://cowstory.com)로 전환하는 건의 실무 협의 거점. 경영진 간 합의만 있고 실무 조건은 미협의 상태에서 시작.

**계약서:** 물품공급계약 초안·수정본·최종본·체결본은 [contracts/카우스토리_철산장육수/](../../contracts/카우스토리_철산장육수/)로 이동 (2026-10-28 싸인오케이 서명 요청, 카우스토리 서명 대기)

## 출발점 (2026-10-14 전달받은 내용)

- 경영진 간 합의: 카우스토리가 철산장 냉면육수 생산
- 제조 방식: **미국산 아롱사태**로 육수를 우리되 살코기가 보존될 정도로만 → 살코기는 냉동해 육수 공급 시 **따로 지급**
- 원물: 카우스토리가 **원물 구매가 공개** → 원물 구매 후 최종 공급가로 공급. **BT 구매력이 더 좋으면 BT가 원물 구매**
- 단가: 카우스토리가 경영진에 **kg당 2,000원** 제시 → 대표님 OK. **조건의 정의(무엇의 kg당인지, 포함 범위)는 실무 미협의**

## 원가 산출 원칙 (사용자 확정 2026-10-14)

육수와 삶은 고기는 **따로 공급**하고, 원육비는 전부 고기에 귀속한다.

- **육수 원가 = 임가공비 2,000원/kg만.** 육수는 고기를 삶으면서 나오는 부산물이라 원육비를 배분하지 않는다. 증발분은 물로 보충해 최초 투입 중량을 맞추므로 육수량은 고정
- **삶은 고기 원가 = 원육 매입가 ÷ 삶은 고기 수율** → 공급가 산출
- 살코기 수율은 고기 원가에만 영향을 주고, 육수 원가에는 영향 없음
- 레시피상 차돌양지가 함께 들어가면 차돌양지 원가도 고기 쪽에 귀속(차돌양지도 고명으로 공급하는지 확인 필요)
조미액은 별개 품목 — 카우스토리 육수가 들어와도 조미액을 계속 쓰는지(육수 + 조미액 배합 구조인지) 확인 필요.

## 미결 쟁점: 아롱사태 원물 구매·수급 책임 (2026-10-14)

- 현 합의: 카우스토리 구매 후 단가 공유 → 비싸면 BT가 카우스토리에 축산 판매 → 점주 공급가 설정
- 문제: 카우스토리 구매 시점에 비싸거나 부족하면 BT도 같은 시장이라 동일. 결국 **옥된장용 비축 재고 출고**로 메우게 되고, 옥된장이 시세 원가로 재매입 → 옥된장 수익 감소
- 선택지: A) BT 전담(철산장+옥된장 분기 사용량 계획 → BT 구매 → 카우스토리 판매) / B) 카우스토리 전담(BT 재고 출고 없음). 건별 비교 후 BT 재고 출고(현 합의)는 부적합
- 대표님 확인 필요 (경영진 합의 내용을 바꾸는 제안)

## 확인된 조건 (2026-10-14 통화, 녹취 txt·노션 회의 정리 DB)

- 2,000원/kg = 생산·포장·배송 + 부재료(파·소주·한우 지방). **원육 별도**
- 레시피(SOP docx): 물 200L 기준 **아롱사태 15kg + 차돌양지 10kg**, 대파·소주. 이후 한우 지방·대파 양만 변동(이정혁 이사). 육수량은 증발분 보충으로 투입 물량과 동일 → 확인할 것은 삶은 고기 수율
- 일정: 을지로점 11/1 납품. 수율 확인용 아롱사태 1박스 BT → 카우스토리 발송, 생산분은 철산장 매장 사용(유상)
- 정산: A) 카우스토리 원물 선매입 후 출고 시 정산(매입처 BT 또는 수입사) / B) BT 원물만 공급 — 내부 검토 후 재소통. 팀장님은 "카우스토리가 BT 원물 매입 → 제때 판매" 의견(철산장이라서), 수율 편차로 입고마다 단가 변동 문제 있어 10/15 재논의
- 부가세(원물 면세 → 육수 과세) 처리 회신 필요

## 생산·수율 기록 양식 (output/)

- `_261019`: 수율·육수 2시트 초안 (미발송 시 폐기 가능)
- `_261020`: 신우미트 가공작업 장부(inventory_management) 방식 반영 — **이력번호로 로트 추적**, 원물 입고·재고(입고 계근 − 투입 누계 = 공장 잔량), 출고 기록(회차·품목별) → 삶은 고기·육수 미출고 잔량 자동 계산. - `_261020` 최종: 3시트 — 원물 입고(검수 중량까지) / 생산·출고(1회 생산 = 1행에 투입·생산·출고·미출고) / 재고 현황(전부 자동)
  - 목적: **입고 물량 대비 생산·출고 수량과 현재고** 확인. 생산 작업 세부(물·부재료·가열)는 업체 자체 관리라 제외
  - 로트: 입고 `AR|CD-입고일-순번`, 생산 `P-생산일-순번`. 원물별 입고 로트 칸 2개(①②)로 혼합 투입 처리, 1입고→여러 생산은 행마다 같은 로트 선택
  - 원물 잔량 = 생산일까지 입고량(검수 우선) − 투입 누계 → 행을 생산일 순서로 입력해야 맞음. 선택 로트의 입고일이 생산일보다 늦으면 점검 「생산일이 입고일보다 빠름」
  - 수율 = 삶은 고기 ÷ 투입 계 (원물별, 생산·출고 K·T열)
  - 출고는 로트별 누계 1칸(분할 출고 시 합계 수정) — 분할 출고가 잦으면 출고 시트 분리 검토
  - 점검: 업체 자체 확인용 — 입고량 초과 투입(원물 전체·로트별), 로트 원물 오선택, 생산량 초과 출고, 누락. BT 확인란 없음. 시트 보호 없음
