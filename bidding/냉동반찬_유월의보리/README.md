**비교 결과 (2026-10-16)**
- 견적 13품목 중 12품목은 가맹점가 × 90% (정확히 10% 할인). 곤드레나물만 11.6% (9,900원 vs 11,200원, VAT 별도)
- 품목명 차이: 건가지나물↔가지나물, 건궁채나물↔궁채나물 — 규격·원산지·보관 동일해 같은 품목으로 매칭
- 견적 미포함 9품목(냉장 8종 + 한우사골미역국)은 노션에 넣지 않음

**10/14 대표님 협의**
- 매입가는 유월의보리 가맹점가 대비 **최소 15% 인하**돼야 거래 가능 → 현재 견적(10%)은 13품목 모두 미달, 품목당 325~490원 추가 인하 필요
- 마켓봄 등록, 혼합 20kg 단위 발주 / 포장 1kg / 택배비 별도(본사 부담), 운송비 차감 후 본사 수익 약 13% 예상
- 옥된장 가맹점 공급가는 유월의보리 가맹점가 범위 내 — 재견적 후 재산출. 옥된장 선택 사용 품목
