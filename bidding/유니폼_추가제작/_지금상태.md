# 유니폼 추가 제작 — 경인양행 (2026-11-06)

**지금 상태**

- 경인양행(안재범) 조건 전부 확인 완료(11/6)
  - MOQ: 단일 품목 100장 / 반팔·긴팔 혼합 150장 / 모자 50개
  - 혼합 불가: 브랜드 간·모자
  - 같은 브랜드는 사이즈별 분할 가능, 단가 직전과 동일, 제작 기간 1주
- 확정 제작안 — 공급가액 2,325,000원(VAT 별도) / 2,557,500원(VAT 포함)
  - 옥된장 혼합 150장: 맨투맨 L50·XL50(14,000) + 반팔 3XL20·2XL15·L15(9,000) = 1,850,000원(VAT 별도)
  - 정백선 모자 50개(9,500) = 475,000원(VAT 별도)
- 석문어 반팔 3XL은 제작 보류(단독 100장 = 61개월분, 제작 1주라 바닥날 때 재판단)

- **11/6 생산계획 엑셀 작성** — `output/261106_옥된장_유니폼_생산계획.xlsx`. 전년 월별 실적으로 다시 보니 맨투맨은 11~1월에만 나가 기존안(맨투맨 L·XL 50씩)은 1년 뒤 226장 남고 반팔 4개 사이즈가 내년 5~9월에 바닥남
  - 데이터 재산출 추천안: 반팔 L50·2XL45·3XL30·4XL10 + 맨투맨 L10·XL5 = 150장, 1,425,000원(VAT 별도) / 1,567,500원(VAT 포함), 1년 안에 바닥나는 사이즈 0개
  - 신규 오픈(캘린더): 안성아양·양평 11/25, NC강서 11/27 미출고 3개점 반영. 12월~2월 오픈 없음

  - 재고통합담당 전달 내용: `output/261106_재고통합담당_전달_유니폼생산기준.md` (슬랙 전달은 사용자)
