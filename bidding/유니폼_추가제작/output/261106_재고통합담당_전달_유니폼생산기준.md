# 재고통합담당 전달 — 유니폼 생산 제안 기준 (2026-11-06, 소싱)

**결정 사항**

- 옥된장 유니폼 추가 생산은 **지금 하지 않음.** 재고가 소진 시점에 가까워지면 재고통합담당이 생산계획을 제안하고, 소싱이 경인양행에 발주함
- 석문어 유니폼은 **한 사이즈라도 재고가 0이 되면(쇼트)** 그때 소싱에 알림 → 소싱이 생산 계획·발주
- 위 두 가지를 통합 재고관리 매뉴얼(`inventory_management/warehouse/kyungin_유니폼/README.md`)에 넣어 주기 바람

**1. 옥된장 — 생산 제안 시점**

- 확인 시점: 매월 월말 대사 후 + 신규 오픈 선분출 신청이 들어올 때
- 제안 조건(사이즈별): **가용재고 ≤ 다음 1개월 예상 출고 + 안전재고**
  - 가용재고 = 경인양행 + 본사창고 − 원장 미반영 출고 확정분
  - 다음 1개월 예상 출고 = **전년 같은 달 출고** + 그달 신규 오픈 소요(옥된장 오픈 캘린더, 지점당 상의 4벌·모자 1~3개)
  - 안전재고 = 최근 1년 중 **가장 많이 나간 달의 출고량**
  - 「최근 3개월 평균」·「겨울 월평균」을 매달 똑같이 적용하지 말 것 — 맨투맨은 11~1월, 반팔은 3~6월에 몰려 소진 시점이 크게 틀림
- 지금 기준으로 가장 먼저 걸릴 사이즈(생산 없이 전년 실적 대입): 반팔 3XL(1월 말 3장 → 3월 소진), 반팔 2XL(1월 말 8장 → 4월), 반팔 L(1월 말 21장 → 4월). 맨투맨 L·XL은 1월 말 10~12장으로 이번 겨울은 넘김
- **정기 판단: 2027년 1월 넷째 주** — 설 연휴(2/7~9) 전에 받아 3월 반팔 시즌을 맞추려면 이때 발주해야 함. 위 조건에 안 걸려도 이 주에 한 번 생산계획을 제안해 줄 것
- 조기 알림: 월말 대사 때 **맨투맨 L 또는 XL 15장 이하 · 반팔 3XL 3장 이하 · 반팔 2XL 8장 이하**면 바로 소싱에 알림(오픈이 몰리는 경우 대비)

**2. 옥된장 — 생산계획 제안에 넣을 것**

- 형식: `bidding/유니폼_추가제작/output/261106_옥된장_유니폼_생산계획.xlsx`를 복사해 파란 칸(월별 출고·신규 오픈·현재고·생산 수량)만 최신값으로 바꾸면 됨
- 사이즈별 필요량 = 다음 1년 예상 출고(전년 같은 달) + 신규 오픈 소요 + 안전재고 − 가용재고
- 제작 조건(경인양행 안재범, 11/6 확인) 안에서 수량을 맞출 것
  - 같은 브랜드 반팔·긴팔 혼합 **150장**(사이즈 분할 가능) / 단일 품목 **100장** / 모자 **50개**
  - **브랜드끼리 혼합 불가, 모자도 유니폼과 혼합 불가**
  - 단가(VAT 별도): 옥된장 반팔 9,000 · 긴팔(맨투맨) 14,000 · 모자 9,500
  - 제작 1주, 입고처는 경인양행 보관
- 제안서에 들어갈 항목: 사이즈별 생산 수량, 금액(VAT 별도·포함 병기), 생산 전후 소진 시점, 1년 안에 바닥나는 사이즈 수
- 참고 — 11/6 기준 추천안: 반팔 L50·2XL45·3XL30·4XL10 + 맨투맨 L10·XL5 = 150장, 1,425,000원(VAT 별도) / 1,567,500원(VAT 포함). 1월에 실제 겨울 출고·오픈 수량을 반영해 다시 산출할 것
- 정백선 모자(재고 16, 8월 이후 출고 0)도 같은 1월 판단 때 함께 볼 것(MOQ 50개)

**3. 석문어 — 쇼트 시 알림**

- 조건: 석문어 유니폼 **한 사이즈라도 가용재고 0** → 소싱에 알림. 그 전에는 생산 제안하지 않음
- 가장 먼저 걸릴 사이즈: **반팔 3XL — 경인 2 · 본사 2 = 4장.** 최근 1년 출고 15장이 1·4·6월에 5장씩 몰려 나감(오픈 때 일괄 출고로 보임). 작년처럼 1월에 나가면 1월 소진
- 쇼트 시 소싱이 할 일: 경인양행에 소량 제작 가능 여부 확인 → 안 되면 단독 100장(950,000원 VAT 별도) 여부 결정. 그 사이 주문은 **2XL(33장) 대체 안내**
- 나머지 석문어 사이즈는 2.5년~수십 년치라 손댈 것 없음
