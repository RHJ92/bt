# 인계 — 한아름오뎅(에스제이푸드) 견적 정리 (2026-11-05)

※ 이 세션의 마지막 작업일은 2026-10-20. 10-20 이후 노션 페이지를 사용자가 직접 고쳤을 수 있으니 이어받을 때 노션 원본부터 확인할 것

**지금 상태**

- 에스제이푸드 견적 3건 정리 완료 — 2024-10-25(봉당 2,400원 VAT 포함) / 2026-10-08 물량 견적(2,750원 VAT 포함 = 2,500원 VAT 별도, MOQ 70박스, 제때 물류센터 입고 운임 포함) / 2026-10-20 택배 견적(3,000원 VAT 포함 = 2,727원 VAT 별도, MOQ 없음, 택배비 포함)
- 대상은 특각(사각어묵)·특세절(채어묵) 2종만. 중대왕·튀김은 검토 대상에서 제외함 (사용자 지시)
- 노션 기록 페이지 작성 완료 — 요약, 인라인 단가 DB(6행), 식봄 시중가 비교, 코주부 참고 견적, 택배 견적 비교, 거래조건, 확인 필요 사항, 근거 자료
- 가맹점 공급가는 제안값 2,900원(VAT 별도, VAT 포함 3,190원)으로 넣어 둠 — 볶음 전용 저가형 품질이라 식봄 저가 어묵(코주부 기획특가 3,200원 VAT 포함)에 맞춤. 미확정
- 마진(공급가 2,900원, 물류비 4.5%): 물량 견적 총 400원(13.8%)·순 270원(9.3%) / 택배 견적 총 173원(6.0%)·순 43원(1.5%)
- 코주부 채어묵 견적(kg 4,800원 VAT 별도, MOQ 1톤)은 단가 차이가 커서 참고 사항으로만 기록함. 단가 DB에는 넣지 않음

**다음 할 일**

1. 에스제이푸드에 택배 견적 조건 확인 — 택배 도착지(제때 물류센터 vs 가맹점 직송), 주문 단위(박스/봉, 특각·특세절 혼합 가능 여부), 리드타임
2. 회신 받으면 노션 기록 페이지 「확인 필요 사항」 갱신. 가맹점 직송이면 택배 견적 2행의 물류비를 0%로 바꿔 순마진 재계산(173원, 6.0%)
3. 공급가 2,900원 확정 여부 결정 → 확정 시 단가 DB 공급가 유지, 변경 시 6행 모두 수정
4. 공급가 확정 후 제때 단가 등록(`price_change/` 절차), 필요하면 가맹점 안내문(`/notice-draft`)
5. 택배 한시 운영 시작 → 초도 입고 때 택배 포장·냉동 상태 확인 → 정착 판단 후 물량 견적(70박스, 2,500원)으로 전환
