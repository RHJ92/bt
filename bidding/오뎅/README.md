- 단가는 2년 사이 봉당 318원(VAT 별도) 인상, 대신 최소발주량은 30박스 줄어듦
- 최소발주 금액은 70박스 × 37,500원 = 2,625,000원 (VAT 포함 2,887,500원)
- 신규 견적서에는 「보관방법(냉동)」「용도(반찬용)」 열이 추가됨
- **견적가는 제때 물류센터 입고까지의 물류비 포함** (2026-10-08 에스제이푸드 확인, 사용자 전달). 매입가에 별도 운임을 더하지 않음. 노션 DB의 물류비 4.5%는 제때 물류 수수료(공급가 기준)로 이와 별개
- **특각·특세절 2종만 다룬다** — 2024-10 견적서에 있던 중대왕·튀김은 검토 대상 아님 (2026-10-08 사용자 지시)
- 신규 견적서 배송지 표기는 「제떼 물류센터」 — 제때 오기로 보임

## 공급가 설정 — 식봄 시중가 기준 (2026-10-08)

**공급가안 2,900원 (VAT 별도, VAT 포함 3,190원)** — 특각·특세절 동일. 제안값이며 확정 전 내부 검토 필요.

- **한아름오뎅은 볶음 용도에 맞춘 저가형 품질** — 탕용 조리 불가. 그래서 공급가는 시중 저가 어묵 가격대에 맞춘다 (2026-10-08 사용자 지시). 최초안 3,300원에서 하향

## 택배 운영 견적 (2026-10-20)

초기 세팅 단계는 운영 편의·소비자 반응에 따라 변화가 많아, **물량 구매(70박스) 전에 택배로 한시 운영**하며 정착 여부를 보기로 함. 주 2~3회 주문 조건으로 문의하고, 택배비를 에스제이푸드가 부담하는 조건의 견적을 요청함 (카톡 10/14~10/20).

| 항목 | 10-08 물량 견적 | 10-20 택배 견적 | 차이 |
|---|---|---|---|
| 단가 (VAT 별도) | 2,500원 | **2,727원** | +227원 (+9.1%) |
| 단가 (VAT 포함, 견적서 표기) | 2,750원 | 3,000원 | +250원 |
| 최소발주량 | 70박스 (1,050봉) | **없음** | 선매입 부담 없음 |
| 배송 | 제때 물류센터 입고 (운임 포함) | 택배발송 (택배비 포함) | |
| 결제 · 리드타임 | 현금 선결제 · 협의 후 결정 | 현금 선결제 · 협의 후 결정 | 동일 |
| 마진 (공급가 2,900원, 물류비 4.5%) | 총 400원(13.8%) · 순 270원(9.3%) | **총 173원(6.0%) · 순 43원(1.5%)** | 순마진 -227원 |

- 공급가 2,900원 유지 시 순마진 1.5%로 얇음. 대신 선결제 약 289만 원(VAT 포함)·재고 위험이 없음 → 정착 확인 후 물량 견적(2,500원)으로 전환하는 전제의 한시 조건으로 봄
- 택배 도착지가 가맹점 직송이면 제때 물류비가 빠져 순마진 173원(6.0%)
- 순마진을 13.8%로 유지하려면 공급가 약 3,164원(VAT 포함 3,480원) — 식봄 저가 어묵(코주부 기획특가 3,200원)보다 높아짐
- 에스제이푸드는 택배 발송이 많지 않고 주로 차량 배송 거래 (10/20 카톡) → 초도 입고 때 택배 포장·냉동 상태 확인
- 노션 단가 DB에 「에스제이푸드 (2026-10 택배 견적)」 2행 추가

- VAT 별도 기준 에스제이푸드 대비 2,300원 높음(약 1.9배). 당사 비딩 중인 견적이 kg 2,500원임을 회신함 (10/12)

## 확인 필요

1. **현행 매입가** — 2024-10 견적가(VAT 별도 2,182원)가 지금까지 실제 매입가였는지, 중간에 조정이 있었는지. 인상 폭 14.6%는 견적서끼리 비교한 값임
2. **최소발주량 70박스 기준** — 품목별 70박스인지, 2종 합산 70박스인지
3. **리드타임** — 2024년 7일 → 이번엔 「협의 후 결정」(택배 견적도 동일). 발주 후 입고까지 일수 확정 필요
3-1. **택배 도착지** — 제때 물류센터 입고인지 가맹점 직송인지 (순마진 1.5% / 6.0% 갈림)
3-2. **택배 주문 단위** — 박스(15봉) 단위인지, 봉 단위·특각·특세절 혼합 가능한지
3-3. **물량 전환 시점** — 택배 운영 기간과 70박스 물량 구매로 넘어갈 기준(월 출고량 등)
4. **인상 사유** — 원재료(연육)·인건비 등 근거 자료 요청 여부
5. **가맹점 공급가** — 제안값 2,900원(VAT 별도) 확정 여부. 기존 공급가가 있는 품목이면 안내문·제때 단가 변경 요청 필요
