# 홍콩 경유 소고기 수출입 — 관세·검역 정리 (2026-07-13 기준)

조사·검토 아카이브용 메모. 미국산·호주산 원물 기준.

## 1. 홍콩은 무관세 맞음 (사실)

홍콩은 자유항(Free Port). 주류·담배·탄화수소유·메칠알콜 4개 품목만 과세하고 소고기 포함 나머지는 관세 0%. 단 이건 **홍콩 자체의 수출입 규정**일 뿐, 상대국(한국)의 관세·검역과는 완전 별개.

## 2. 홍콩 경유 → 한국 재수입

관건은 경유지가 아니라 **원산지(사육·도축국)**. 한국 소고기 수입위생조건은 국가 단위로 농림축산검역본부(QIA)가 개별 승인.

- 홍콩은 소를 사육하지 않음 → "홍콩산 소고기"는 존재하지 않음
- 홍콩 창고를 거쳐도 원산지는 여전히 호주·미국이어야 하고, 위생증명서도 **원산지국 정부기관** 발급본이어야 함
- QIA 등록된 원산지국 도축장·가공장 산출물이어야 통관
- FTA 협정세율 받으려면 **직접운송원칙** 준수 필요 → 홍콩 보세창고 단순 보관·비가공 증명(Non-manipulation Certificate) 있어야 원산지 지위 유지. 못 하면 협정세율 상실, 고율 기본세율 적용

**결론: 미국산·호주산을 홍콩 경유시켜 한국 재수입할 실익 없음. 서류 리스크만 증가. 원산지국 → 한국 직수입이 정석.**

## 3. 한국 → 홍콩 수출 시 관세

- **홍콩 도착 관세**: 원산지 무관 0% (항상)
- **한국 수출관세**: 한국은 수출세 제도 사실상 없음 → 내보낼 때 내는 관세 없음
- 진짜 변수는 **국내 통관 때 이미 낸 관세(매몰비용)**:
  - **미국산**: 2026.1부로 한미FTA 15년 이행 완료 → 관세 **0%** 완전철폐. 재수출해도 매몰비용 없음
  - **호주산**: 한호주FTA 이행 중 → 2026년 협정관세율 **약 5.34%** (2028년 0% 완전철폐 예정, TRQ 초과분은 세이프가드 24%). 정상 유통 재고를 되파는 경우 이 관세는 환급 안 됨(재수출 환급은 하자·오배송 등 계약상이물품에 한정)

**실무 정리**
- 처음부터 홍콩행 확정 물량 → 국내 통관(수입신고 수리) 시키지 말고 **보세창고 유치 상태로 환적/보세운송**으로 홍콩까지. 한국 관세 아예 안 냄. 한국은 순수 물류 경유지 역할
- 이미 국내 통관·유통 중 재고를 홍콩에 파는 경우 → 미국산은 관세 이슈 사실상 없음 / 호주산은 기납부 5%대 관세를 매몰비용으로 원가 반영

## 4. 한우(국산) 수출 트랙 (참고)

수입육 재수출과 별개로 국산 한우 수출은 이미 상용 트랙. 홍콩향 소고기·식용란 수출위생증명서 발급 2023년 177건 → 2024년 315건 → 2025년 385건 증가.

절차: ①검역본부 **수출등록 작업장**(도축·가공장) 확인 → ②관할 지역본부에 **수출검역신청서** 제출(온라인 가능) → ③**수출위생증명서** 발급(민원인 직접 출력 가능하도록 개선됨) → ④홍콩 측 수입자가 FEHD **식품수입업자 등록**(3년 HK$195) + 냉동/냉장육 **수입허가(Import Licence, Cap.60)** 보유, 도축장도 FEHD 인정 소스여야 함

## 출처

- 홍콩 자유항·무관세: 홍콩경제무역대표부, CFS(홍콩 식품환경위생서)
- 한미FTA 소고기 관세 0%(2026): 한국경제·MBC 등 2026.1 보도
- 한호주FTA 소고기 관세율·세이프가드: 관세청 FTA포털, 한호주FTA 상세설명자료
- 한국 수출관세·재수출 환급: 관세청, 관세법
- 한우 홍콩 수출 절차: 한우수출홍보포털(k-beef.or.kr), QIA 수출검역정보
- 홍콩 육류 수입허가: CFS Guide to Import of Game, Meat, Poultry and Eggs / Import & Export Ordinance Cap.60

> 주의: 관세율·이행일정은 조회 시점 기준. 실제 통관 전 관세청 FTA포털·QIA에서 재확인 필요.
