# 작업 MD 개정안 — 공급가 산정 (2026-07-29)

노션 커넥터 재연결 후 「축산품 시장 상황 작업 MD」의 공급가 산정 섹션을 아래로 교체.
근거: 사장님 확인(2026-07-29) — 원물/자체가공/완제매입 3경로, 수율 공식, 유연 마진, 시중가 매칭 규칙.

## 공급가 산정 기준 (3경로)

**① 원물 공급품** (상태=원물, 원물 그대로 공급)
- 예: 아롱사태·소꼬리·스지·미박삼겹·로인립·전지·BBQ립·목전지(원물)·한돈목살(원물)·우삼겹(삼겹양지)
- 원가 = 매입 원물가
- 공급가 = 원가 ÷ 0.825 (총마진 17.5% 목표), 미트박스 동일 스펙 원물 시중가 방어

**② 자체가공품** (축산품가공이력에 기록 — 원물 매입 후 자체 절단/가공)
- 예: 우삼겹슬라이스 (가공이력에 있는 상품이 자체가공)
- 원가 = **(원물가 + 작업비) ÷ 수율**
- 공급가는 시중 세절 상품가에 맞추고, 원가와의 차액을 수익으로 수취

**③ 완제 매입품** (가공이력 없이 가공장 완제를 매입)
- 목록: 목전지 제육용 · 한돈목살 칼집 · 오소리 슬라이스 · 돈두 슬라이스 · 염통 슬라이스 · 절단 소창
- 매입 = 가공장 최종 가공가
- 공급가 = 매입 ÷ 0.825 (총마진 17.5% 목표), 미트박스 세절육 시세 방어

## 마진 원칙

- 총마진 17.5% = **제때(물류) 4.5% + 본사 13%**. 순마진 = 총마진 − 4.5%.
- **고정 아님**: 시장에 물건이 귀해 비싸게 매입하면 17.5%를 다 붙일 때 시중가(미트박스)보다 비싸져 가맹점 사입 위험 → 시중가에 맞춰 마진을 낮춘다.
- 반대로 시세보다 현저히 싸게 매입하면 17.5% 이상으로 운영.
- 품목·시기별로 서로 상쇄해 평균적으로 17.5%를 지향.

## 시중가 매칭 규칙

- 등급·상태·온도 키워드는 판매자가 표기 생략하는 경우가 많아 정확 매칭 어려움 → **브랜드 + 가공장 넘버 + 원산지** 중심으로 매칭.
- 냉장육만 '냉장' 표기가 확실 → **'냉장' 표기 유무로 냉장/냉동 구분**(냉동은 표기 생략 가능).
- 원물/가공을 쌍으로 관리(한돈목살↔칼집, 우삼겹↔슬라이스): 원물은 시세 추적, 가공은 공급가 산정.

## 품목 상태판(마스터) 신설 지표

온도 / 상태(원물·가공) / 품목군 / 원산지 / 브랜드 / 등급 / 마지막 검토일.
→ 시중가 매칭과 산정 경로(①원물/②자체가공/③완제매입) 판별의 기준.

## BBQ립 시중가 정정

- 우리 스펙 = 미국 엑셀 언그레이드(86R/E/K/M).
- 시중 정합가 = 미국 BBQ등갈비 엑셀 86R 언그레이드 13,200(재고27)~14,800(살밥 많은 86R), 유사 브랜드(오마하·뎀코타·아이오와) 12,500~14,800.
- 우리 공급 14,800 ≈ 시중 상단, 매입 13,000 < 시중 = 경쟁력 OK.
- 이전 9,100(저가 등갈비/백립)·캐나다 13,980은 오조회. 다음 실측 검색어 "BBQ등갈비 엑셀"로 고정.

## 기타

- 참머리: 단종 (마스터·원장에서 제외).
- 원물/가공 쌍 매핑: 목전지도 원물행 + 가공 기준행 쌍(한돈목살↔칼집, 우삼겹↔슬라이스와 동일). 원물=시세 추적, 가공=공급가 산정.
