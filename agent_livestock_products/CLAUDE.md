## 핵심 원물 8종 (구글시트 원물 마스터 기준)

M01 우삼겹슬라이스(A/10kg박스) · M02 소꼬리절단(A/10kg박스) · M03 뼈갈비절단 BBQ백립(A/10kg박스) · M04 아롱사태(B/계근) · M05 전지 수육용(B/계근) · M06 스지 통합/비정형(C/박스정액 4.3~4.54kg) · M07 목전지 제육용(A/10kg박스) · M08 목전지 찌개용(A/10kg박스)

판단의 단위는 이 8개 원물이다. 100개 품목 전체를 깊게 분석하지 않는다.

## 운영 루틴

- **주간 리포트**: 매주 수요일 11:00 — 주간 리포트 DB에 새 행 1개 (최신 행과 같은 틀)
  1. 시장 현황: 미국산·호주산 분리 → 국내 해석 (표)
  2. 미트박스 관찰: 스지·미박삼겹·백립·돌돌이 실측 → 전주·전월 비교 코멘트
  3. 원물별 구매 판단 (8원물 표) → 영향 품목은 상태판 갱신
  4. 결정: 보고 문안 3줄 + 기한 있는 액션 → 대시보드 스냅샷 갱신
- **월간 공급가 권장안**: 매월 25일 11:00 (25일이 토요일→24일 금, 일요일→23일 금). 상태판에서 "인상 검토·인하 검토·수입사 확인" 필터로 시작
- **월말**: 지난달 리포트의 "결정 검증" 칸 채우기 (적중/부분 적중/빗나감)

## 미트박스 실측 방법

로그인 없이 공개 검색 페이지를 WebFetch로 읽을 수 있다:
`https://www.meatbox.co.kr/fo/search/searchPage.do?searchText=<URL인코딩 검색어>`

우선 관찰 4종 검색어: 스지 / 미박삼겹 / 등갈비 미국산 / 삼겹양지 돌돌이
기록 우선순위: 최저가보다 판매자 수·품절·재고 신호. 원물/세절/대량/낱개/브랜드 스펙 차이가 크므로 동일 스펙끼리만 비교.

### 처분 매물 태그 규칙 (최저가를 시세로 오독 방지)

미트박스 상위 노출 최저가가 유통기한 임박·도축 경과로 손실 감수 급처인 경우가 있음. 최저가 하나로 쓰지 말고 **대표 시세가(여러 판매자 몰린 안정 밴드) / 관찰 최저가(처분 포함 바닥)** 두 값으로 분리해 기록. 신호태그 3종: `시세`(정상) / `처분 의심`(대량재고인데 최저가·1~2건만 튀게 저가·소비기한임박/떨이/도축일 표기·단발 판매자) / `강세`(품절·재고소진). 대표가 산정 시 `처분 의심`은 제외.

### 시세 데이터 3층 파이프라인

시세는 원장 → 시황 → 주간 리포트로 위로 취합(분산 아님):
1. **시세 원장** — 미트박스 실측·공식 시세를 한 DB에 `출처`로 구분해 시계열 축적 (1행 = 관측 1건). 공식 부위가(육류협회 삼겹살 등)를 상한 기준선, 미트박스 실측을 실거래로 나란히 기록.
2. **주차별 시황 카드** — 주차 × 세그먼트(국내소·수입소·국내돼지·수입돼지) 4행/주. `근거 시세`로 원장 행을 링크, 내부 공유용 서술.
3. **주간 리포트** — 위 둘을 합친 1장 보고서. 시황 카드를 `주간 리포트` 관계로 롤업.

미박삼겹 시중가 참고법: 공식 삼겹살 부위가(상한 기준선) ↔ 미트박스 미박 실측(실거래·처분 반영) 두 축으로 해석. 미박삼겹 전용 공식 시세는 없음.

## 판단 기준

- 총마진 기준 **17.5%**. 단, 시중가가 우리 공급가 아래로 내려오면 마진보다 **가맹점 이탈 방어 우선**
- 원가 상승 → 인상 검토 / 시중가 하락·판매 저항 → 동결·인하 검토 / 물량 잠김 → 비축 검토
- 미트박스 신호: 판매자 감소=잠김 / 품절 증가=공급 부족 / 최저가 상승=강세 / 저가 매물 증가=풀림 / 판매자 증가+가격 하락=약세
- 미국산×호주산 취합: 둘 다 강세=비축 / 미국 강세+호주 약세=호주 대체·협상 / 미국 조정+호주 풀림=동결·인하 / 엇갈림=선별 대응
- 비축 트리거: 주간 컷아웃 반등 + 스크루웜 확진 가속 **동시 발생** 시 중간육 선별 비축 즉시 검토
- 불확실한 내용은 가능성 / 확인 필요 / 보류로 구분해 기록
