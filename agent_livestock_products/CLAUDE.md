### 공급가 조정 보고서 구성 (2026-10-07 사용자 확정 루틴)

공급가 조정 시 노션 보고서 DB 페이지는 아래 순서로 작성한다 (2026-09·10월 보고서가 형식 원본):

1. **보고 문안 콜아웃** — 인상·인하·유지 품목 수 + 품목별 핵심 사유
2. **품목 표** — 재고 구간(A/B/C)별 구매가·공급가·총마진·순마진 병기. 데이터 원본은 구글시트 `중간단가변경이력` 탭 (동일 품목에 단가 여러 개 = 매입확정가 + 매입예정가. 매입예정가 기준 마진까지 확인하는 용도)
3. **산출 기준** → 4. **시황 요약** → 5. **근거** (기존 형식 유지)
6. **운영팀 응대 참고(바이저 안내용)** — 반드시 포함. 구성: ① 한눈 요약 ② 시세가 왜 오르는지 배경(쉬운 말, 품목 공통의 거시 요인 중심) ③ 점주 예상 질문 Q&A(약속성 발언 금지선을 ※로 병기) ④ 응대 시 주의(내부 한정 정보)
   - **품목별 설명 포인트는 싣지 않는다** — 바이저가 복붙해 점주에게 그대로 전달할 가능성이 있어, 품목 단위의 노골적 설명은 예민할 수 있음(2026-10-07 사용자 판단). 품목 특이사항(예: 립은 미국 내 바비큐·연말 수요로 현지 강세)은 ②시세 배경에 녹여서 쓴다.
   - ④응대 주의에는 금지 항목을 명시: 매입 단가·마진율·재고 보유량 언급 금지, "싸게 사둔 재고" 류 표현 금지, 인상 사유는 외부 요인으로만 설명.
   - **운영팀 실제 전달본은 보고서의 응대 참고 전문이 아니다** — 사용자가 추려서 전달한다. 2026-10-07 전례(최종): 한눈 요약 + 시세 배경 + Q&A 앞 2개만 전달하고, **책임성이 생기는 문구는 전부 제외**함 — ① 시중가 대비 가격 비교 단언 ② 과거 인하 전례 언급 ③ 품질 무차이 단언 ④ "원가 올랐지만 본사가 흡수" 어필 ⑤ **본사의 행동 약속**("매주 시세 점검 중", "인상 요인이 생겨도 최소한으로만 반영" — Q2 답변도 "당분간 강세 가능성이 높음"에서 끊음) ⑥ ※ 표기 내부 지침·응대 주의 섹션. 전달본은 **외부 사실의 설명까지만**, 본사가 무엇을 하겠다·하고 있다는 문장은 넣지 않는다. 초안 작성 때부터 이 선을 지켜 보고서 내부용과 전달본 후보를 구분해 둔다.

## 미트박스 실측 방법

로그인 없이 공개 검색 페이지를 WebFetch로 읽을 수 있다:
`https://www.meatbox.co.kr/fo/search/searchPage.do?searchText=<URL인코딩 검색어>`

우선 관찰 3종 검색어: 스지 / **BBQ등갈비 엑셀** / 삼겹양지 돌돌이
- BBQ립은 "BBQ등갈비 엑셀"로 고정 검색한다. "백립"·"엑셀 백립"으로 조회하면 저가 등갈비·조각백립이 섞여 오조회(2026-07-29 9,100 → 13,200 정정 건).
- BBQ립 대표가 스펙: **86M·86K 언그레이드 기준** (86R은 시중 재고 단종 — 2026-08-20 사용자 확인). 단 자사는 9월까지 86R 재고로 공급 중 → 9월엔 동일 스펙 시중가가 없으므로 86M/K는 유사 스펙 참고선. 10월 재매입분부터 86M/K 매입가 기준으로 공급가 재산정 필요.
- 품목 명칭은 **BBQ립**으로 통일(구 "BBQ백립" 표기 폐지 — 마스터·시세 원장·시황 카드 모두 BBQ립).
기록 우선순위: 최저가보다 판매자 수·품절·재고 신호. 원물/세절/대량/낱개/브랜드 스펙 차이가 크므로 동일 스펙끼리만 비교.

**실측 전 마스터 대조 (필수)** — 2026-08-03 아롱사태 냉장/냉동 오매칭(-7% 오판) 재발 방지:
1. 실측 전에 품목 상태판(마스터)에서 해당 품목의 **온도·상태·원산지·브랜드·등급**을 확인하고, 그 조건에 맞는 매물만 대표가로 쓴다.
2. '냉장' 표기가 있는 매물은 냉장. 마스터가 냉동이면 냉장 표기 매물은 대표가에서 제외(별도 참고 기록만).
3. 마스터 브랜드 목록에 없는 PB(당당한컷 등 가공장 미상)는 참고값으로만 기록, 대표가는 마스터 브랜드 기준.
4. 검색 결과를 요약할 때 특정 브랜드로 좁혀 읽지 말 것(브랜드 전체를 나열시킨 뒤 마스터 조건으로 거른다).
5. 스펙 확정 사항(2026-08-03 사용자 확인): 한돈목살 칼집은 **프리미엄급** — 대표가는 프리미엄 밴드(2026-10-26 실측 기준 오성愛한돈류), 일반 밴드는 참고만. 목전지=미국산(스미스필드·시보드·스위프트). (전지 수육용 2스펙 기준은 2026-10-27 운영 종료로 폐지 — 재운영 시 과거 기준: 미국 스위프트·네덜란드 웨스트포트, 검색어 "앞다리")

### 처분 매물 태그 규칙 (최저가를 시세로 오독 방지)

미트박스 상위 노출 최저가가 유통기한 임박·도축 경과로 손실 감수 급처인 경우가 있음. 최저가 하나로 쓰지 말고 **대표 시세가(여러 판매자 몰린 안정 밴드) / 관찰 최저가(처분 포함 바닥)** 두 값으로 분리해 기록. 신호태그 3종: `시세`(정상) / `처분 의심`(대량재고인데 최저가·1~2건만 튀게 저가·소비기한임박/떨이/도축일 표기·단발 판매자) / `강세`(품절·재고소진). 대표가 산정 시 `처분 의심`은 제외.

### 시세 데이터 3층 파이프라인

시세는 원장 → 시황 → 주간 리포트로 위로 취합(분산 아님):
1. **시세 원장** — 미트박스 실측·공식 시세를 한 DB에 `출처`로 구분해 시계열 축적 (1행 = 관측 1건). 공식 부위가(육류협회 삼겹살 등)를 상한 기준선, 미트박스 실측을 실거래로 나란히 기록.
2. **주차별 시황 카드** — 주차 × 세그먼트(국내소·수입소·국내돼지·수입돼지) 4행/주. `근거 시세`로 원장 행을 링크, 내부 공유용 서술.
3. **주간 리포트** — 위 둘을 합친 1장 보고서. 시황 카드를 `주간 리포트` 관계로 롤업.

### 국내 돼지 운영 2품목 — 주차별 별도 추적 (2026-09-10 확정 / 2026-10-26 개정)

운영 중인 국내산 돼지는 **한돈목살(원물, 냉장) · 한돈 등갈비(냉동 원물)** 2품목. 매주 실측 때 이 둘만 따로 표로 뽑는다(스킬 `weekly-survey` 1-1단계에 조회 URL·파라미터·기록 표기 전부 있음).

- 세 축으로 본다: **미트박스 실측**(실거래) / **육류협회 부위별 공장출고가**(정육 기준선) / **축평원 지육 경락가 탕박·등외제외**(원가 뿌리, 가장 빠른 선행 신호)
- 대응 칸: 한돈목살↔목심 냉장 / 한돈 등갈비↔갈비 냉동(대분할이라 방향 참고만)
- 육류협회는 발표가 1~2주 늦다 — 값이 채워진 가장 최근 주를 기준주로 쓰고 비고에 적는다
- 한돈 등갈비는 2026-09-10 마스터 신규 등록(검색어 "한돈 등갈비"). 냉동 원물만 대표가, 냉장·세절팩은 kg당 1만원 이상 비싼 별개 스펙
- 한돈목살 칼집은 품목 표에서 제외(기존 실측은 유지)
- **미박삼겹은 2026-10-26 운영 종료** — 실측·보고·공급가 조정 대상에서 모두 제외한다. 과거 시세 원장 기록은 그대로 두되 신규 관측은 하지 않는다

## 판단 기준

- 총마진 기준 **17.5%**. 단, 시중가가 우리 공급가 아래로 내려오면 마진보다 **가맹점 이탈 방어 우선**
- 원가 상승 → 인상 검토 / 시중가 하락·판매 저항 → 동결·인하 검토 / 물량 잠김 → 비축 검토
- 미트박스 신호: 판매자 감소=잠김 / 품절 증가=공급 부족 / 최저가 상승=강세 / 저가 매물 증가=풀림 / 판매자 증가+가격 하락=약세
- 미국산×호주산 취합: 둘 다 강세=비축 / 미국 강세+호주 약세=호주 대체·협상 / 미국 조정+호주 풀림=동결·인하 / 엇갈림=선별 대응
- 비축 트리거: 주간 컷아웃 반등 + 스크루웜 확진 가속 **동시 발생** 시 중간육 선별 비축 즉시 검토
- 불확실한 내용은 가능성 / 확인 필요 / 보류로 구분해 기록

- 구글시트는 gdrive MCP로 첫 탭만 읽힘 → 다른 탭은 `~/.gdrive-mcp` OAuth 자격증명으로 Sheets API 직접 호출(`/v4/spreadsheets/{id}/values/{탭명}`)해서 읽는다 (2026-08-21 검증, 메모리 gsheets-direct-read 참고). 탭명: 중간단가변경이력·축산품가공이력·축산품구매이력
- 환율(USD/KRW)이 기록 체계에 없음 → 주간 리포트 지표에 추가 권장 (미반영 상태)
