```

                                                          ▼
제때 입고이력 (입고원가 = 가공품→가공원가 / 그외→구매이력 원가_최종 forward-fill)
```

## 5. 허점 점검에서 발견·수정한 것 (3건)

1. **[수정] 13/14 시트 INDEX 범위 고정 버그**: `$A$3:$A$10`(8원물 고정)이라 M09~M11 코드가 F9 재계산 시 #N/A 나던 잠재 버그 → **원물 수 동적**(`$A$3:$A$13`)으로 수정.
2. **[수정] 제때 입고원가 캐시 불일치(20행)**: 기존엔 "그 날짜에 가공LOT 매칭이 하나라도 있으면 그날 전체 캐시=가공원가"(날짜맵) → 시트 수식은 행별 가공LOT 기준이라 **같은 날 미매칭 행의 캐시≠수식**(F9 시 값 변동). → **행별 캐시**로 수정(매칭행=가공원가, 미매칭행=구매이력 원가_최종). 엔진 원가 캐시도 "그 날짜 마지막 제때 행의 S"로 수식과 1:1 일치화.
3. **[수정] 이식 시 수식 소실**: ExcelJS가 구글 export의 캐시값(0·빈문자열)을 잃고, 스트리밍 라이터가 result 없는 수식셀을 드롭(가공 764·구매 830셀) → **SheetJS 캐시값을 result로 병합**해 100% 보존.
