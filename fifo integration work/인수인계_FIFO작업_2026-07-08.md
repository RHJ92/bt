## 4. 코드·문서 핵심
### build5.js 파이프라인 (prep + stream)
1. **prep**: ①드라이브 4시트를 ExcelJS로 풀로드→셀단위(값·수식·스타일·병합·너비) TRANS 구조로 캡처(=verbatim 이식 준비), 스지 4.5 보정 ②마스터에서 ORD(M01~M11)·그룹·박스당kg·CClist(제때코드→원물ID) 파싱 ③구매이력→purchases[] (원가_최종 캐시), 가공이력→gacKByLot·가공출고이벤트 ④비축산 구매가 타임라인(btBuyAt: 월별시트+BFBT) ⑤02 입고 lots + FIFO 계산(MONTHS 2024-02~2026-06 동적)
2. **stream**(ExcelJS WorkbookWriter): 0_읽어보기 → 축산 4시트 이식 → 제때 입고이력(가공LOT 수량매칭, 입고원가 수식, **비축산 K=값 주입**) → 매출원본_2024/25/26 → 출고요약_월별 → 4_출고_가맹점 → 엔진_M01~M11 → 13 → 14
3. **참조 체계**: S2(구매이력) = $B입고일/$C원물ID/$P원가_최종/$R출고단위원가, 행범위 4~428(버퍼 50행 포함). 제때 입고원가($S) = IF(가공LOT, 가공원가, S2 forward-fill). 엔진 costFormula = 제때 $S 참조.
4. **재빌드 명령**:
