# 옥감자수제비

■ 1. 주요 반품 사유

① 해동 흔적: 배송 중 냉동 탑차 온도 유지 실패로 제품이 녹아 면끼리 엉겨 붙거나, 재동결로 박스 내부에 과도한 얼음덩어리가 뭉쳐진 경우

② 갈라짐·부서짐 과다: 제품 표면의 줄무늬·갈라짐·부서짐이 정상 범위를 초과하여 조리 시 형태 유지가 불가능한 수준인 경우 — 과거 제조 공정(완만동결 수분편차) 원인의 대량 갈라짐으로 제조사 회수 처리된 사례가 있으므로, 광범위 발생 시 즉시 보고 (단, 냉동면류 특성상 미세 갈라짐은 정상 범위 — 유의사항 참조)

③ 포장 파손: 물류 하차 시 박스·내포장이 파손되어 내용물이 노출·훼손된 경우

④ 이물 검출: 제조 공정상 비의도적으로 유입된 이물질이 발견된 경우

⑤ 소비기한 경과·임박: 소비기한이 경과했거나 기한 내 소진이 불가능할 정도로 임박한 상품이 입고된 경우

⑥ 상이품 입고 (발주 품목 상이): 가맹점 전산 발주 품목과 실제 입고 제품이 일치하지 않는 경우

■ 4. 유의사항

⚠ 냉동 상태 그대로 조리에 투입하는 것이 매뉴얼입니다: 냉장 해동 후 조리 시 수분 편차로 갈라짐·끊어짐이 발생하며, 이는 조리 방법에 기인한 것으로 반품 사유가 되지 않습니다. 반드시 냉동 상태에서 바로 끓는 물에 투입해 주십시오.

⚠ 냉동면류 특성상 표면의 미세 갈라짐·줄무늬는 정상 범위입니다. 다만 조리 시 형태가 유지되지 않을 정도의 광범위한 갈라짐(과거 제조 공정 이슈 사례)은 반품 대상이므로, 제조일자가 보이도록 촬영해 보고해 주십시오 — 동일 제조일자분 일괄 조치가 가능합니다.

⚠ 개봉·일부 사용 후에는 반품이 불가합니다. 이상 발견 시 미사용 상태로 분리 보관 후 보고해 주십시오.
