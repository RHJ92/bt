# 옥감자수제비

보관조건 : 냉동 (-18℃ 이하)　　단위 : BOX — [속포장 단위·중량 확인 필요]

■ 공급처
　동성식품 (추정) — [제때코드 확인 필요]
　※ 회사명은 히스토리 기반 추정 — 확정 전 확인 필요

■ 1. 주요 반품 사유

① 해동 흔적: 배송 중 온도 관리 실패로 녹아 수제비끼리 엉겨 붙었거나, 다시 얼면서 박스 안에 얼음덩어리가 크게 뭉쳐 있는 경우

② 갈라짐·부서짐 과다: 조리 시 모양이 유지되지 않을 정도로 넓게 갈라지거나 부서진 경우 (표면의 가는 실금은 냉동 제품 특성상 정상 — 유의사항 참조)

③ 포장 파손: 박스·속포장이 찢어져 내용물이 드러나거나 훼손된 경우

④ 이물 발견: 제조 과정에서 들어간 이물이 나온 경우

⑤ 소비기한 문제: 기한이 지났거나, 기한 내에 도저히 소진할 수 없을 만큼 임박한 상품이 입고된 경우

⑥ 다른 상품 입고: 주문한 상품과 다른 제품이 입고된 경우

■ 3. 수령 검수 체크리스트

| No | 검수 항목 | 확인 방법 | 판정 기준 (정상) | 이상 시 조치 |

| 1 | 주문 일치·수량 | 발주 품목·수량과 실물 대조 | 주문과 정확히 일치 | 즉시 보고 후 반품/매출수정 |

| 3 | 갈라짐·부서짐 | 포장 투명면으로 표면 상태 확인 | 가는 실금 이내, 모양 온전 | 넓은 갈라짐은 제조일자 포함 사진 보고 |

■ 4. 유의사항

⚠ 냉동 상태 그대로 끓는 물에 넣는 것이 조리 기준입니다: 냉장고에서 해동한 뒤 조리하면 수분 차이로 갈라지고 끊어지며, 이 경우는 조리 방법에 따른 것이라 반품 대상이 되지 않습니다.

⚠ 표면의 가는 실금은 냉동 제품 특성상 정상 범위입니다. 다만 조리 시 모양이 유지되지 않을 정도로 넓게 갈라진 경우는 제조 공정 문제일 수 있으니, 제조일자가 보이게 촬영해 보고해 주세요 — 같은 제조일자 상품을 한꺼번에 조치할 수 있습니다.

⚠ 개봉하거나 일부 사용한 뒤에는 반품이 어렵습니다. 이상이 보이면 사용하지 말고 그대로 보관한 상태에서 보고해 주세요.
