# 목전지 (제육용)

보관조건 : 냉동 (-18℃ 이하)　　단위 : BOX (10kg/BOX, 6등분 5kg×2)

■ 공급처
　[공급처명 확인 필요] — CC311801 목전지 제육용(SM/6등분/5kg×2)
　※ 원산지: 미국산 (네덜란드산 전지 대체 테스트 이력 있음)
　※ 목전지 찌개용(CC311800)은 2026년 5월 제육용으로 통합 종료 — 현재 제육용 단일 운영

■ 1. 주요 반품 사유

① 해동 흔적: 배송 중 냉동 탑차 온도 유지 실패로 핏물이 흘러나오거나(드립 현상), 재동결로 박스 내부에 과도한 얼음덩어리가 뭉쳐진 경우

② 중량 부족: 박스당 표기 중량(10kg) 대비 실측 중량이 본사 허용 오차 범위를 초과하여 부족한 경우 — 실측 부족분 전산 반품 처리된 실사례가 있는 품목이므로 정량 검수 필수

③ 포장 파손·진공 해제: 물류 하차 시 박스가 파손되거나 내부 비닐 진공 포장이 풀려 원육이 공기에 노출된 경우

④ 과지방 및 정형 불량: 살코기 대비 지방 비중이 본사 허용치를 초과하거나, 지방 덩어리가 뭉치로 혼입된 경우 (실제 클레임 사례 있음)

⑤ 절단 두께 불량·자투리 과다: 세절 두께가 불균일하여 해동·조리 시 제품이 심하게 으스러지거나, 조리에 부적합한 소형 자투리 고기가 과도하게 혼입되어 수율을 저하시키는 경우

⑥ 이물 검출: 진공 포장 풀림 및 전처리 공정상 비의도적으로 유입된 이물질(비닐 조각, 작업용 장갑 조각 등)이 발견된 경우

⑦ 원육 변색 및 갈변·이취: 입고 당일 검수 시 목전지 고유의 색을 잃고 검게 변색·갈변되었거나 이취가 확인된 경우

⑧ 상이품 입고 (발주 품목 상이): 가맹점 전산 발주 품목과 실제 입고 제품의 규격·스펙이 일치하지 않는 경우

■ 4. 유의사항

⚠ 정량 검수를 생활화해 주십시오: 목전지는 과거 표기 중량 대비 실측 부족(10kg 주문분 8,420g 입고) 사례가 있었던 품목입니다. 수령 당일 실측 후 부족분은 증빙 사진과 함께 즉시 보고해 주시면 전산 반품(매출수정)으로 처리됩니다. 당일 경과 후 이의 제기는 인정되지 않습니다.

⚠ 해동 후 재냉동 절대 불가: 세절된 육류 특성상 재냉동 시 원육끼리 엉겨 붙는 경화 현상이 발생하여 조리 시 심하게 으스러지므로, 당일 사용분만 냉장 완만 해동합니다.

⚠ 진공 해제 제품 최우선 사용: 보관 중 진공 풀림이 발견된 팩은 선입선출과 관계없이 최우선으로 즉시 사용하여 산화 갈변을 방지합니다.

⚠ 갈변·이취는 입고 당일 검수가 원칙입니다: 입고 당일 발견분은 반품 가능하나, 익일부터는 귀책 확인 후에만 제한적으로 수렴됩니다.
