# 쌀 (혼합미)

보관조건 : 상온 (서늘·건조, 직사광선 차단)　　단위 : 포대 — [포대당 중량 확인 필요]

■ 공급처
　경기서부미곡처리장 — [제때코드 확인 필요]

■ 1. 주요 반품 사유

① 벌레·곰팡이 발생: 입고 직후 검수 시 쌀벌레(곡식나방 유충 등)·곰팡이가 확인된 경우 — 실제 다수 매장에서 동시 발생하여 공급사 반품 처리된 사례가 있는 유형 (도정 후 3주 초과 보관 시 유충 부화 가능성이 원인)

② 변색·도정 불량: 노랗게 변색된 쌀알이 과다하거나, 도정 불량으로 밥이 심하게 떡지는 등 취반 품질에 문제가 있는 경우

③ 이물질 혼입: 시멘트 유사 경질 이물, 작업벼 등 비의도적 이물이 발견된 경우 (실사례 있음 — 발견 시 포대째 보관 필수)

④ 싸래기 과다: 부서진 쌀알 비율이 정상 범위를 초과하여 취반 품질이 저하되는 경우

⑤ 포대 훼손: 포대가 찢기거나 파손되어 내용물이 오염·유출된 경우

⑥ 상이품 입고 (발주 품목 상이): 가맹점 전산 발주 품목과 실제 입고 제품이 일치하지 않는 경우

■ 4. 유의사항

⚠ 입고 직후 검수가 가장 중요합니다: 쌀벌레·곰팡이는 매장 보관 환경(온도·습도)의 영향도 크기 때문에, 입고 후 장기간 경과 후 발견된 건은 귀책 구분이 어려워 반품이 불가할 수 있습니다. 입고 당일 도정일자와 내용물 상태를 확인하는 습관을 들여 주십시오.

⚠ 보관은 서늘하고 건조한 곳에: 직사광선·습기·고온을 피해 보관하고, 여름철에는 특히 장기 보관을 지양해 주십시오. 도정 3주 초과 보관 시 유충이 부화할 수 있습니다(본사 센터도 도정일 기준 2주 재고회전으로 운영 중).

⚠ 과발주 주의: 재고 회전이 품질 유지의 핵심입니다. 소진 가능한 수량만 주문해 주십시오. 과발주로 인한 매장 재고분은 반품이 불가합니다.

⚠ 이물·벌레 발견 시 해당 포대를 버리거나 소분하지 말고 포대째 보관해 주십시오. 공급사 확인·반품 협의에 실물이 필요합니다.
