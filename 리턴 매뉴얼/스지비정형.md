# 스지 비정형

보관조건 : 냉동 (-18℃ 이하)　　단위 : BOX (박스정액 4.1~4.54kg/BOX, ★스지통합)

■ 공급처
　하이랜드 (추정) — CC310897 스지S (4.54kg)
　하이랜드 (추정) — CC310907 스지 비정형S (4.1~4.5kg)

　※ 취급 브랜드: 블루리본·다이아몬드 등 (뒷스지) — 수급 상황에 따라 변동
　※ 회사명은 히스토리 기반 추정 — 확정 전 확인 필요

■ 1. 주요 반품 사유

① 해동 흔적: 배송 중 냉동 탑차 온도 유지 실패로 핏물이 흘러나오거나(드립 현상), 재동결로 박스 내부에 과도한 얼음덩어리가 뭉쳐진 경우

② 중량 미달: 박스당 표기 중량 대비 실측 중량이 본사 허용 오차 범위를 초과하여 부족한 경우 — 과거 계측 (-)오차가 다발하여 전 지점 보상 처리된 사례가 있는 품목이므로 실중량 계량 필수

③ 상이품(타 부위) 혼입: 스지가 아닌 타 부위(우설 등)가 혼입되거나 현지 오포장으로 다른 부위가 통째 입고된 경우 — 실제 반품 사례 다수

④ 포장 파손·진공 해제: 물류 하차 시 박스가 파손되거나 내부 비닐 진공 포장이 풀려 원육이 공기에 노출된 경우

⑤ 이물 과다 혼입: 연골 조각·잔여 뼈조각 등 비의도적 이물이 과도하게 혼입된 경우 — 털·심줄 핏기 소량은 부산물 특성상 반품 불가(유의사항 참조)

⑥ 성상 불량: 검붉은 변색, 과도한 살코기 부착, 딱딱함·질김 등 정상 조리가 어려운 수준의 성상 저하가 확인된 경우

⑦ 상이품 입고 (규격 코드 혼동): 스지(4.54kg)와 스지 비정형(4.1~4.5kg)은 코드·규격이 다르므로, 발주 코드와 실제 입고 규격이 상이한 경우

■ 4. 유의사항

⚠ 털·심줄 핏기 소량은 반품 사유가 아닙니다: 스지는 소의 부산물로 소량의 솜털이 있을 수 있으며 이는 자연스러운 현상입니다. 1차 해동 및 초벌삶기 과정에서 솜털·비계·이물질을 제거하고, 2차 조리·제공 시 다시 한번 확인해 주십시오. 특히 검은색 털은 머리카락으로 오인될 수 있으니 반드시 재확인 바랍니다. 정상 전처리로 제거 불가능한 수준의 과다 혼입만 반품 협의 대상입니다.

⚠ 비정형육 특성상 팩마다 일정 수준의 크기·형태 편차가 있는 것은 정상 범위입니다. 과도한 지방·피막·이물 혼입 등 명확한 하자가 있는 경우만 반품 대상입니다.

⚠ 스지는 코드 간(스지 4.54kg / 스지 비정형 4.1~4.5kg) 스펙 차이가 있으므로 발주 시 코드를 재확인해 주시고, 실중량 계량을 생활화해 주십시오(과거 계측 오차 다발 품목).

⚠ 해동 후 재냉동 절대 불가하며, 진공 해제가 발견된 팩은 선입선출과 관계없이 최우선으로 사용해 주십시오.
