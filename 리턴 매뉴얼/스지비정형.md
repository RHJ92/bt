# 스지 비정형

보관조건 : 냉동 (-18℃ 이하)　　단위 : BOX (박스정액 4.3~4.54kg/BOX, ★스지통합)

■ 공급처
　[공급처명 확인 필요] — CC310897 (스지, 4.54kg)
　[공급처명 확인 필요] — CC310907 (스지 비정형, 4.3kg)
　[공급처명 확인 필요] — CC311798 (스지 비정형, 4.3kg)

■ 1. 주요 반품 사유

① 해동 흔적: 배송 중 냉동 탑차 온도 유지 실패로 핏물이 흘러나오거나(드립 현상), 재동결로 박스 내부에 과도한 얼음덩어리가 뭉쳐진 경우

② 포장 파손·진공 해제: 물류 하차 시 박스가 파손되거나 내부 비닐 진공 포장이 풀려 원육이 공기에 노출된 경우

③ 중량 미달: 박스당 표기 중량(4.3~4.54kg) 대비 실측 중량이 본사 허용 오차 범위를 초과하여 부족한 경우

④ 이물 혼입: 스지는 손질 난이도가 높아 연골 조각·잔여 뼈조각·잔털 등 비의도적 이물이 과도하게 혼입되는 경우

⑤ 정형 불량: 비정형 특성상 크기 편차가 있는 것은 정상 범위이나, 특정 팩에 지방·피막이 과도하게 잔존해 상품화가 어려운 경우

⑥ 원육 변색 및 갈변 현상: 냉동 보관·유통 중 정온 관리 미흡으로 검게 변색되거나 갈변한 경우

⑦ 상이품 입고 (규격 코드 혼동): 스지(4.54kg)와 스지 비정형(4.3kg)은 코드·규격이 다르므로, 발주 코드와 실제 입고 규격이 상이한 경우

■ 4. 유의사항

⚠ 스지는 코드 간(스지 4.54kg / 스지 비정형 4.3kg) 스펙 차이가 있으므로, 발주 시 코드를 재확인해 주시기 바랍니다.

⚠ 비정형육 특성상 팩마다 일정 수준의 크기·형태 편차가 있는 것은 정상 범위입니다. 과도한 지방·이물 혼입 등 명확한 하자가 있는 경우만 반품 대상입니다.

⚠ 해동 후 재냉동 절대 불가하며, 진공 해제가 발견된 팩은 선입선출과 관계없이 최우선으로 사용해 주십시오.
