# 뼈갈비 절단 (BBQ 백립)

보관조건 : 냉동 (-18℃ 이하)　　단위 : BOX (10kg/BOX)

■ 공급처
　[공급처명 확인 필요] — CC311991
　[공급처명 확인 필요] — CC311992

■ 1. 주요 반품 사유

① 해동 흔적: 배송 중 냉동 탑차 온도 유지 실패로 핏물이 흘러나오거나(드립 현상), 재동결로 박스 내부에 과도한 얼음덩어리가 뭉쳐진 경우

② 포장 파손·진공 해제: 물류 하차 시 박스가 파손되거나 내부 비닐 진공 포장이 풀려 원육이 공기에 노출된 경우

③ 절단 규격·뼈대 수 불균일: 갈비대 개수·두께 편차가 커서 지정 규격에 미달하는 경우

④ 골절편·뼈파편 과다 검출: 절단 공정 중 뼈가 산산조각나 잔존 파편이 다량 혼입되어 조리·취식 시 위해 우려가 있는 경우

⑤ 살코기 비율 부족·과지방: 뼈 비중이 과다하여 상품성이 저하되거나, 특정 부위에 지방이 집중 혼입된 경우

⑥ 원육 변색 및 갈변 현상: 냉동 보관·유통 중 정온 관리 미흡으로 검게 변색되거나 갈변한 경우

⑦ 상이품 입고 (발주 품목 상이): 가맹점 전산 발주 품목과 실제 입고 규격·스펙이 일치하지 않아 오배송이 확인된 경우

■ 4. 유의사항

⚠ 뼈파편 이물은 소비자 안전과 직결되는 사안입니다. 발견 즉시 조리·판매를 중단하고 해당 박스 전량을 반품 대상으로 처리해 주십시오.

⚠ 해동 후 재냉동 절대 불가: 뼈 포함 부위는 재냉동 시 육질 경화와 뼈-살 분리가 심해져 조리 품질이 저하되므로, 당일 사용분만 냉장 완만 해동합니다.

⚠ 진공 해제 제품 최우선 사용: 보관 중 진공 풀림이 발견된 팩은 선입선출과 관계없이 최우선으로 즉시 사용하여 상품 가치 저하를 방지하십시오.
