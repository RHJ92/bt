# CLAUDE.md 활용법 — 에이전트의 뇌 키우기

## 3층 구조

| 층 | 무엇 | 예 |
|---|---|---|
| 루트 CLAUDE.md | 회사 전체 규정집 — 폴더 열면 항상 자동 로딩 | 내 정보, 선호(한글·헤딩 금지), 프로젝트 지도 |
| 폴더별 CLAUDE.md | 부서 업무 매뉴얼 — 그 폴더 작업 시 로딩 | agent_livestock_products의 주간 루틴·판단 기준 |
| 노션·구글시트 | 장부(데이터) | 이번 주 시세, 공급가, 리포트 |

## 어디에 넣을지 판단 기준

1. 적용 범위: 모든 작업에 적용 → 루트 / 특정 프로젝트만 → 그 폴더 CLAUDE.md
2. 변하는 속도: **석 달 뒤에도 참이면 CLAUDE.md, 다음 주면 바뀌면 노션**

넣기 좋은 것: 반복되는 선호, 보고 형식, 판단 기준, 두 번 이상 교정한 것
넣지 말 것: 이번 주 데이터, 작업 일지(= git 커밋 기록이 대신함), 긴 설명문

## 보강하는 법

작업하다가 Claude에게 한마디: **"이건 앞으로도 계속 적용해줘. CLAUDE.md에 기록해."**
→ Claude가 적절한 위치·길이로 정리해 넣음 → "깃허브에 백업해줘"까지 하면 회사 PC와도 공유됨.

이 루프(작업 → 규칙 발견 → 기록 → 푸시)가 돌수록 양쪽 PC의 Claude가 내 방식대로 일하는 에이전트가 되어간다.
