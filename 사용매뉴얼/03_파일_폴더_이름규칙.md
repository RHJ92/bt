# 파일·폴더 이름 규칙

## 폴더의 세 가지 이름 관례

| 관례 | 뜻 | 예 |
|---|---|---|
| `.이름` (점) | 도구 전용 살림살이. 숨겨도 됨. 건드리지 말 것 | .git, .vscode, .claude, .gitignore |
| `대문자.md` | 먼저 읽으라는 안내 문서 | CLAUDE.md, README.md |
| 보통 이름 | 실제 작업물 | edit, Data, agent_livestock_products |

## 점(.) 파일들이 뭔지

- `.git` — 백업 기록 전체가 든 심장. 커밋 이력 + 깃허브 연결 정보. **지우면 이력 전부 소실**
- `.gitignore` — "깃허브에 올리지 마" 목록 (파일임, 폴더 아님). PC별 설정·임시파일을 제외해둠
- `.vscode` — VS Code 편집기 설정
- `.claude` — Claude Code의 이 프로젝트 설정·권한 기록

점 = 유닉스 시절부터의 "숨김/설정" 표시 관례. 탐색기 정리하다가 점 붙은 걸 지우면 안 된다.

## Q. CLAUDE.md는 왜 점이 안 붙나?

숨길 파일이 아니라 사람이 읽고 보강하라고 만든 문서라서. README처럼 전부 대문자 = "이 폴더에 온 사람(Claude)은 이걸 먼저 읽어라"는 반대쪽 관례.
