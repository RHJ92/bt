# 10월 거래 지출결의 미작성 건 점검 (2026-10-30)

슬랙 #지결계산서담당 지시 「10월 거래 지출결의 작성하지 않은건들 찾아서 작성해줘」 처리 기록.

**결론: 대상 선별·금액 대조까지 완료, BT FLOW 작성은 못 함.** 이 세션에 크롬 확장이 연결돼 있지 않아 BT FLOW(bt.btflowlab.kr)·노션 「확인용」 접근이 불가능함. 아래는 작성 직전까지 준비한 자료임.

## 확인한 근거

- 매입사마감 시트(조회기간 2026-10-01~10-31) — 지출결의서 진행 **20 / 92개사**
- 10월_발주진행현황 전 행 재집계 — 매입사마감 BT매입가와 전건 대조(아래 표의 「금액 검증」)
- 바탕화면 `지출결의 증빙 이미지` 폴더 + `계산서_수신` 폴더
- `state/pending_attach.json`(노션 미첨부 계산서 6건) / `attach_resolved.json`(10-29 기 확인분)

**노션 「법인 지출통합결의서 확인용」 Master DB는 확인하지 못했음** — 시트 M열(지출결의서) 표기만으로 판단한 것이라, 실제로는 올라가 있는데 시트 체크가 안 된 건이 섞여 있을 수 있음.

## C. 담당 범위

미작성 9건 중 **담당자 칸이 비어 있음**. 시트에서 류호정 담당 표기는 선우프레시·에치알푸드 2건뿐이고, 나머지 20건의 작성완료분은 전부 김민혁(팀장) 담당임. 가야김치·광천김·동원홈푸드·IC푸드·강서푸드뱅크·블루칩글로벌·아토무역은 팀장 담당분일 수 있어 **먼저 확인받는 쪽이 안전함**.
