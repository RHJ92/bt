# 발주담당 업무노트

슬랙 #발주담당 에이전트가 **작업 전에 매번 읽는** 판단 규칙 모음. 오류를 해결했거나 사용자가 고쳐 준 것·새로 알게 된 규칙은 **에이전트가 작업 끝에 바로 한 줄 추가**한다(2026-10-30~). 사용자가 「빼」라고 하면 지운다.
기본 문서: README.md §2 판단 규칙표가 기본. 여기는 운영하며 새로 확정된 규칙만. 문서와 이 노트가 다르면 이 노트가 더 최근이다.

|---|---|---|
| 2026-10-30 | **메일 본문 표와 첨부 엑셀 수량이 다르면 본문 기준.** 제때가 엑셀은 수정 없이 이전 파일을 첨부하는 경우가 있음. 입력은 본문대로 하고 결과에 차이만 참고로 표시 | 동원홈푸드(철산장) 10/30 발주 — 본문 60 / 첨부 40, 사용자 확인: 본문이 맞음 |
| 2026-11-02 | **발주 자동입력 실행 주기 = 월~금 09~18시 2시간마다**(09·11·13·15·17시 — 하루 5회. 19시 차례는 시간대를 벗어나 그날 마지막은 17시, 토·일·퇴근 후 발주는 다음 영업일 09시). 봇 `WATCH` 줄마다 **주기(분)와 실행 시간대**를 따로 둠 — 발주 `120, WINDOW_ORDER=(5, 9, 18)` / 계산서 수집은 그대로 `5, WINDOW_ALL=(6, 7, 21)`. 시간대 형식은 (요일 상한(배타), 시작 시, 끝 시(배타)). 마지막 실행 시각은 `shared/slack_bot/state/watch_runs.json`에 남아 봇을 다시 켜도 주기가 처음부터 돌지 않음. **봇 코드를 고치면 `shared/slack_bot/restart-bot.ps1`로 재시작해야 적용된다**(시작할 때 한 번만 읽음) | 사용자 지시 「발주 자동 입력은 1시간마다」(11-02 오전) → 「월~금 오전 9시~오후 6시까지 매 2시간마다」(11-02 오후) |
| 2026-11-02 | **봇 재시작은 담당 작업 안에서 직접 부르지 않는다** — `restart-bot.ps1`은 봇의 자식 `claude.exe`(=지금 돌고 있는 나)가 끝날 때까지 기다리므로, 내가 부르면 서로 기다리다 슬랙 답장이 끊긴다. **1회용 예약 작업**으로 몇 분 뒤에 돌리고 `-SelfTask '작업이름'`을 주면 끝나고 그 작업을 스스로 지운다(작업명 `슬랙 봇 재시작 (1회용)`). 이 방법으로 재시작한 뒤에는 `logs/restart.log`에 「재시작 완료 — 새 봇 [PID]」가 남는지로 확인 | 발주 주기 2시간 변경을 적용하려고 재시작할 때 |
| 2026-11-02 | **스크립트 안에 `\r`·`\n` 같은 글자를 Bash 히어독으로 써넣으면 역슬래시가 먹혀 실제 CR·LF 문자로 들어간다.** 그래서 `restart-bot.ps1`의 로그 경로가 `'logs\restart.log'`가 아니라 깨진 이름이 돼 재시작 기록이 하나도 안 남아 있었음(정정함 — `Join-Path (Join-Path $here 'logs') 'restart.log'`). **윈도우 경로는 한 문자열에 역슬래시로 이어 쓰지 말고 `Join-Path`(PowerShell)·`Path(...)/'...'`(파이썬)로 잇는다.** 고친 뒤 `[Parser]::ParseFile`로 구문 확인 | 재시작 기록을 찾다가 로그 파일이 없는 걸 발견 |
