- 작성: 2026-10-28 / 상태: **운영 중** — 슬랙 봇이 **월~금 09~18시 2시간마다**(09·11·13·15·17시) 자동 입력 (2026-11-02~, 사용자 지시)
  - 이력(정정함): 「월~금 16:30 하루 1회 작업 스케줄러」(10-29) → 「봇 5분 감시」(10-29) → 「봇 1시간 감시, 월~토 07~21시」(11-02) → **「봇 2시간 감시, 월~금 09~18시」(11-02 오후, 사용자 지시)**. 작업 스케줄러 작업 `제때 발주 자동입력 (월-금 16시30분)`은 **지금 등록돼 있지 않다** — 봇 감시로 대체됨
- 위치: `agents/` 거점(허브 README 먼저) — 「메일·카톡 수신물 분류 에이전트」의 업무 중 하나(지결은 `../expense_report/README.md`). 커리큘럼 2단계 「Slack 슈퍼팀」

- 테스트 환경: **개인 슬랙** (회사 허락받음). 검증 끝나면 회사 계정으로 같은 구조 그대로 이전

## 8. 기록기 동작 (`write_orders.py`, 2026-10-29)
