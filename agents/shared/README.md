**이카운트 IMAP (2026-10-29 확정)**
- 서버 `wmbox3.ecount.com:993` SSL, 계정 `invoice@bluetrend.co.kr` (출처: 웹메일 「외부연동가이드」 → 서버 정보설정)
- **전제: 웹메일 프로필 → 개인기능설정 → 외부연동설정 → [메일 클라이언트 사용] = 사용** (기본 꺼짐, 계정 사용자가 직접 켬. 출처: 이카운트 「아웃룩 2016 연동」 매뉴얼). 꺼져 있으면 비밀번호가 맞아도 `Authentication failed`
- 비밀번호: Windows 자격 증명 관리자 `ecount-imap` — 깃·파일에 두지 않음
- 로그인 문제 진단: `diagnose_login.py` (아이디 형식·인증 방식별 성공/실패만 출력, 저장 안 함)
- **읽기 전용**: `EXAMINE`(readonly) + `BODY.PEEK`로 읽음. 폴더 이동·삭제 없음
- **처리 끝난 메일만 「읽음」 표시**(`mark_seen`, 2026-10-29 사용자 요청): 웹메일 초록색(안 읽음)이 남아 있으면 다른 사람이 누락으로 오해함. 발주 입력·계산서 수집이 끝난 메일만 표시하고, 보안메일 열기 실패 등 확인 필요 건과 처리 대상이 아닌 메일(예: 블루푸드랩 입고 수량 공유)은 안 읽음으로 남김. 소급: 10/14 이후 처리분 발주 55·계산서 21통
- 처리 여부: 각 업무 폴더 `state/`에 처리한 메일 UID 기록 (Gmail 「처리완료」 라벨 대체)
- 업무 구분: 웹메일 「내 메일함」 업체별 폴더(발주서 등)가 이미 있으면 그대로 사용, 아니면 받은 메일함에서 보낸사람·제목 규칙으로 거름
- 폐기: Gmail 자동전달 경로 — 웹메일 자동전달이 관리자 전용(Self-Customizing)이라 불가. Gmail 「다른 계정 메일 가져오기(POP3)」도 구글이 기능 축소 중이라 쓰지 않음

**슬랙 앱 설정 메모 (2026-10-29)**
- 권한: chat:write · channels:read · channels:history · reactions:write / 이벤트: message.channels / Socket Mode 토큰 이름 `socket`
- 크롬에서 이벤트 구독 저장이 막힘(요청이 브라우저에서 차단, 응답코드 0) → **엣지로 설정**. 앱 설정 변경은 엣지 사용
- 봇 표시 이름이 슬랙 안에서 아직 「Demo App」 (앱 이름은 업무비서)
- 주인(지시 받는 사람) = 처음 `#지시`에 쓴 사용자 → `config/slack.json`의 owner
