## 지금 상태

- **매입처 전환 확정** — 옥된장 티타늄 국그릇·김치찜접시를 기존 매입처에서 **명화주방**으로 전환함
  - 국그릇 5,950원(기존 6,300, -5.6%) · 김치찜접시 3,600원(기존 6,650, -45.9%). 전부 VAT 별도
  - 접시 1차 견적 2,350원은 표면 질감이 기존 대비 떨어져 미채택 → 상위 사양 재견적 3,800원 → 협의로 3,600원 확정
- **발주·결제 완료** — 각 1,000개 선결제·선생산
  - 국그릇 세금계산서 10/14 6,545,000원 · 접시 10/15 3,960,000원 (VAT 포함 합계 10,505,000원)
  - BT FLOW 지출결의 상신 완료(10/16, 이체요청일 10/20), 노션 확인용 DB에 「이체 대기」로 등록 확인함
- **샘플 검토 완료** — 운영팀(서지윤 과장) 확인 결과 기존품에서 교체해도 운영상 문제 없음(10/1)
- **보관 재고관리 양식 완성** — 명화주방 발송용 2파일 준비됨(미발송)
  - `명화주방_식기류_재고관리대장.xlsx` (빈 양식) / `명화주방_식기류_재고관리대장_작성예시.xlsx`
  - 구조: 월별 시트(2026-10·11·12) + 로트대장 + 품목표. 명화주방은 **노란 칸(실사수량·비고)만** 기재
  - 로트번호 자동 생성(`입고일YYMMDD-순번`, 11111부터). 삼보 보관분(`-0…`)과 첫 자리로 구분

  - 출고내역은 받지 않음 — 당사가 마켓봄·출고 요청 기준으로 집계(삼보물류 대사와 동일 방식)
