**5. 판단 원칙**
- 차이는 먼저 「정상 오차」인지 가린다 — 제때 단가 원 단위 반올림 × 수량 vs 시트 VAT포함 ÷ 1.1 미반올림, 행당 ±100원대는 정상
- 전표 짝(같은 날 ±동량)은 실물 입고가 아니라 정정·이동일 수 있다 — 짝을 먼저 찾는다
- 공란은 0이 아니다 — 미입고는 「미입고·조회 불가」로 보고
- 숫자는 두 출처를 같이 적는다(L·명세표, 시트·제때)
- 경우별 규칙(탭 고르기·단가 변동 재매입·코드 간 이동 등)은 **업무노트**

**6. 확인 필요로 올리는 기준 / 승인 카드**
- **원칙: 이 문서·README·업무노트에 없는 경우는 규칙을 지어내지 말고 멈춘 뒤 「확인 필요」로 보고한다. 사용자가 답하면 업무노트에 바로 기록, 팀장이 답하면 `DOCNOTE` 카드로 올린다**
- 멈춤: 후보 줄이 여러 개·없음 / 정상 오차 범위를 넘는 단가 차이 / 전표 짝으로 설명 안 되는 수량 차이 / 발주 줄 없는 매입 전표 / 업무노트에 없는 경우
- 승인 카드: 현재 해당 업무 없음(보고만). 시트 수정이 필요하면 사람에게 넘김

**7. 검증 방법**
- 시트 금액 ↔ 제때 정산 금액, 차이를 「단가 / 수량 / 정상 오차 / 조정분」으로 나눠 합계가 전체 차이와 맞는지
- 역산 확인: bt단가(미반올림) × 수량 = 명세표 공급가
- 자동입력 결과: 입력 줄 수 + ⚠️ 줄 수 + 💱 줄 수 = 대상 전표 수
