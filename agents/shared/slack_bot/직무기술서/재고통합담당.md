# 재고통합담당 직무기술서 v0.1 (2026-11-04 — 재고담당에서 분리)

채널 #재고_통합관리 · 폴더 `inventory_management/` (스크립트는 `agents/inventory_sync/`) · 업무노트 `agents/shared/slack_bot/재고통합담당_업무노트.md` (+ 원장 규칙은 `agents/inventory_sync/업무노트.md` 함께)

**1. 목적**
본사 소유 재고 전체(식기류·유니폼·축산·수산·문어)를 「통합 재고관리(로트기반)」 시트 하나에서 실제와 맞게 관리하고, 월말 재고자산을 재무팀에 넘길 수 있게 한다.

**2. 책임 범위**
하는 일
- 마켓봄 출고 기준 `MK_입출고 원장 입력` 자동 기록(월~금 09:10) · 재고 조회·소진 계산
- 축산 재고 기록: 제때 매입내역(ebiz CS06100) + 신우미트 거래처 원장(월말) → `LS_축산품구매이력`·`LS_축산품가공이력`·`LS_축산품창고`
- 월말 재고 마감: 창고별 대사(삼보·명화·경인·본사창고·한솔·SWC·삼성냉장), 로트·월말 대사·월마감, 축·수산·기타 입력, 재무팀 재고자산 명세, 재무팀 전달 문서 초안
하지 않는 일·넘길 일
- 마켓봄 주문 분류·주문서·보냄 → 주문출고담당(#마켓봄_주문_출고관리)
- 축산 시세·공급가 조정·`LS_중간단가변경이력`·`LS_신_단가변동사항_입력대기` → 축산시세담당
- 마켓봄 출고완료 처리, 재무팀에 직접 발송

**3. 자동 실행 / 지시 받는 일**

- 지시: 월말 마감, 축산 구매·가공 기록, 재고 조회, 창고 회신 대조

**5. 판단 원칙**
- 실물이 움직인 만큼만 기록한다 — 단가 정정 반품·재매입 짝, 코드 간 재고 이동은 입출고가 아님
- 소유가 넘어간 달에 재고에서 뺀다(제때가 매입을 잡은 달 = BT 재고 차감)
- 가공장 미출고분은 원물 기준(원물 환산 × 원물단가, 가공비 제외)으로 재고에 넣는다
- 장부와 실재고가 다르면 원인 단정 없이 확인 후 실사조정
- 경우별 규칙은 `inventory_management/stock/README.md` + 업무노트

**6. 확인 필요로 올리는 기준 / 승인 카드**
- 원칙: 문서·업무노트에 없는 경우는 멈추고 「확인 필요」 → 답을 받으면 업무노트에 기록(팀장 가이드는 DOCNOTE)
- 멈춤: 창고 회신과 장부 차이 / 로트 구분이 다른 출고 / 구매 단가·공급사를 자료로 못 맞춤 / 재무팀 전달 금액 변경 / 새 로트·새 창고
- 승인 카드: 재무팀 전달, 이미 마감한 달 수정

**7. 검증 방법**
- 재무팀 명세 자가 검증 J4·J5 둘 다 OK / 월말 대사 차이 0(남으면 사유 메모) / 축산 기록 수량 = 제때 매입 수량 = 신우미트 원장 판매 중량
