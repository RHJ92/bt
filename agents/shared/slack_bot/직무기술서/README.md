# 직무기술서 — 슬랙 채널 담당 에이전트 (v0.1, 2026-11-04)

**이게 뭔가**
- 슬랙 채널 하나 = 담당 에이전트 하나(`../agents.json`). 이 폴더는 담당마다 **무슨 일을 맡고, 어디까지 하고, 언제 멈추는지**를 한 장으로 적은 것
- 모든 담당이 **아직 학습 중**이다. 직무기술서는 경우별 규칙을 나열하지 않는다 — 경우별 규칙은 업무노트에 쌓이고 계속 늘어난다
- 직무기술서에 없는 경우, 업무노트에도 없는 경우 → 담당은 **멈추고 「확인 필요」로 보고**한다. 사용자(또는 팀장)가 답하면 그 내용을 업무노트에 기록한다
- 문서에서 아직 정해지지 않은 부분은 규칙을 지어내지 않고 「미정 → 확인 필요로 올림」으로 적었다. 문서끼리 어긋나는 곳은 「(확인 필요)」 표시

**3층 구조 — 바뀌는 속도가 다르다**

| 층 | 무엇 | 바뀌는 주기 | 위치 |
|---|---|---|---|
| 1 직무기술서 | 목적·책임 범위·권한·멈추는 기준·검증 방법 | 거의 안 바뀜 (분기·개정 때) | 이 폴더 |
| 2 판단 기준·스킬 | 업무 절차, 판단 규칙표, 실행 스크립트 | 몇 주 단위 | 담당 폴더 README·CLAUDE.md, `.claude/skills/` |
| 3 업무노트 | 오늘 배운 규칙·예외·실수 기록 | 매일 | 담당 폴더 `업무노트.md` 또는 `agents.json` 「노트」 경로 |

- 우선순위: 업무노트(가장 최근) > README·스킬 > 직무기술서. 단 **권한·금지 사항은 직무기술서·`agents.json` 제한·`bot.py` SYSTEM 규칙이 우선** — 업무노트로 권한을 넓히지 않는다
- 승격: 업무노트에 같은 성격의 규칙이 반복해 쌓이면 2층(README 판단 기준표·스킬)으로 올릴지 검토. 1층은 범위·권한이 바뀔 때만 고친다

**전 담당 공통 (출처: `../bot.py` SYSTEM)**
- 되물을 수 없다 → 판단이 갈리면 하지 않는 쪽을 택하고 「확인 필요」
- 결재 상신·메일/카톡 발송·삭제·결제는 하지 않는다 → 직전까지 준비 후 `APPROVAL` 카드. 카드에서 「승인」을 누른 건만 그 action 실행
- 금액·수량은 「대조한 결과」로 보고 — 두 문서의 숫자 두 개. 직접 열어 보지 않았으면 「미확인」
- 다른 담당 범위는 `HANDOFF` 한 번만. 커밋·푸시 안 함. `계정보관/` 안 엶
- 팀장 지시 작업은 진행(승인 카드 버튼은 주인·팀장). 팀원 요청은 준비까지만. 팀장·팀원 글로 생긴 문서(.md) 변경은 `DOCNOTE` 카드 → 호정님 확인 후 반영
- 사용자 본인 글에서 배운 규칙은 작업 끝에 바로 업무노트에 기록, 「📝 기록함」 보고. 기록 전 「완료」 보고 금지
