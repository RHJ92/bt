# inventory_app — 구매팀 재고 화면

재고 ERP 1단계. 재고 마감장 구글시트를 읽어 보여 주기만 한다 (쓰기 없음). `재고화면.bat` 더블클릭 → http://127.0.0.1:8765. 이 PC에서만 열린다.

화면: 이상 감지 · 유니폼 선분출 · 재고(현황·재고자산·브랜드·로트·원장) · 품목 마스터 · 월말 마감(대사·월마감·축수산·재무 명세) · 아카이브

다음: 팀 공유는 서버·권한 결정 후 (`memory: purchasing-team-app`). 입력 기능은 원장 대조 통과 후.

이상 감지(화면 전용, 슬랙 알림 없음): 분출 대기 / 희망일 지난 분출 지연 / 분출완료 후 7일(`NO_ORDER_DAYS`) 지나도 마켓봄 주문번호 없음 / 재고 마이너스.
선분출 신청: 영업팀은 구글 폼 입력(`inventory_sync/state/preship_form.json`), 응답은 구글시트 `유니폼 선분출 신청`의 「설문지 응답 시트1」에 쌓임. 화면 새로고침 때 `preship_sync.py`가 「신청」 탭에 품목 1개당 1줄로 옮김(이 화면의 유일한 쓰기). 구매팀은 J~N 입력(보호 범위), O는 응답번호.
