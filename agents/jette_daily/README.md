## 2. 방식 (2026-10-29 사용자 결정: 무인 자동)

- 스크립트가 ebiz에 **직접 로그인 → 화면이 쓰는 데이터 요청을 그대로 호출 → 시트에 값 쓰기**
- **원칙 예외 2호**: 웹 로그인 자동화. 사유 — 매일 9:10 마감 작업을 계정 2개 × 조회 5회 수작업으로 하고 있음. 비밀번호는 Windows 자격 증명 관리자(`jette-ebiz-옥된장`, `jette-ebiz-철산장`)에만
- 실패(로그인 화면 변경·보안문자 등) 시 시트는 건드리지 않고 알림만 → 그날은 사람이 수동

## 3. ebiz 조사 결과 (2026-10-29, 옥된장 본사 계정 로그인 상태에서 크롬으로 확인)

**데이터 요청 — 단순함.** 화면 그리드는 `POST /api/...`에 JSON을 보내고 `{"_Datatable":[...]}`를 받는다. 로그인 쿠키 외 별도 토큰 없음. 직접 호출 결과 = 화면 그리드 행수 일치 확인

| 시트 블록 | 화면 | API | 요청 JSON 키 |
|---|---|---|---|
| 재고현황 1~3 | 주문관리 → 주문대비 재고 조회 (`CS06/CS06230`) | `api/CS06230/CS06230_GetDataTopGrid` | `:YYMMDD`(화면 기본값 = 다음 배송일), `:OWNERID`(옥된장 3680), `:VENDORID`(블루푸드랩 JT01036 / 블루트렌드 JT01057), 나머지 `:CENTERID`·`:STOCK_TYPE`·`:ITEM_STATUS`·`:ITEMNAME` = null |
| 주간 매출 | 주문관리 → 주문내역 조회(가맹본부) (`CS06/CS06050`) **제품별 탭** | `api/CS06050/CS06050_GetGrid_TAB2` | `:SHIPDATE_FROM`·`:SHIPDATE_TO`(YYYYMMDD), 나머지 `:ORDERDATE_*`·`:OWNERID`·`:SHOPID`·`:ITEMNAME`·`:ORDER_STATE`·`:ORDER_TYPE`·`:CENTERID`·`:ITEM_USING`·`:CATEGORY1`·`:CATEGORY2` = null |

- 시험 호출(10/29): 재고 블루푸드랩 18행 = 시트 2~19행. 매출 10/26~10/31 3,197행(확정 3,099·저장 98) — 시트 아침 붙여넣기 3,073행 이후 늘어난 분
- 매출 TAB2 응답 33개 필드 = 시트 34열에서 No 뺀 것과 순서 일치 (SHIPPING_DATE·ORDER_DATE·ORDER_TYPE·ORDER_STATE·BRANDNAME·SHOPNAME·CENTERID·CENTERNAME·ITEMID·ITEMNAME·ITEM_USING·CATEGORY1_NAME·SALE_UNIT·TAX_GUBUN·OM_QTY·OUT_QTY·NO_QUT_QTY·UNIT_PRICE·SUPPLY_PRICE·VAT·TOTAL_AMOUNT·RETURN_DATE·RETURN_REASON·TEMP_GUBUN·ORDER_NO·LINE_NO·OUT_BY·OWNER_ITEMID·OUT_SHOPID·SHOPID·BUSINESS_NO·CREATE_BY·UPDATE_BY). 응답 필드 순서는 화면과 다르므로 열 매핑은 이름으로
- 시트는 붙여넣을 때 숫자로 변환돼 **원값**(주평판 21.8 등)으로 저장돼 있음 — 보이는 반올림은 열 서식. → API 원값을 그대로 USER_ENTERED로 쓰면 됨
- 재고 「매입사명」 열은 기존 붙여넣기에서도 빈칸 → 비워 둠. 매출 합계행의 「########」는 ebiz 화면 열 폭 때문에 복사된 글자 → 자동화는 실제 합계 숫자를 넣음
- 재고 조회 날짜 = 화면 기본값 **내일**(`(new Date()).addDays(1)`)
- 철산장 계정: 미확인 (OWNERID·매입사 값 따로 확인)

**로그인 — `POST /api/CommonApi/Login`** (JSON: userId·password·authNum·rtnNum·uniqueId·remember_p_yn). 보안문자 없음. 응답 `RETURN` 코드:
- `Y` = 아이디·비번만으로 인증 / `YS` = **문자(SMS) 인증 추가 필요** / `YY` = 문자 인증까지 완료
- `85` = 인증되지 않은 기기 / `80` = 비밀번호 변경 필요 / `82` = 비밀번호 틀림 / `92` = SMS 인증 만기
- → **계정이 매 로그인마다 문자 인증을 요구하면 무인 로그인 불가.** 사용자 확인 필요(§4)
- 로그아웃: `GET /home/logout`

## 4. 확인 필요 (사용자)

- ✅ 주간 탭: 매일 **전체 행 삭제 → 해당 주 다시 조회 → 전체 붙여넣기** (2026-10-29)
- ✅ 새 주(2026-11-02~ 자동): 오늘이 든 주간 탭이 없으면 가장 오래된 주 탭 이름을 이번 주(월~토)로 바꿔 맨 앞으로 옮기고, 종합현황 K~O 머리글(4행)·SUMIFS 탭을 오래된 주 → 최신 주 순서로 맞춘다. 사람이 먼저 탭을 바꿔 둬도 매 실행 `align_summary`가 어긋남만 맞춘다. **종합현황에서 쓰는 칸은 K4:O4와 K15:O의 SUMIFS뿐**, 나머지 금지. 정렬 전 값은 `state/종합현황_정렬전_YYMMDD.json`
- ✅ **새 주로 넘어가는 날 지난주 탭 보충** (2026-11-05 월~금 전환): 토요일엔 돌지 않으므로 리뉴얼하는 실행에서 지난주 탭(월~토)을 한 번 더 받아 덮어써 토요일 출고분까지 채운다(`refresh_prev_week`, 쓰기 전 `state/*_prevweek_backup.json`, 새 조회가 절반 미만이면 안 씀)
- ✅ **종합현황은 팀장님 관리 양식 — 자동화가 절대 건드리지 않음** (2026-10-29)
- ✅ 시트 쓰기 허용: `재고현황` 탭 전체, 그 주 매출 탭 전체 — 매일 전체 삭제 후 신규 업로드 (사용자 승인 2026-10-29)
- ✅ ebiz 로그인: **아이디·비밀번호만** (문자 인증 없음) → 무인 로그인 가능 (2026-10-29)
- ✅ 「합계」 행: **블록마다 모두 넣음.** 제목행은 **첫 블록에만**, 이어 붙이는 블록은 제목행 없이 데이터+합계만 (2026-10-29)
- ✅ 자동 리뉴얼 조건이 안 맞으면(일요일, 주간 탭이 5개가 아님, 같은 이름 탭 존재): **쓰지 않고 알림**(종료코드 2). 종합현황 구조가 예상과 다르면 예외로 중단

## 5. 구현 (`scripts/`)

| 파일 | 역할 |
|---|---|
| `ebiz.py` | 로그인·로그아웃, 재고(`stock`)·매출(`sales`) 조회. 조회 API만 씀 |
| `set_ebiz_password.py` | 계정 등록(별칭 옥된장/철산장 → 아이디·비밀번호) + 로그인 시험. 아이디 `shared/config/jette_accounts.json`, 비밀번호 자격 증명 관리자 `jette-ebiz` |
| `../run-jette-daily.ps1` | 스케줄러가 부르는 실행기. `run_daily.py --write` → 로그(`logs/`) → 토스트 알림. `-DryRun` = 비교만 |
| `../register-task.ps1` | 작업 「제때 일일 조회 (월-금 8시10분)」 등록/해제(`-Unregister`). 놓친 실행은 PC 켜면 따라잡기, 절전이면 깨움 |
| `run_daily.py` | 조회 → 블록(No+데이터+합계) 조립 → 시트와 행수 비교. `--write` 줘야 시트에 씀. 쓰기 전 현재 값 `state/*_backup.json` 백업 |

- 쓰는 범위: `재고현황`·그 주 탭의 **A2:AH 값만** (1행 제목·서식 유지). 종합현황 등 다른 탭 접근 없음
- **병합 셀 (2026-10-30 발견, 2026-11-02 해결)**: 지난 붙여넣기의 합계행 자리에 남은 병합이 데이터행을 덮던 문제. `prepare_tab`이 쓰기 전 2행 아래 병합을 해제하고, 데이터가 탭 행수를 넘으면 행을 추가한다 (재고현황은 119행까지뿐). 쓰기 후엔 행수 + 제품코드(재고현황 D·주간 J)를 대조한다
- **연결 재시도 (2026-11-02)**: 구글·ebiz 요청은 `retrying_session()`으로 끊김·5xx 때 간격을 늘려 5회까지 다시 시도. 부팅 직후 따라잡기 실행이 10053으로 죽은 게 계기
- 주간 탭 = 이름 `MMDD~MMDD`에 오늘이 들어 있는 탭. 없으면 중단(시트 안 씀)
- **확인됨(2026-10-29): 스크립트가 로그인하면 같은 계정의 브라우저 ebiz 세션이 로그아웃됨** (크롬 탭이 로그인 화면으로 바뀜) → 08:10 실행 후 ebiz를 쓰려면 다시 로그인해야 함
