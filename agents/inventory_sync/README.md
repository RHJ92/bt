# inventory_sync — 마켓봄 → 재고 입출고 원장 자동화

마켓봄 9517(블루트렌드: 옥된장·석문어·정백선) 주문을 읽어 재고 조회·소진 계산, 이후 입출고 원장 차감까지 자동화하는 거점. 슬랙 #마켓봄_주문_출고관리(주문출고담당) · 원장·재고 마감은 #재고_통합관리(재고통합담당, 2026-11-04 분리).
재고 파일·월말 대사의 원본 규칙은 `inventory_management/`, 업체별 출고 요청 규칙은 `shipping_request/` — 이 폴더에서 고치지 않는다.

## 범위

- 재고 원장: **마켓봄 9517 계정 하나** (로트 원장 51행·품목 마스터 64개와 1:1). 3802(업체 직배송, 차감할 로트 없음)·10509(재고 장부에 없음)는 원장 범위 밖
- 일일 주문 처리: **9517·3802·10509 전부** (2026-11-02 사용자), 매일 오전 9시. 주문번호가 2개 업체로 나뉘면 **두 업체 주문서가 모두 나간 뒤에** 출고완료
- 지금 단계: **쓰기 없음.** 마켓봄·시트·엑셀 어디에도 쓰지 않는다
- 금액 기준 전사 재고의 대부분은 마켓봄 밖(축·수산) → 이 자동화는 식기류·유니폼 원장 범위

## 일일 주문 처리 (2026-11-02 시작, 미리보기)

- 봇이 **월~금 09:00** `scripts/daily_orders.py` 실행. 주문 마감 09:00, 그 뒤 주문은 다음 영업일(월요일엔 주말 주문 포함) → 출고처별 주문서를 `output/YYMMDD/`(깃 미추적)에 만들어 #마켓봄_주문_출고관리 스레드에 파일 + 「📨 보냄」 버튼 게시. 마켓봄·시트에 쓰지 않음
- 「보냄」 = 사람이 카톡으로 보낸 뒤 누름 → `state/sent.json` 기록, 다음 날 출고전으로 또 보여도 주문서 중복 생성 안 함. 주문번호의 모든 출고처가 보냄이 되면 **봇이 바로 마켓봄 출고완료 처리**(2026-11-04 사용자 지시 「보내기 누른 건은 출고완료 처리까지」 — 보냄 = 승인). `scripts/ship_done.py`: 주문별 목록 `/vendor/order/olist`에서 주문번호 → 내부 번호, 출고전(OS001)만 요청, 요청 뒤 다시 읽어 출고완료(OS002)로 바뀐 것만 ✅. **출고완료를 돌릴 때마다 「디자인물만인 출고전 주문」(디자인물, 또는 디자인물+배송비만)을 `design_only()`로 찾아 같이 처리**한다 — 주문서·보냄이 없어 그냥 두면 계속 출고전으로 남기 때문(사용자 지시 2026-11-05). 구매팀 품목이 섞인 주문은 넣지 않고 보냄 경로로만. 결과는 스레드 + `state/shipped.json`, 실패는 #할일-확인필요
- 양식: 가야김치·삼보·경인양행은 지난 파일 복사, 천안은 복사용 텍스트, 그 외 기본 양식(`make_requests.py`). 실제 발송본 3종(가야·삼보·본사)과 칸 단위 일치 확인, 경인양행·천안은 미대조
- 배송지는 `shipping_request/reference/` 거래처 파일. 새 지점이 없으면 「확인 필요」로 올라옴 → 거래처 파일 다시 받기
- 사용자가 확인한 출고처는 `출고처_매뉴얼.json`에 쌓는다. 없는 품목은 「확인 필요」로 올리고, 답을 받으면 담당이 한 줄 추가 → 다음 실행부터 자동. 직배송(공급사→매장, 정산은 블루트렌드 경유)은 유형으로 표시해 원장 차감에서 뺀다
- 분류 규칙 원본은 `shipping_request/README.md` 업체 매칭표. 표에 없으면 임의로 넣지 않고 「확인 필요」. 삼보 수량은 낱개 환산(`100ea` × 1 → 100)
- 검증: 9·10월 주문 ↔ 주문번호 있는 지난 요청서 7건 전수 일치(환산 포함). 경인양행 파일은 주문번호 열이 없어 미대조
- 첫 실제 출고완료 2026-11-05 성공(삼보 IDZYnba042611010·가야 KYAKepf042611011) — 11/04~05 실패분은 `action=delivery_end` 누락이 원인이었고 고친 뒤 재실행해 OS002 확인
- 다음: 원장 차감 미리보기

## 차감 규칙 (기존 마감 규칙 승계)

- `출고완료`만, 일자는 **배송요청일**, 디자인물·식자재·배송비 행 제외
- 반품은 자동화 밖: `반품접수` 줄은 차감하지 않고 담당 채널로 올려 상세화면 확인 (목록에 반품수량 열이 없어 부분반품이 안 보임)
