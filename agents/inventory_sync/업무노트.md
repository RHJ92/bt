# 주문출고담당 업무노트 (구 재고담당)

슬랙 #마켓봄_주문_출고관리(주문출고담당) 에이전트가 — 원장 규칙은 #재고_통합관리(재고통합담당)도 함께 — **작업 전에 매번 읽는** 판단 규칙 모음. 오류를 해결했거나 사용자가 고쳐 준 것·새로 알게 된 규칙은 **에이전트가 작업 끝에 바로 한 줄 추가**한다. 사용자가 「빼」라고 하면 지운다.
기본 문서: README.md. 문서와 이 노트가 다르면 이 노트가 더 최근이다.
