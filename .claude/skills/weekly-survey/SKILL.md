# 축산품 주간 실측 (/weekly-survey)

너는 F&B 구매 10년차의 어시스턴트다. 아래 절차를 **순서대로, 빠짐없이** 수행한다.
상세 배경은 `agent_livestock_products/CLAUDE.md` 필독.

## 0. 준비 — 기준 데이터 로드

1. 노션 **품목 상태판(마스터)** (data source `f6c565f1-f7f7-487f-99bc-f265da01b470`)에서 전 품목의
   품목 / 온도 / 상태 / 원산지 / 브랜드 / 등급 / **미트박스 검색어** / 마지막 검토일을 조회한다.
   - 노션 접근: 대화 세션이면 claude.ai 노션 커넥터, 무인 실행이면 REST API
     (`NOTION_API_TOKEN` — PowerShell에서 `[Environment]::GetEnvironmentVariable("NOTION_API_TOKEN","User")`로 읽기,
     헤더 `Notion-Version: 2022-06-28`).
2. **시세 원장** (data source `b36d6ade-2001-4a80-96e2-4d4aee9f4c47`)에서 직전 조사일의 전 행을 조회한다
   (품목명·kg당 시세·신호태그·재고·판매자수). 이것이 전주 비교 기준이다.
3. 관측 대상 = 마스터에서 **미트박스 검색어가 채워진 품목 전부** (부속 완제 4종 오소리·돈두·염통·소창은 검색어 없음 = 주간 관측 제외).

## 1. 미트박스 실측

각 품목의 검색어로 `https://www.meatbox.co.kr/fo/search/searchPage.do?searchText=<URL인코딩 검색어>` 를 WebFetch로 읽는다.

**요약 프롬프트 규칙 (오조회 방지 — 필수):**
- 특정 브랜드로 좁혀 읽지 말고 **전 매물을 나열**시킨다: 상품명 원문 / '냉장' 표기 유무 / 브랜드 / 등급·가공장 넘버 / kg당 가격 / 재고·품절.
- 대표가 선정은 나열 결과를 **마스터 조건으로 필터**한 뒤:
  1. 마스터 온도가 냉동이면 '냉장' 표기 매물 **제외** (냉장 표기 없는 매물 = 냉동 간주)
  2. 마스터 브랜드 목록 내 매물만 (PB '당당한컷' 등 가공장 미상은 참고값으로만 별도 기록)
  3. 남은 매물 중 **재고 최다 = 대표가**, 밴드(최저~최고)를 비고에 병기
  4. 처분 의심(대량재고인데 튀는 저가·소비기한 임박·단발 판매자)은 대표가에서 제외, 신호태그 `처분 의심`
- 프리미엄 스펙 품목(미박삼겹·한돈목살 칼집): 대표가는 프리미엄 밴드(미박삼겹=탐라애돈류). 일반 밴드는 참고.
- 마스터 스펙 매물이 없으면(예: 스위프트 전지 원물) "스펙 매물 부재"를 명시하고 유사 스펙 대용치를 기록.

## 2. 해외 지표

- 미국 컷아웃: WebSearch로 "USDA choice beef cutout value <최근 금요일 날짜>" 검색 → AMS 일일 요약 PDF(lsddcbs)에서 Choice/Select 값·도축두수 확인.
- 호주 관세·스크루웜·ASF 등 시황 뉴스는 전주 카드의 "다음주 확인" 항목 위주로만 추적.

## 3. 검증 게이트 (기록 전 필수)

- 품목별로 전주 대비 증감률 계산. **±10% 이상 변동 시 그대로 기록하지 말고**:
  1. 스펙 오매칭 의심 → 냉장/냉동 표기·브랜드·등급을 재확인(해당 검색을 다시 읽어 상품명 원문 대조)
  2. 재확인 후에도 실제 변동이면 비고에 "재확인 완료, 실제 변동" 명시
- 전주 행과 평균유통규격이 달라지면 이유를 비고에 기록(스펙 변경은 시계열 단절이므로 신중히).

## 4. 시세 원장 기록

품목당 1행 생성 (data source `b36d6ade-...`). 필수 속성:
품목명(전주 행과 동일 표기) / 조사일(오늘) / kg당 시세(대표가) / 냉장·냉동 / 데이터유형=실측매물 /
브랜드·판매자 / 원산지 / 재고·판매자수 / 신호태그(시세·처분 의심·강세) / 출처=미트박스 / 출처 URL(검색 URL) /
평균유통규격(전주와 동일 문구 유지) / 관련 품목(마스터 행 relation, 전주 행과 동일) /
비고(밴드·참고 매물·전주 대비 코멘트).

## 5. 주차별 시황 카드 초안

data source `5047f9a7-7f14-40e4-b8ac-ad3f04dba5ff`에 3장 생성:
`<YYYY>-W<주차> · 수입 소(미국·호주)` / `· 국내 돼지` / `· 수입 돼지`.
- 속성: 기준일/축종/원산지 구분/시장 방향/전주 대비/확신도/핵심 지표/시황 요약/시사점·대응/근거 시세(오늘 원장 행들 링크)/**검토 상태=초안**.
- 시사점에는 반드시: 공급가 함의(인상·동결·인하 검토), 비축·대체 기회, **다음주 확인 항목**.
- 컷아웃→국내 반영 래깅(심리 1~3주, 원가 ~2개월)을 해석에 반영. 신호 해석·판단 기준은 작업 MD와 CLAUDE.md를 따른다.
- **에이전트는 절대 '확정'으로 표시하지 않는다. 마스터·작업 MD 등 기준 문서도 수정하지 않는다** (발견한 문제는 카드 시사점에 "확인 필요"로 적는다).

## 6. 마무리

1. 관측한 마스터 행들의 "마지막 검토일"을 오늘로 갱신.
2. 보고 문안 3줄 작성 (팀장·대표께 그대로 읽는 단정한 문장 — 시장 방향 + 핵심 근거 + 대응).
3. 결과 요약 출력: 품목별 전주 대비 표 + 보고 문안 + 검토 요청 목록(초안 카드 링크, ±10% 변동 품목, 스펙 매물 부재 품목).
