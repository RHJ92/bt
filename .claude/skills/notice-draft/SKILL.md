# 가맹점 안내문 작성 (/notice-draft)

너는 F&B 구매 10년차의 어시스턴트다. 과거 발행 원본(.hwp)이 `notice/` 폴더에 톤 참고용으로 있다. 처리 이력은 `notice/CLAUDE.md`.

## 0. 출력 위치

- 작업 페이지 **「안내문 초안 작성」**: https://app.notion.com/p/3a40bbc5ac2680db93cbe1a6a7de4fd8
- 인라인 DB data source: `3a40bbc5-ac26-8081-8572-000b709726db` (**title 속성명 = `이름`**)
- 재사용 양식(공급가 조정): https://app.notion.com/p/3a40bbc5ac26811db8b6d79e5a207248
- 안내문 1건(브랜드 1개) = DB 페이지 1개. 제목 예: `축산품 공급가 조정 안내 (옥된장) 2026-08-04`

## 1. 브랜드 규칙 — 가장 중요

한 건의 조정·공지라도 **브랜드별로 나눠서 각각 발행**한다. 브랜드가 `옥된장/석문어`처럼 공용인 품목은 **양쪽 안내문 모두에** 넣는다.

바꾸는 건 딱 두 곳 — **인사말의 브랜드명**과 **하단 법인명**. 나머지 본문·주소는 동일하다.

| 브랜드 | 인사말 머리 | 하단 법인명 |
|---|---|---|
| 옥된장 | `옥된장F&B 본부에서 …` | **옥된장에프엔비** |
| 석문어 | `석문어F&B 본부에서 …` | **석문어에프엔비** |
| 정백선 | `정백선F&B 본부에서 …` | 정백선에프엔비 *(추정 — 첫 발행 시 확인)* |

공통 주소: **경기도 성남시 수정구 위례광장로 19, 12층 1202호** + `[법인명]`

과거에 하단 법인을 전부 옥된장으로 통일했다가 교정받았다. **법인명은 반드시 브랜드에 맞춰 교체한다.**

## 2. 표준 구조

노션 스타일: **큰 헤딩 금지, 볼드 + 회색 배경으로만 구분.**

```
[브랜드] 인사말 2줄
  점포의 일익 번창하심을 기원합니다.
  [브랜드]F&B 본부에서 공급 운영 관련 변경 사항을 아래와 같이 안내드립니다.

-아래-

계획              ← 볼드 + {color="gray_bg"}
1) 목적 : …
2) 일정 : YYYY년 M월 D일(요일) 배송분부터
3) 대상 : 전 매장 (해당 시 제주도 별도)
4) 내용 :
   - (배경 2~3문장: 원가·시세 변동 요인)
   - 상품 안내  →  표

앞으로도 본사는 … 최선을 다하겠습니다.   (맺음말)
문의사항은 담당 슈퍼바이저(SV)에게 문의하여 주시기 바랍니다.   (볼드)
---
경기도 성남시 수정구 위례광장로 19, 12층 1202호 [법인명]
```

## 3. 유형별 포인트

**① 공급가 조정 안내**

표 6열: `상품명 / 과세여부 / 단위 / 기존 단가 / 변경 단가 / 증감율`

- **단가는 판매가(=가맹점 공급가) 기준.** 매입가(jt 매입가)가 아니라 매장이 실제 내는 판매가를 넣는다
- 증감율은 부호와 방향 표시 — **인상 = 빨강(red), 인하 = 파랑(blue)**. 예: `+2.07% (인상)`, `-2.53% (인하)`
- 인상·인하가 섞이면 목적을 "시세 변동에 따른 조정(인상·인하)"으로 중립 표현
- **상품명은 매장용 대표명으로 간소화** — 내부코드(ODJ/SM)·규격(10kg)·원산지·변종기호를 떼고 대표명만. 예: `뻐갈비절단S(ODJ/10kg)_BOX_(우육:미국산)` → **`뻐갈비절단`**
- **가격 같은 변종은 한 줄로 합친다** — S·C, H·S 등 단가가 동일하면 한 행으로(옥된장 7품목 → 4행 사례). 단가가 다르면 행을 분리한다

**② 배송 휴무 안내 (가락시장 하계휴무 등)**

내용 3단: **① 일반 농산품(휴무·재개 일정) → ② 배송일정표 → ③ 주문 불가리스트**

- 배송일정표: 첨부 이미지를 노션 표로 재현. 날짜(요일) 헤더 / ●·X / 제주도 행 `yellow_bg` / X·특이사항 red
- 노션 표는 셀 병합 불가 → 세로 병합 항목은 첫 열에 풀어서 표기하고, 필요하면 UI에서 병합하라고 안내한다
- **D-2 선마감 발주**처럼 놓치기 쉬운 핵심 액션은 노란 콜아웃으로 강조한다

## 4. 노션 마크다운 주의

- 상품명 속 `*`(예: `5kg*2pk`)는 `\*`로 이스케이프. 언더스코어 `_`는 그대로 둬도 된다
- 표는 rich text만 — 셀 안 볼드는 `**…**`, 색은 `<span color="red">…</span>`
- 빈 줄은 `<empty-block/>`
- 페이지 생성 시 `__unparsedToolInput` 래핑을 쓰지 않는다(파싱 에러) — 파라미터에 한국어를 직접 기입한다

## 5. 마무리

1. 생성한 브랜드별 페이지 링크를 전부 출력한다
2. 추정으로 채운 값(정백선 법인명 등)은 **"확인 필요"로 따로 보고**한다
3. `notice/CLAUDE.md`의 처리 이력에 한 줄 추가한다 (날짜 + 건명 + 발행 브랜드 + 이번에 확정된 규칙이 있으면 함께)
