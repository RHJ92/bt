떠리몰 — 돼지꼬리 위탁판매 정산 (2026-10 ~ 2026-11 판매분, 이후 종료)

**담당:** 슬랙 #공통_매출수수료_정산 (매출수수료담당). 정산서 다운로드는 호정님이 직접 하고 파일을 채널에 올린다(담당은 로그인하지 않음, 2026-11-06 사용자)

**구조**
- 떠리몰(파트너센터 https://partner.thirtymall.com/settlements, 몰 화면 표기 「떠리몰」·「샵바이 정산현황」)은 수수료 기반 위탁판매 몰. 블루트렌드가 상품을 올리고 직접 택배 출고(파트너배송, 무료배송 → 택배비는 블루트렌드 부담), 고객 결제는 떠리몰이 받음
- 상품: 한돈 돼지꼬리(스킨제거) 10kg 대용량, 판매가 26,990원(면세), 수수료율 15%. 재고는 한솔냉장·삼보물류 보관분(재고통합담당 원장)
- 매월 구매확정분을 모아 떠리몰이 판매수수료를 뺀 나머지를 입금
- 일정: 매월 6일 전월 정산서 오픈 → 10일 수수료 세금계산서(블루트렌드 메일) → 15일 정산금 입금
- 떠리몰 회신 담당: 민선아 팀장, 정준선 대리

**세금 (떠리몰 안내 + 검토)**
- 블루트렌드가 떠리몰에 계산서를 발행할 일은 없음
- 판매분: 결제가 떠리몰 명의라 「기타 매출」로 신고하라는 안내. 돼지꼬리는 면세 원물(정산서 과세유형도 「면세」) → 면세 매출로 볼지 재무팀 확인 중
- 수수료: 판매대행 용역이라 과세 — 떠리몰이 세금계산서 발행. 면세 상품 판매 관련 비용이라 매입세액 공제 여부는 재무팀 판단
- 10월 정산서 수수료 24,288 = 공급가액 22,080 + 부가세 2,208 로 딱 떨어짐 → 정산서 수수료는 VAT 포함 금액으로 보임. 10일 세금계산서 합계와 같아야 함

**증빙 (재무팀 회신 대기, 2026-11-06 문의)**
- 제안안: 판매분 = BT FLOW 매출내역서(판매액 전체, 발행 불요·신고용) / 수수료 세금계산서 = 지출결의서(판매수수료, 정산금 차감분이라 이체 없음) / 15일 입금은 대조만
- 재무팀 답이 오면 이 절을 확정 내용으로 고친다

**매월 검토 (정산서 올라오면)**
1. 「전체 합계」: 판매액(면세) − 판매 수수료 = 차가감 지급금액
2. 「샵바이 상세」: 주문별 판매가 × 수량, 수수료 = 판매액 × 15%(원 미만 버림), 환불수량·금액조정·파트너분담 할인 0인지
3. 판매 수량 ↔ 재고 원장 돼지꼬리 출고(택배) 수량 대조
4. 10일 세금계산서 합계 = 정산서 판매 수수료
5. 15일 입금액 = 차가감 지급금액
