## 3. 한 가지만 확인 — 5~7월 자료가 "정산명세"가 아니라 "발주·입고 명세"

1차와 2차의 첨부 자료 **포맷이 다릅니다.**

| | 2~4월 (1차) | 5~7월 (2차) |
|---|---|---|
| 시트 열 구성 | 수불일 / 지급구분 / 구분 / 공급가 구분 / 정산합계 | 발주일 / 입고확정일 / 발주확정수량 / 입고확정수량 / 이슈수량 / 클레임여부 |
| 성격 | 컬리 **정산 확정** 명세 | 컬리 **발주·입고** 리포트 |
| 반품 반영 | `구분` 열에 입고/반품 구분 존재 | 반품 열 자체가 없음 |
| 지급 회차 | `지급구분` 1~3회차 표기 | 없음 |

즉 2차는 컬리가 실제 정산한 확정 명세가 아니라, 발주·입고 기준으로 산출한 자료입니다. 이번 건은 이슈수량 0·클레임 0이라 결과적으로 차이가 없을 가능성이 높지만, **입고 후 반품·차감이 컬리 정산 단계에서 잡히면 이 자료에는 안 잡힙니다.**

→ 금액을 다투는 게 아니라, **1차와 같은 포맷(정산 확정 명세)으로 한 부 더 받아 대조**해두면 3차부터도 기준이 고정됩니다. 부담 없는 요청이라 이번에 정리해두는 게 좋습니다.
