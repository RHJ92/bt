# 메리고라운드컴퍼니 — 옥된장 IP 마켓컬리 수수료 (수취형)

메리고라운드가 옥된장 IP 상품을 마켓컬리에 공급하고, 그 **공급매출의 5%**를 IP 사용료로 블루트렌드에 지급한다.

- 담당: 신승민
- 정산 주기: **3개월 단위**. 1차 2~4월(지급완료) / 2차 5~7월 / 3차 8~10월 예정
- 대상: 단일 SKU — `[옥된장] 소고기삼겹 미나리 된장전골` (마스터코드 M00000754898 / 바코드 8809861821029)
- 판매 개시: 2026-02-19 (그 이전 판매분 없음)

## 정산 기준

| 항목 | 내용 |
|---|---|
| 요율 | 컬리 공급매출의 5% |
| base | **컬리 공급단가 × 입고확정수량.** 메리고의 매입원가가 아님 |
| 컬리 공급단가 | **8,950원 고정** — 2~7월 489행 전수 확인, 변동·행사가 0건 |
| 월 귀속 | **입고확정일 기준**(발주일 아님). 월 경계 행은 이 기준으로 판단 |
| 세금계산서 | 우리가 발행. IP 사용료는 과세 용역이므로 VAT 10% |

## 회차마다 하는 일

1. 요약표(메일 본문)와 첨부 상세내역을 **행 단위로 합산해 대조** — 월별 수량·공급가 전부
2. **`공급단가` 열 전수 확인** — 8,950원 외 값이 있는지, 행사·프로모션 공급가가 섞였는지
3. 차감 항목 확인 — `이슈수량`, `클레임여부`, `증정품여부`, `입고상태`, `발주확정수량 = 입고확정수량` 여부
4. 기간 정합성 — 직전 회차와 겹치는 달·빠진 달이 없는지. **입고확정일 기준**으로 월 경계 확인
5. 마감 확정 여부 — 마지막 달 입고확정일이 월말까지 차 있는지(잠정치 아닌지)
6. 계산서 발행 정보 확정 — 공급가액 / 세액 / 합계

## 주의점

- **VAT 포함 소계는 "소계 × 1.1"로 계산된 값이 맞다.** 월별 반올림값을 더하면 1원 차이가 나지만 세금계산서가 떨어지는 기준은 소계×1.1이므로 이의 제기하지 말 것
- **첨부 자료 포맷이 회차마다 다를 수 있다.** 1차는 컬리 **정산 확정 명세**(수불일/지급구분/구분/공급가 구분), 2차는 컬리 **발주·입고 명세**(발주일/입고확정일/이슈수량/클레임여부). 후자는 반품 열 자체가 없어 컬리 정산 단계의 차감이 안 잡힌다 → **3차부터 정산 확정 명세로 통일 요청함**
- 시트마다 **헤더 행 위치가 다르다** (7월 시트만 1행이 안내문, 헤더는 2행). 자동 탐지해서 읽을 것
