# 세금계산서 발행 요청 자료 — 리우 본부수익금

세무·회계 담당에게 전달할 발행 요청 증빙. 월별로 파일을 나눈다.

| 파일 | 대상 | 공급가액 | 세액 | 합계 | 작성 기준일 |
|---|---|---|---|---|---|
| `261006_세금계산서발행요청_26년8월분.xlsx` | 2026-08-24 ~ 08-31 (37건) | 121,279 | 12,128 | 133,407 | **2026-09-30 (지연 발행)** |
| `261006_세금계산서발행요청_26년9월분.xlsx` | 2026-09-02 ~ 09-29 (98건) | 461,901 | 46,190 | 508,091 | 2026-09-30 |
| **합계** | | **583,180** | **58,318** | **641,498** | |

각 파일은 ① 발행 금액 ② 거래 당사자 ③ 상품별 산출 근거 ④ 근거 자료·확인 사항으로 구성된다. 금액은 리우 원본에서 직접 집계한 값이고, 리우 신청서와 전수 일치하는 것을 확인했다.

## 재무팀 제출 세트

이 폴더를 통째로 전달하면 된다. 발행 요청서 2건 + 리우 원본 증빙 2건이다.

```
세금계산서_발행요청/
  261006_세금계산서발행요청_26년8월분.xlsx     ← 발행 금액·산출 근거
  261006_세금계산서발행요청_26년9월분.xlsx     ← 발행 금액·산출 근거
  리우원본_증빙/
    261006_리우_본부수익금신청_확정내역.xlsx   ← 리우가 확정한 월별 금액
    261006_리우_주문정산내역_건별상세.xlsx     ← 주문 건별 원천 데이터
```

| 증빙 파일 | 보는 법 |
|---|---|
| 본부수익금 신청 확정내역 | 한 시트에 월별 1행. **2026-08 행과 2026-09 행이 확정분**이고, 2026-10 행은 진행 중이라 확정 전이다 |
| 주문 정산 내역 건별상세 | 주문 1건 = 1행. **연도·월 열로 걸러서 본다.** 8·9·10월 외에 2024년 1~2월 과거 거래 26건이 섞여 들어오므로 집계에서 제외해야 한다 |

리우가 보내온 원본 그대로이며 가공하지 않았다. 받은 원본 전체 이력은 `statements/`에 날짜별로 남아 있다(10/2 최초 수령분, 10/6 재발행분). 9월분 수치는 두 판본이 행 단위까지 동일함을 확인했다.

## 거래 성격

본사(가맹본부)가 리우에 **용역을 제공하고 받는 수수료 매출**이다. 물건이 본사를 거치지 않고 리우 → 가맹점으로 바로 가므로, 본사가 발행하는 것은 상품 매출 계산서가 아니라 수수료 계산서다.

- 공급자: 주식회사 옥된장에프엔비 (506-81-94698)
- 공급받는자: 주식회사 리우 (257-81-01545)

> **실제 발행 법인은 블루트렌드다 (2026-10-19 확인).** 노션 「법인 매출 내역서」의 옥된장 8·9월분(133,407 / 508,091)이 매출법인 '블루트렌드'로 발행 완료됐고, 석문어·정백선분도 같은 기준으로 블루트렌드 명의 요청함. 위 '옥된장에프엔비' 표기는 초안 당시 가정이라 발행요청 엑셀 2건의 공급자 칸과 다름 — 재사용 시 고칠 것.

## 발행 기준 — 신청 파일의 지급 확정 금액에 맞춘다

**리우 「본부수익금 신청」의 지급 확정 금액이 정산 금액이다.** 세금계산서도 그 금액에 맞춰 발행한다.

기타 비용은 리우가 지급액에서 **차감한 뒤 입금**하는 구조다. 리우가 역으로 계산서를 발행해 돈을 따로 보내는 방식이 아니므로, 총액으로 끊으면 계산서 금액과 입금액이 어긋난다. **차감 후 순액으로 한 장만 발행한다.**

8월분 산출은 이렇게 된다.

| 구분 | 공급가액 | 세액 | 합계 |
|---|---|---|---|
| 본부수익금 | 133,093 | 13,309 | 146,402 |
| 기타 비용 (물티슈 차액 환급) | −11,814 | −1,181 | −12,995 |
| **발행 금액** | **121,279** | **12,128** | **133,407** |

> **금액을 바꿔야 하면 세금계산서가 아니라 신청 파일부터 수정 요청한다.** 계산서를 임의로 조정하면 신청 파일·입금액·계산서가 따로 놀게 된다.

## 짚어야 할 것 — 8월분 발행 시기

8월 공급분인데 발행 시기를 놓쳐 9월자로 발행한다. 공급시기와 작성일자가 어긋나므로 세무 담당 확인이 필요하다. 8월 수익금이 확정된 날은 10월 2일이다.

9월분은 기타 비용이 0원이라 계산서 금액과 입금액이 같다.
