## 2. 짚어야 할 것 — 우선순위 순

### ① 택배비 금액 — 해소됨 (4,000원 확정)

26.06 거래원장은 3,500원, **26.07 명세서(양재점 건)는 4,000원**으로 7월부터 인상된 것이 확인됐습니다. 별도 문의 불필요합니다. → [260731_7월명세서_검토.md](260731_7월명세서_검토.md)

가맹점 방향은 점주가 매입가 기준 10만원 이상 구매 시 무료배송이고 1개 단위 주문은 발생하지 않으므로 **택배비 손익은 검토 대상이 아닙니다.**

### ② 마진이 두 그룹으로 완전히 갈립니다

마켓봄 「단가 일괄수정」의 **`택배배송 단가` = VAT 포함 가맹점 판매가**입니다. 죽그릇 6,314 · 겉절이접시 7,645가 7월 주문내역 실청구 단가와 정확히 일치해 확인됐습니다. ÷1.1이 공급가입니다.

14품목 전체를 계산하니 **마진율이 3.97% ~ 35.67%로 품목마다 완전히 다릅니다.**

A그룹이 4%대로 얇긴 하나, 각인 상품은 배송 2주 소요라 몰아서 주문하는 구조이고 택배비도 점주 10만원 이상 구매 시 무료라 **당장 조치가 필요한 사안은 아닙니다.** 판매가 조정 논의가 생기면 A그룹부터 보면 됩니다.

### ②-1 개인접시만 마진율 35.67%

개인접시는 매입 3,300 → 판매공급가 5,130으로 **혼자 35.67%** 입니다. 같은 각인 도자기류가 전부 4%대인데 이것만 8배 넘게 붙어 있습니다.

- 판매가 5,130이 맞다면 → 매입가가 내려갔는데 판매가를 안 내린 것 (우리에게 유리, 가맹점 불만 소지)
- 매입가 3,300이 맞다면 → 판매가 갱신 누락

매입가는 견적서대로 확정됐으니 **판매가 설정 이력만 확인**해보시면 됩니다.

### ③ 레이저각인 매입 단가 — 해소됨

레이저각인 포함 매입 단가는 **견적서대로 확정**됐습니다. 인쇄비 가산액을 따로 뜯어볼 필요 없이, 월 명세서 단가가 견적서 단가와 같은지만 대조하면 됩니다.

(참고: 거래원장 「2026.06.05초도」 시트 K·L열에 명화 쪽 품번·단가로 보이는 데이터가 헤더 없이 남아 있으나, 스텐복냄비 행은 L이 `28㎝` 텍스트라 일관된 가격 열이 아니고 명화 공식 자료도 아닙니다. 지금은 볼 일 없습니다.)

### ④ 견적서와 마켓봄 상품명이 다른 것은 정상입니다

**마켓봄 상품명은 점주가 보기 편하도록 붙인 명칭**입니다. 견적서·명세서는 명화주방 품명 기준이라 서로 다른 게 맞고, **본사와 명화주방이 출고할 때 매핑표를 참고**하면 됩니다. 확인할 사안이 아니라 상시 참조 대상입니다.

| 견적서(명화 기준) | 마켓봄(점주 기준) |
|---|---|
| 직사각접시/소·대 | 돌문어숙회(소·대) |
| 다진양념통 | 스텐_다진마늘통 |
| 스텐복냄비 Φ240/Φ280/Φ340 | 스텐_전골냄비 (1인/2인/3인) |
| 문어볶음/소·대 | 문어볶음(소·대) |
| 스텐복냄비 Φ280 | **명화_**(석문어)스텐_전골냄비 (2인) — 이 품목만 접두어 |

매핑표는 고유키까지 붙여 산출물 엑셀에 정리해뒀습니다. **출고 대조용으로 쓰는 표**입니다.

**문어볶음 규격 차이 — 해소됨**
견적서 Φ275/Φ308과 마켓봄 31cm/34.5cm의 차이는 **손잡이 포함 여부**였습니다(마켓봄=포함, 견적서=미포함). 같은 물건이며, 혼선 방지를 위해 **마켓봄 규격을 견적서 기준으로 수정 완료**했습니다.

디저트 접시_도기 2건은 견적서에 없으므로 **명화주방 거래 품목이 아닙니다.** 이 표 대상에서 제외했습니다.

### ⑤ 견적서 파일 날짜가 6월 초도 건과 같아 헷갈립니다

견적서 파일명·문서일자가 **2026.06.05**인데, 같은 날짜의 6월 초도 실제 발주와 내용이 다릅니다.

| | 견적서(본사가) | 26.06.05 초도 실발주 |
|---|---|---|
| 품목 수 | 14 | 12 |
| 스텐복냄비 | Φ240×4, Φ280×20, Φ340×15 | Φ280×8 만 |
| 합계 | 3,625,490 | 2,977,238 |

**견적서는 8/5 확정된 표준 단가표**이고 6월 초도는 실제 발주 건입니다. 단가는 동일하니 문제는 없지만, 파일명에 확정일(260805)을 넣어 보관했습니다. 다음 회차부터 명화주방에 **문서일자를 확정일로 찍어달라고** 요청해두면 나중에 헷갈리지 않습니다.

## 3. 판매가 데이터 — 어느 열을 쓰는지

가맹점 판매가는 마켓봄 **「단가 일괄수정」** 양식에 있습니다(상품 일괄수정 양식이 아님 — 거기엔 단가 열 자체가 없고 `택배배송비` 열은 금액이 아니라 배송비 그룹명 `티타늄(식기류)`입니다).

| 열 | 값 | 쓰는가 |
|---|---|---|
| 매입 단가 | 전 품목 **0** | 미등록 |
| 직배송 단가 | 식기류는 전부 0 (계근 육류만 값 있음) | 아님 |
| **택배배송 단가** | 죽그릇 6,314 / 겉절이접시 7,645 … | **이 열이 가맹점 판매가 (VAT 포함)** |

7월 주문내역의 실청구 단가(죽그릇 6,314 · 겉절이접시 7,645)와 정확히 일치해 검증됐습니다. **공급가 = 택배배송 단가 ÷ 1.1** 입니다.

**마켓봄 `매입 단가`가 전 품목 0이라 시스템에서 마진이 안 보입니다.** 확정 견적이 나왔으니 매입단가를 등록해두면 마켓봄에서 바로 마진 확인이 됩니다. 등록 전에 매입 단가가 VAT 포함 기준인지(택배배송 단가와 같은 기준인지) 확인이 필요합니다.

## 5. 명화주방에 확인할 사항 — 없음

단가·택배비·규격·거래 품목 범위 모두 확정됐습니다. 다음 회차부터 명화주방에 요청해둘 것은 **견적서 문서일자를 확정일 기준으로 기재**해 달라는 것 하나뿐이고, 다음 견적 협의 때 같이 말하면 됩니다.
