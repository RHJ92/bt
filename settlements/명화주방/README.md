# 명화주방 — 석문어 테이블웨어 (지급형)

**명화주방 → 블루트렌드(본사) 매입 → 가맹점 판매(마켓봄)** 구조. 매입 단가 검증 + 재판매 마진 관리.

## 품목별 마진

가맹점 판매가는 마켓봄 「단가 일괄수정」의 **`택배배송 단가`(VAT 포함)**. 공급가 = ÷1.1.
14품목 마진율이 **3.97% ~ 35.67%**로 품목마다 다르고, 두 그룹으로 갈린다.

**판단**: 인상 후에도 15~20% 마진이 남아 수익성에 무리 없음. 각인 도자기류가 4%대로 얇긴 하나 **본사가 재고를 떠안지 않고 중개만 하는 구조**여서 전체 밸런스는 문제없다고 본다 (2026-08-05 담당자 판단).

**개인접시만 마진율 35.67%로 이상치.** 같은 각인 도자기류인데 혼자 8배 넘게 붙어 있어, 매입가·판매가 중 하나가 과거 단가에서 안 갱신됐을 가능성이 있다.

## 월 명세서 받으면 하는 일

1. 「월명세서」 건별 금액 합계 = 총합계 검산
2. 각 건별 시트에서 **단가가 확정 견적 단가와 같은지** 전 행 대조 (`reference/석문어테이블웨어_구매가판매가_마진.xlsx` D열이 대조 기준)
3. 수량 × 단가 = 금액, 부가세 10%, 각 건 합계 재계산
4. **택배비 붙은 건**: 해당 건 주문액(VAT 포함)이 10만원 이하가 맞는지, 금액이 4,000원인지 확인
5. **마켓봄 주문내역과 건별 대응 확인** — 각인 상품은 주문 후 2주 뒤 출고라 명화 청구일이 마켓봄 주문일보다 늦는 게 정상. **대응되는 마켓봄 주문이 아예 없는 건은 가맹점 청구 누락일 수 있으므로 반드시 짚는다**
6. 건별 마진 계산 (매입 공급가 vs 마켓봄 판매 공급가)
7. 신규 품목이 있으면 마진표에 행 추가하고 매핑 고유키 기록

## 자료 다루는 요령

- **견적서 품목명 ≠ 마켓봄 상품명 — 이건 정상이다.** 마켓봄 상품명은 **점주가 보기 편하도록 붙인 명칭**이고, 견적서·명세서는 명화주방 품명 기준이다. 직사각접시↔돌문어숙회, 다진양념통↔스텐_다진마늘통, 스텐복냄비↔스텐_전골냄비. **본사와 명화주방은 출고할 때 매핑표를 참고**한다 (마진표 엑셀에 고유키까지 정리)
- **규격 표기 차이는 손잡이 포함 여부에서 온다.** 문어볶음 소·대가 마켓봄 31cm/34.5cm(손잡이 포함) vs 견적서 Φ275/Φ308(미포함)로 갈렸던 건이 그 사례 — 같은 물건이며, 혼선 방지를 위해 **마켓봄 규격을 견적서 기준으로 통일**해 두었다(26.08.05)
  - 26.07 명세서 스텐복냄비 Φ280이 `*77`(견적서·26.06 명세서는 `*64`)인 것도 같은 원인으로 보인다. 단가가 같으면 표기 문제로 보고 넘기되, 단가까지 다르면 다른 물건이므로 확인
- **가맹점 판매가 뽑는 법**: 마켓봄 **「단가 일괄수정」** 양식(`상품 일괄수정`이 아님)을 받는다. 그 안의 **`택배배송 단가`가 가맹점 판매가(VAT 포함)**, 공급가는 ÷1.1. `매입 단가`·`직배송 단가`는 식기류에서 전부 0이라 쓸 수 없다
  - `상품 일괄수정` 양식에는 단가 열 자체가 없다 (`택배배송비` 열은 금액이 아니라 배송비 그룹명 `티타늄(식기류)`)
  - 검증법: 주문내역의 `단가`(VAT 포함)와 대조 — 죽그릇 6,314 · 겉절이접시 7,645로 일치 확인됨
- **마켓봄 `매입 단가`가 전 품목 0**이라 시스템에서 마진이 안 보인다. 확정 견적가로 등록하면 마켓봄에서 바로 마진 확인 가능 (등록 전 VAT 포함 기준인지 확인할 것)
- 거래원장 「2026.06.05초도」 시트 K·L열에 명화 쪽 품번·단가로 보이는 데이터가 헤더 없이 남아 있다. 단, 스텐복냄비 행은 L이 `28㎝` 텍스트라 일관된 가격 열이 아니고 명화 공식 자료도 아니다 — **참고만 하고 문의 근거로 쓰지 말 것**. 매입 단가는 견적서대로 확정됐으므로 지금은 볼 일 없음
- 견적서 문서일자가 실제 확정일과 다를 수 있다(6월 초도 건과 같은 2026.06.05인데 내용이 다름) → 보관 시 **파일명에 확정일**을 쓴다

**해소됨**: 택배비 금액(26.07 명세서에서 4,000원 확정) · 레이저각인 매입단가(견적서대로 확정) · 견적 외 품목(명화주방 거래 품목 아님) · 문어볶음 규격(손잡이 포함 여부, 마켓봄 규격을 견적서 기준으로 통일) · 상품명 불일치(점주 편의 명칭, 매핑표로 운영)
