# 정보공개서 관리

가맹사업법상 정보공개서 **정기 변경등록(매년)** 때 구매팀이 넘기는 자료를 연도·브랜드별로 쌓아두는 곳. 주로 「별지1. 물품 구입 및 임차 현황」의 물류 품목 리스트·공급가·차액가맹금(본사수취 마진) 작성.

**구조:** `연도/브랜드/` 한 칸이 한 건

```
franchise_disclosure/
├─ README.md          ← 이 파일 (매년 공통 기준 + 연도별 이력)
└─ 2026/
   └─ 철산장/
      ├─ README.md    ← 요청자·기준일·작업 방식·확정 사항
      ├─ received/    ← 브랜드 운영 담당자에게 받은 원본 양식 (수정 금지)
      ├─ output/      ← 작성본 (원본 파일명_YYMMDD)
      └─ reference/   ← 구매가·공급가 등 근거 데이터
```

**매년 공통 기준**
- 받은 양식 구조는 그대로 유지하고 내용만 채움
- 마진율은 **공급가 대비 %** — (공급가 − 구매가) ÷ 공급가. 양식 문구가 "공급가격의 OO%를 경제적 이익으로 수취"
- 기준일은 양식에 적힌 날짜를 따름 (2026년은 09월 30일)
- 작년 같은 브랜드 폴더가 있으면 먼저 열어서 품목 증감·마진 변동을 비교

**연도별 이력**

| 연도 | 브랜드 | 요청자 | 기준일 | 상태 |
|---|---|---|---|---|
| 2026 | 철산장 | 박지훈 팀장 | 2026-09-30 | 1차 작성본 완료(09-17), 팀장 확인 대기 |
| 2026 | 옥된장 | 운영팀 (일회성, 별지1 작업 아님) | 2025-09 공급가 | 26년 가맹계약서 시트 I열(25년 9월 공급가) 입력(09-17) — `_260917` 파일 + 매칭검증 파일, 폴더 구조 미적용 |
