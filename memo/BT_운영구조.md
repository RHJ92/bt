# BT(블루트렌드) 운영구조 (2026-06 기준)

## 0. 지배구조
- **블루트렌드(BT) = 지주사**. 브랜드별 가맹본부(옥된장가맹본부, 석문어가맹본부 등)는 BT에서 파생된 별도 법인/조직.
- 이 문서에서 "BT"는 지주사(매입·유통 기능 수행 주체), "가맹본부/본사"는 각 브랜드 프랜차이즈 운영 주체를 가리킴 — **마진 배분상 서로 다른 귀속처**이므로 구분해서 읽을 것.

## 1. 사업 구조
외식 프랜차이즈 본사(가맹본부) + 직영점 운영 + 식자재 유통(상품 공급) 겸업.

**브랜드 포트폴리오**
| 브랜드 | 매장 수 | 상태 |
|---|---|---|
| 옥된장 | 120개 | 운영 중 (주력) |
| 석문어 | 19개 | 운영 중 |
| 정백선 | 4개 | 운영 중 |
| 철산장 | 1개(예상) | 오픈 준비(설계 단계) |

직영점: 옥된장 정자점·마곡점·판교점, 석문어 양재점, 정백선순대 판교점·광교점.


**유통 수익 축 2가지**
1. 전용상품 유통마진 — BT(1차 마진) + 가맹본부(매출수수료) 배분, 본사 수익 대부분
2. 범용상품 매출수수료(판매장려금) — 가맹본부가 공급가의 약 5% 수취 (BT 개입/수익 없음)

## 2. 상품 흐름 (전용 vs 범용)

**① 전용상품 — 매입-재판매 구조 (제때를 거래주체로 세운 우회 구조)**
```
제조사 → BT 매입(BT매입가, 원가)
       → BT가 마진 반영해 제때에 판매(제때구매가)  ← BT 1차 마진 실현
       → 제때가 가맹점에 공급(공급가), 매출 전액을 제때가 수취
       → 제때는 공급가의 4.5%만 물류수수료로 보유
       → 나머지(공급가 − 제때구매가 − 4.5%)는 "매출수수료" 명목으로 가맹본부에 반환
```
BT가 직접 매입 → 제때에 넘김 → 제때가 가맹점 공급·배송·정산·매출수취 전담.

**왜 제때를 거치나 (핵심 설계 이유)**
가맹본부가 가맹점으로부터 상품대금을 **직접 수취**하면 법적 이슈(차액가맹금 관련)가 불거질 수 있음. 그래서 제때(물류사)를 매입·판매 주체로 세워 가맹점과의 거래를 전담시키고, 가맹본부는 그 매출에서 발생하는 차익을 제때로부터 **"매출수수료"(장려금 성격) 명목으로 사후 지급**받는 구조로 설계. 실질은 필수품목 구매 마진(차액가맹금)이지만, 형식상으로는 물류사가 가맹본부에 주는 장려금으로 우회 수취하는 셈. → 관련 법적 리스크는 [4-③ 유의점](#-제때--가맹점-공급-단계) 참고.

**② 범용상품 — 제때 직매입 + 매출수수료(판매장려금) 구조**
```
다양한 공급사 → 제때가 직접 매입 (BT 미개입, 범용적으로 여러 브랜드/매장에 사용) → 제때/물류사 직배송 → 가맹점
                                                                              └ 가맹본부: 매출액의 약 5%를
                                                                                제때로부터 매출수수료(판매장려금)로 수취
```
구매 주체는 제때 — BT는 매입도, 마진 실현도 없음. 가맹본부만 제때로부터 매출액의 약 5%를 매출수수료(판매장려금) 명목으로 셰어받는 구조.

## 3. BT ↔ 제때 거래구조 · 마진셰어

**단가 3단 구조**
- BT매입단가: BT가 제조사/공급사에서 사오는 원가
- 제때구매단가: 제때가 BT에서 사는 가격 (BT 1차 마진 실현 지점)
- 가맹점 공급단가: 점주가 지불하는 가격 (제때 매출 전액 수취 지점)

**총마진(공급단가 − BT매입단가)의 3자 배분**
| 귀속처 | 산정 | 성격 |
|---|---|---|
| BT 몫 | 제때구매단가 − BT매입단가 | BT가 제때에 판매하며 실현하는 1차 마진 (BT 자체 매출) |
| 제때 몫 | 공급단가 × 4.5% | 물류수수료 |
| 가맹본부 몫 | 공급단가 − 제때구매단가 − (공급단가×4.5%) | 제때 → 가맹본부 "매출수수료"로 반환 (실질상 차액가맹금) |

**월 정산(제때 마감정산) 산식**
- 전용 지급수수료 = 공급합계 − 제때구매가합계 − 물류비용 (= 가맹본부에 귀속되는 매출수수료)
- 범용 지급수수료 = 공급합계 × 약 5% (매출수수료/판매장려금, 가맹본부 귀속 — BT 미개입)
- 최종 지급수수료 = 위에서 면세 안분공제(면세품 매출의 1/11 차감) 반영
- **26년 7월 정산부터 면세 안분공제 적용**

## 4. 단계별 유의점·장단점

### ① BT 매입 단계 (공급사 → BT)
- 장점: 매입가 직접 통제로 원가 경쟁력 확보, 비딩(김치 3사·물류 웨스토리/SPC 등)으로 지속 개선 가능
- 단점: 재고·품질 리스크를 BT가 부담. 매입가가 시중가(코스트코 등)에 근접한 품목은 3단 마진 구조 자체 성립 어려움
- 유의점: 매입원가는 공급사 계약상 대외비. 점주 문의 시 "동일 사양 비교" 프레임으로 대응, 원가는 비공개 유지

### ② BT → 제때 판매 단계
- 장점: 물류·배송·여신(수금)·정산을 제때가 전담 → BT는 물류 인프라 투자 없이 120개+ 매장 커버, 고정비의 변동비화
- 단점: 제때구매가-공급가 스프레드가 제때에 귀속되어 BT/가맹본부 합산 마진 얇음(7~9%). 단가 개정 시점 차이로 원장 단가와 품목리스트 단가 어긋날 수 있어 정산 검증 필요
- 유의점: 물류비 4.5%가 비딩 마지노선(미만 시 협약 불가). 면세 안분공제(7월~) 적용으로 수수료 실수령 감소분을 손익 계획에 반영 필요

### ③ 제때 → 가맹점 공급 단계
- 장점: 점주 입장 발주·배송·정산 창구 일원화(운영 편의성↑), 본사는 매장별 사용률 데이터(마켓봄/제때 원장) 확보 가능
- 단점: 공급가가 점주 노출 접점이라 가격 민감도 최고 (인터넷 최저가 비교 민원 실제 발생). 전용상품 사용률 낮은 매장(경북권, 강남구청점 등)은 수익 기여 급감
- 유의점(**법적 리스크 최대**):
  - 정보공개서 버전 이슈 — 구버전="매입가의 5% 이내 마진" 문구, 현행="공급업체 결정 + 매년 초 협의"로 개정. 점주별 계약 당시 교부 버전이 기준 → 가격 민원 대응 전 반드시 교부 버전 확인. 구버전 교부 점주에게 5%를 부인하면 가맹사업법상 분쟁 소지(가맹금 반환 청구, 과징금 등)
  - **위 정보공개서 이슈와 직결되는 구조적 배경**: 가맹본부가 가맹점 상품대금을 직접 수취하지 않고 제때를 통해 "매출수수료(장려금)" 명목으로 받는 것 자체가, 필수품목 구매 마진(차액가맹금)의 공시·규제를 우회하려는 설계임 (근거: [2. 상품 흐름 - 왜 제때를 거치나](#2-상품-흐름-전용-vs-범용) 참고). 점주 민원·감사·소송 시 이 구조 자체가 쟁점이 될 수 있음

### ④ 범용 매출수수료(판매장려금) 단계 — 제때 직매입, 가맹본부 귀속
- 장점: 가맹본부는 무재고·무매입으로 리스크 없이 매출액 5% 수취, 신선품 클레임 부담을 물류사(제때)에 이전. BT는 이 단계에 개입도, 수익도 없음
- 단점: 수익률 자체가 낮고, 점주가 범용을 시중에서 따로 사면 매출수수료가 통째로 소멸(강제성 없음). 품질 편차(예: 미나리)로 사용률 하락 시 수익도 동반 하락
- 유의점: 물류사 교체(비딩) 시 범용 재사용 유도가 가맹본부 수익 개선 레버리지

## 5. 핵심 트레이드오프
현재 제때 구조 = **낮은 마진(7~9%) + 낮은 운영 리스크 + 차액가맹금 우회(제때 경유로 직접 수취 회피)**
BT직공급 전환 = **높은 마진(25~27%) + 물류·여신·정산 리스크 내재화 + 상품대금 직접수취에 따른 차액가맹금 노출 위험**

전환 검토 시, 마진 상승분(약 3배)이 물류센터·배송·수금 인력의 고정비 증가분을 넘어서는 매장 규모(임계점) 계산뿐 아니라, 직접수취 전환 시 정보공개서 개정·차액가맹금 공시 대응까지 함께 검토 필요.
