## 정리 원칙

**지출 카테고리는 「품목별 제조사」의 `상품유형`을 정답으로 삼는다.** 매입사가 품목 파일에 있으면 상품유형을 카테고리 기본값으로 쓰고, 없으면 5~8월 실적 최빈값을 쓴다. 근거는 마스터의 `카테고리 근거` 열에 표시.

**승인자·결제자는 거래처가 아니라 (법인 × 부서)로 결정된다.** 별도 시트로 분리했고, **구매공급관리팀 승인자는 김민혁 고정**(실적도 242건 전부 김민혁). 결제자는 법인으로 갈린다 — 블루트렌드·철산장은 정준선, 옥된장·석문어·정백선·블루푸드랩은 민선아.

**계좌는 현행대로 한 칸에 담되 표기를 통일한다.** `우리은행 / 1005-… / 한마당`과 `우리은행 1005-… 한마당`이 다른 값으로 잡히는 게 표기 충돌의 최대 원인이었으므로, 마스터에서는 전부 `은행 계좌번호 예금주` 공백 구분으로 맞췄다.

**제목은 자동 조합.** `[지출카테고리]거래처명_지출내용` 규칙을 실적 96%가 따르므로 수기 입력을 없앨 수 있다.

## 남은 확인 사항

1. **2025년 1~9월에 같은 자동화를 이미 운영하다 중단한 이력**이 있다 (`[종료] 거래처명(불러오기)` 컬럼 1,046건, 노션 릴레이션 방식). 개발팀에 **중단 사유부터 확인**할 것
2. 사업자등록번호를 키로 넣을지 — 현재 데이터에 없음
3. 개인 거래처(개인경비·경조사·전도금)를 같은 마스터에 둘지, 접근권한 때문에 분리할지
