# BT FLOW 지출결의서 작성 절차

Claude가 대신 작성할 때 따르는 절차. 2026-10-16 명화주방 건을 실제로 작성하며 정리함.

## 경로

1. https://bt.btflowlab.kr/expense (로그인된 상태여야 함 — **비밀번호 입력은 Claude가 하지 않는다**)
2. `고정 양식 선택` 드롭다운에서 거래처 선택 (예: `명화주방 · 식기류 · 블루트렌드`)
   - 선택하면 지출카테고리·거래처명·지출목적·법인·부서·거래속성·승인자·요청자·계좌가 자동으로 채워짐
   - 거래처가 목록에 없으면 `일반 지출결의서 작성` 또는 `우리 부서 고정양식 만들기`
3. `금액(VAT포함)` 칸에 금액 입력 (비우면 탈리 폼에서 입력)
4. `탈리 폼 열기 (자동 채움)` → 새 탭에서 「지출통합결의서」 폼이 열림 (form.bluetrend.co.kr/document_0001, 값은 URL 파라미터로 전달)
5. 안내문 아래 `작성하기 →` → 입력 화면
6. 1페이지 입력 후 `증빙 자료 첨부하기 →` → 2페이지(첨부)
7. 마지막 `작성완료 →` = **상신**. 누르기 전에 사용자 확인을 받는다

## 입력 규칙

| 칸 | 값 |
|---|---|
| 기안 작성 | `YYYYMMDD_이름` (자동) |
| 지출내용 | 고정양식 기본값은 `{월}월 마감정산`. 건 성격이 다르면 그 건에 맞게 수정 |
| 신규 거래처 선정 이유 | 고정거래처면 비움 |
| 이체요청일 | 달력에서 날짜 클릭 (필수) |
| 금액(VAT포함) | BT FLOW에서 넣었으면 자동 반영됨 |
| **지출 세부 내용 작성** | **비운다.** 특이사항은 사용자가 작성 완료된 페이지에 직접 댓글로 단다 |
| **증빙 미제출 사유** | 평소 비움. **거래명세서만 있고 세금계산서가 없는 경우에만** `댓글 첨부하겠습니다.` 라고만 작성 |
| 계약서 / 통장사본 / 결과보고서 | 해당 없으면 비움 (결과보고서는 마케팅팀 전용) |

## 증빙 첨부

- 파일 위치: **바탕화면 `지출 증빙 이미지` 폴더** (`C:\Users\BLUETREND\Desktop\지출 증빙 이미지`)
- 파일명 규칙(관찰): `업체약칭 + 월` = 거래명세서, 끝에 `0`이 더 붙으면 세금계산서. 같은 달 2건째는 `-1`
  - 예: `명화10.png`(명세서 10월) / `명화100.png`(세금계산서) / `명화10-1.pdf`·`명화100-1.png`(2건째)
- 첨부 칸: `거래명세서 및 견적서` ← 명세서·견적서 / `세금계산서 및 계산서` ← 전자세금계산서
- **첨부 전에 파일을 열어 금액을 확인하고, 세금계산서 합계가 입력 금액과 맞는지 대조한다**

## Claude가 지키는 선

- **`작성완료`(상신)는 사용자가 숫자를 검토하고 "눌러라"고 한 뒤에만 누른다.** 한 번 승인받았다고 다음 건까지 자동으로 올리지 않는다
- 로그인 비밀번호는 입력하지 않는다
- 첨부 파일 금액과 입력 금액이 다르면 상신 전에 보고한다
