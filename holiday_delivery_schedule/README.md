택배 운영 품목의 **연휴·공휴일 배송일정표**를 만들어 마켓봄 공지에 올리는 작업 공간.

이 폴더는 2026-08-11에 신설됐다 — 그 전(7월 건 등)에는 거점 없이 그때그때 만들었다.

- [ ] **커밋 안 됨.** 커밋 전담 세션에서 처리할 것
- [ ] **7월 건 원본이 이 폴더에 없다.** 톤 참고용으로 옮겨두면 다음 건이 쉬워진다

  모르는 점주가 있을 수 있으나 `발송 불가`만으로도 행동은 결정되므로 자리값이 더 크다고 판단.
  문의가 실제로 들어오면 다음 건에 되살릴 것

## 배경 — 왜 이 표가 필요한가

마켓봄은 **가맹점 → 본사 → 공급사** 구조다. 물류사 배송이 아니라, 가맹점이 마켓봄으로 주문하면 본사가 주문 내역을 확인해 각 공급사에 **택배 발송을 요청**한다.
따라서 택배사가 쉬면 발송 자체가 끊긴다 → 연휴 전 **주문 마감일**을 매장에 미리 알려야 결품이 안 난다.

## 작업 방식

1. 택배사에서 연휴 배송 일정 통보를 받는다 (집하 가능일 / 배송 가능일 / 휴무일)
2. **집하 불가 = 발송 불가**로 환산한다 — 배송만 되는 날도 매장 입장에선 발송이 안 되는 날
3. 마지막 집하 가능일 = **주문 마감일**(오전 9시 마감, 당일 출고)
4. 엑셀로 달력형 표 + 안내 문구를 한 파일에 작성 → 마켓봄 공지에 이미지로 첨부

## 표에 반드시 들어가야 하는 것 (혼선 방지 — 2026-08 건에서 확정)

빠뜨리면 문의 전화가 몰리거나 결품이 나는 항목들이다.

1. **출고 기준임을 명시** — 표의 날짜는 발송일이고 매장 도착은 그 다음 날. 이걸 안 쓰면 "배송만 정상"인 날(집하 불가일)에 물건이 도착하면서 표와 어긋나 보인다. 배송일과 집하일이 갈리는 연휴에 특히 위험
2. **며칠치를 준비해야 하는지** — 마지막 도착일 ~ 재개 후 도착일까지 굵게 강조. 휴무 일수보다 체감 공백이 항상 길다
3. **마감 하루 전 주문 권장** — 택배사가 "미리 마감"한다는 건 물량이 몰린다는 뜻. 마감일 당일 주문은 다음 출고일로 밀릴 수 있다
4. **택배 품목 한정 명시** — 물류사(제때) 배송 품목과 섞여 "연휴 내내 아무것도 안 온다"로 읽힌다
5. **제주·도서산간 +1일** 고지
6. 회색(지난 날짜)은 **공지 등록일 전날까지만** — 등록일 당일을 회색 칠하면 당일 주문 불가로 오해

## 분량 원칙 (★ 위 6개 항목만큼 중요)

넣을 게 많다고 다 쓰면 **정작 읽어야 할 마감일·재고 확보를 못 읽는다.** 안내문은 짧을수록 지켜진다.

- **중단 일수는 발송 기준으로만 센다** — 재개일은 중단에 포함하지 않는다. 8/13~8/17이면 **5일**(재개일 8/18 제외)
- **표 셀에 있는 내용을 하단 유의사항에 반복하지 않는다** — 휴무일 나열, 재개일 안내는 달력만으로 충분
- 하단 유의사항은 **3줄** — 주문 마감 / 마감 후 주문 안내 / 품목·지역 단서.
  **맺음말("감사합니다.")은 넣지 않는다** — 안내문(구역 A)에 이미 있어 중복 (2026-09-23 사용자 수정)
- 셀 문구는 **2줄 이내**, 반복되는 "택배 발송 불가"는 `발송 불가`로 통일하고 사유는 괄호 한 단어로
- 강조 박스는 **하나만.** 여러 곳을 강조하면 아무것도 강조되지 않는다

## 구성 원칙 — 두 구역으로만 나눈다 (★ 배치가 어긋나면 읽기 흐름이 끊긴다)

테두리 있는 블록과 없는 블록이 번갈아 나오면 어디까지가 표이고 어디부터가 글인지 헷갈린다.
**한 파일에 시각적 덩어리는 두 개뿐**이어야 한다.

| 구역 | 담는 것 | 서식 |
|---|---|---|
| **A. 안내문** | 제목 · 등록일 · 인사말 · 맺음말 | 테두리 없음 · 왼쪽 정렬 |
| **B. 배송일정표** | 강조 → 기준 → 요일 헤더 → 달력 → 유의사항 | 테두리 있는 **연속된 한 덩어리** · 가운데 정렬 |

- 표 제목(`10월 "마켓봄" 배송일정`)만 예외로 표 바깥 — **A~G 한 줄로 병합해 가운데 정렬**
  (2026-09-23 사용자 수정. 그 전에는 `10월`을 왼쪽, `"마켓봄" 배송일정`을 오른쪽에 나눠 뒀다)
- **표에 딸린 설명은 전부 표 안으로.** 강조 문구·기준 안내를 표 위에 떠 있는 텍스트로 두지 않는다.
  강조 줄은 표의 **첫 행**, 유의사항은 표의 **마지막 행**으로 편입시킨다
- 구역 A와 B 사이는 빈 행 하나로만 띄운다

## 표 양식 (고정)

- 열 A~G = 일요일~토요일, 2주치(연휴 전 주 + 재개 주)
- 각 주는 **날짜 행 + 비고 행** 2줄 세트
- 색 규칙
  | 색 | 의미 |
  |---|---|
  | 남색(1F3864) 바탕·흰 글씨 | 요일 헤더 |
  | 하늘색(BDD7EE) | 주문 마감일 / 발송 재개일 |
  | 노랑(FFFF00) | 택배 발송 불가 |
  | 연두(E2EFDA) | 여유 주문 권장일 (마감 전날) |
  | 회색(D9D9D9) | 지난 날짜 |
  | 빨강 글씨 | 일요일·공휴일 날짜 |
- 표 첫 행: **재고 확보 강조 줄**(연노랑 바탕 + 빨강 굵은 테두리) → 그 아래 **출고 기준 안내 줄**(연회색)
- 표 마지막 행: 유의사항 3줄 — 주문 마감 / 마감 후 주문 안내 / 품목·지역 단서
  - **유의사항은 줄 사이 가로 구분선을 넣지 않는다** — 바깥 테두리만 둘러 한 덩어리로 읽히게
    (2026-09-23 사용자 수정. 달력 칸과 달리 여기는 표가 아니라 글이라서)
- 폰트 맑은 고딕, 눈금선 숨김, 가로 인쇄 1페이지 맞춤
