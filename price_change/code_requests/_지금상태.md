**지금 상태**

- 기존 요청서 예시(260819 폰즈소스·냉면육수 양식)를 복사해 2026-10-16 신규 코드 요청 초안 작성, 파일 2개로 분리함
- 석문어 떡볶이소스: 사용자가 매입가 15,300 / 판매가 18,000원(VAT 별도, 제때 매입가 기준) 최종 반영함 → 제때 메일 발송은 사용자가 직접 하기로 함 (발송 여부 이 세션에서 미확인)
- 철산장 4건(냉면육수·아롱사태 수육·차돌양지 수육·한돈 본양념구이): 사용자가 "다음에 하기로" 보류함. 냉면육수 규격 5kg, 수육 2종 (계근) 표기는 사용자가 직접 수정함
- 5건 통합 초안 파일은 삭제함
- 폴더에 사용자가 따로 만든 `철산장,석문어 전용상품 코드 생성_261031_(블루푸드랩,정담)_떡볶이소스,한돈본양념구이.xlsx` 있음 — 이 세션에서 손대지 않음

**다음 할 일**

1. 떡볶이소스 제때 메일 발송 여부 사용자에게 확인
2. 아롱사태·차돌양지 수육 평균 중량 받으면 제품명·단위 수정 — 품목리스트 계근 품목 관례대로 `(계근)아롱사태 수육(CSJ/○kg내외)_KG_(소고기 : 미국산)`, 단위 KG로 맞출지 사용자 확인
3. 카우스토리 3종 매입가·판매가 입력 — 육수 매입가는 임가공비 2,000원/kg × 5kg 기준, 수육은 원육 매입가 ÷ 삶은 고기 수율 (근거: `bidding/냉면육수_카우스토리/README.md`)
4. 한돈 본양념구이 입수(5kg × ?ea)·매입가·판매가 입력 (참고: 기존 CC314881 본양념구이 5kg×6ea, 매입 210,600 / 공급 275,400원, VAT 별도)
5. 4건 공통 빈칸 채움: 최소발주량, 금번 입고량, 월 예상 사용량 / 카우스토리 리드타임·김현식 대표 연락처·메일
6. 수육 2종 과세 여부 확인 (현재 과세로 입력)

**막힌 것·대기 중**

- 카우스토리: 수율 샘플 결과 대기 → 수육 평균 중량·단가 미확정
- 정담: 한돈 본양념구이 입수·단가 미확정
- 사용자 결정: 수육 단위 PK/KG, 과세/면세, 떡볶이소스·한돈 본양념구이를 261031 파일로 합칠지 여부
