> 호출 문구: **"거래명세서 작성 가이드 보고 만들어줘"**

**작업 순서 한눈에**

1. 거래 방향 정하기 — 누가 공급자(파는 쪽), 누가 공급받는자(사는 쪽)인지
2. 양식 복사 — 루트 `_공용/거래명세서_양식_BT_옥된장.xlsx`
3. 당사(계열 법인) 정보 — 바탕화면 `사업자_통장_명함` 폴더
4. 거래처 정보 — 회사 노션 협력사 DB → 업체 페이지 → 「사업자 정보」 토글
5. 품목 행 입력 → 서식 점검 → PDF 렌더링으로 눈 검수
6. 해당 거점 폴더에 저장, 빈칸·확인 필요 사항 보고

**1. 거래 방향 정하기**

| 상황 | 공급자 (오른쪽 G~L열) | 공급받는자 (왼쪽 B~F열) | 문서번호 예 |
|---|---|---|---|
| 당사가 판다 (원물 매각, 재고 이관 등) | 당사 법인 — 양식에 이미 박혀 있음 | 거래처 | `BT-YYYYMMDD-01` |
| 거래처가 당사·계열사에 판다 (거래처가 발행할 명세서를 대신 작성) | 거래처 | 당사 또는 계열 법인 (철산장에프엔비 등) | 거래처 이니셜 `JD-YYYYMMDD-01` (정담=JD) |

- 한 파일에 여러 장이 필요하면 **시트를 나눈다** (예: 정담 건 = 세부내역 / 원물 매각 / 완제품 매출 / 샘플 매출)
- **세금계산서 받는 법인이 다르면 시트도 나눈다.** 한 장에 「제때 + 철산장 직납분」처럼 두 법인을 섞지 않는다
- 거래처가 발행 주체인데 우리가 만들어 주는 경우는 제목에 `(참고용)`을 붙이는 경우가 있음 — 상대에게 확인용으로 보낼 때

**5. 입력·서식 규칙**

- **상호는 등록증의 법인명 그대로** (`정담` ✕ → `주식회사 정담`, `철산장 F&B` ✕ → `주식회사 철산장에프엔비`). 세금계산서 상호와 맞추기 위함
- 공급자 대표자 칸은 `이름          (인)` 형식 유지
- 담당자/연락처(D11): 거래처 담당자 `이름 / 휴대폰`. 당사 쪽 전화/팩스(J11): `1661-1685`
- 금액은 VAT 별도 단가 기준으로 넣고, 문서 안에서 VAT 별도/포함을 헷갈리지 않게 한다
- 중량 거래는 단위 `kg`, 수량에 중량. **소수 수량(2.5 등)은 셀 서식을 `#,##0.0`으로** — 양식 기본 서식은 정수라 2.5가 「3」으로 보인다 (금액 계산은 정상이라 놓치기 쉬움)
- 긴 주소(D9·J9)는 **줄바꿈 + 9행 높이 확대**(2줄 26pt, 3줄 38pt). 축소 맞춤(shrink)은 글씨가 너무 작아져 못 읽음
- 품명·규격이 길면 해당 셀만 축소 맞춤
- 미확정 행은 노란 칠 메모로 남겨도 됨 (예: 「10월 마지막주 샘플 입고 후 명세서 확정」)
- 글꼴은 양식 그대로 (사용자 양식 파생 파일이라 `_공용/폰트크기_작업기준.md` 예외)

**6. 검수 — PDF로 렌더링해서 눈으로 본다**

수식 값은 openpyxl 저장 후 비어 있으므로 LibreOffice로 변환해 계산값까지 확인한다.

```bash
# 스크래치 폴더에 복사본 → PDF → PNG
"/c/Program Files/LibreOffice/program/soffice.exe" --headless --convert-to pdf --outdir <scratch> <scratch>/copy.xlsx
python -I -c "import pymupdf,sys; d=pymupdf.open(sys.argv[1]); [p.get_pixmap(dpi=90).save(sys.argv[1][:-4]+f'_{i}.png') for i,p in enumerate(d)]" <scratch>/copy.pdf
```

- 시트마다 확인: 빈칸 / 잘린 글자 / 소수 수량 표시 / 합계·「일금 ○원정」 / 계좌가 **공급자** 계좌인지 / 하단 법인명
- 이 PC 파이썬 출력은 cp949라 한글·특수문자 print가 깨지거나 에러 남 → 결과는 **UTF-8 파일로 써서** Read로 본다 (`python -I`는 `PYTHONIOENCODING`도 무시함)

**7. 저장·보고**

- 저장 위치: **그 일을 하는 거점 폴더** (예: `bidding/양념갈비완제품/`). 이 가이드 폴더에는 산출물을 두지 않는다
- 파일명: `YYMMDD_거래명세서_거래처_내용.xlsx` 또는 건 이름 (예: `261023_정담_정산명세서.xlsx`)
- 이미 나간(발행한) 파일을 고칠 때는 덮어쓰지 말고 `_YYMMDD`를 붙인 새 파일. 당일 만들고 있는 미발행 초안은 그대로 수정
- 보고할 때: 저장 경로 전체(따옴표), 채운 값 표(출처 포함), **못 채운 칸과 이유**, 확인 필요 사항
