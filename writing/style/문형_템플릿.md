# 상황별 문형 템플릿

교정 세션에서 효과가 확인된 구조. 새 메시지를 쓸 때 뼈대로 쓴다.

## 1. 결재·검토 요청 (재무팀·대표님)

> **용건을 첫 줄에.** 원문은 대개 배경부터 시작해 마지막에 요청이 나오는데, 결재자는 "나한테 뭘 해달라는 건지"를 먼저 찾는다.

```
안녕하세요, OOO 관련 문의드립니다.

제안: (결론 한 줄 — 무엇을 하려고 하며 가능한지 묻는다)

배경: 현재는 ~ 한데, 이 과정에서 아래와 같은 문제가 발생하고 있습니다.
- (항목 1)
- (항목 2)

이를 해소하기 위해 (대안 시도)했으나, (결과)를 확인했습니다.
이 경우 (남는 부담)이 발생하는 상황이라, 부득이하게 위와 같이 제안드립니다.
```

핵심: **"번거로워서 바꾸자"가 아니라 "대안을 먼저 시도했고, 남은 선택지는 이것뿐"** 구조로 만들면 결재가 쉬워진다.

숫자 정보(금액·일자·회수 시점)는 문장에 섞지 말고 불릿으로:
```
- 예상 지출액: 약 O억 원
- 예상 지출일: O월 O일
- 매출 발생 시점: O월부터
```

## 2. 개조식 검토 보고 (원산지·스펙 전환 등)

```
OOO 전환 검토 (A → B)

배경
- (현 상황과 문제)
- (시장 전망)
- 이에 (대안)을 테스트하여 적합할 경우 전환하는 방향을 검토하고자 함.

등급/스펙 검토
- (현재 운영 스펙과 대체 스펙 비교)

진행 계획
- O월: 테스트 진행
- O월부터 약 1개월: 직영점 시범 운영
- 특이사항 없을 시: O년 O~O월 전 지점 전환
```

시간 흐름이 한 문장에 뭉치면 안 읽힌다. **타임라인 3단계로 분리.**
결재자는 "테스트 판단 기준이 뭔가"를 반드시 묻는다 → 평가 주체·기준(블라인드 평가, 클레임률 O% 이하)을 미리 한 줄 넣는다.

## 3. 거절 답변을 받은 뒤 재요청 (재무팀 등)

```
넵, 확인 감사합니다!
다만 (이슈)가 운영 쟁점이 될 것 같아 상황 공유드립니다.

(근거 1 — 과거 실패 사례)
(근거 2 — 시장 상황)

전량이 어렵다면 가능한 규모만이라도 확보하고 싶어서, (언제) 검토 시 가능 범위 확인 부탁드립니다!!
```

**첫 줄의 "확인 감사합니다"가 핵심.** 거절 직후 바로 반론으로 들어가면 "말 안 듣네"로 읽힌다.
요청은 "확인해달라"가 아니라 "부분 집행이라도 열어달라"로 의도를 명확히.

## 4. 오해 소지가 있는 카톡 (인원 정리·업무 회수 등)

```
OOO님, 안녕하세요!!
(지시 배경) 지시가 있어서, 관련 인원 전체 대상으로 정리를 진행하게 되었습니다!
그동안 (상대의 불편)하셨을 텐데, 이번 기회에 아래는 편하게 (조치)하셔도 될 것 같습니다.

- 항목 1
- 항목 2

혹시 필요한 자료 있으시면 미리 백업해두시고, 이번 주 중으로 정리해주시면 감사하겠습니다!!
(조치) 후에도 필요한 내용 있으시면 언제든 저한테 말씀 주세요~ 바로 공유드리겠습니다!!
```

마지막 줄이 제일 중요 — **단절이 아니라는 안전장치.**

## 5. 업체 소싱 공고

```
안녕하세요, 프랜차이즈 본사입니다.
(품목)을 생산해 주실 업체를 찾습니다.

원물은 당사에서 구매해 공급드립니다. 다만 (조건)이라면 완제품 기준으로도 구매 가능합니다.

**공정 관련 요청 사항**
(핵심 필터 — 부적합 업체가 지원하지 않도록 문단을 따로 빼고 굵게)

**거래 조건**
- 월 사용량: O톤 예상
- 포장 단위: Okg/box
- 입고 물류센터: OOO
- 원물 스펙 / 납품 시작 시점  ← 업체가 가장 먼저 묻는 항목

제안 가능하시면 쪽지로 업체명·연락처를 남겨주시면 확인 후 연락드리겠습니다.
```

## 6. 세팅·발주 요청 (담당자)

코드·수량은 담당자가 복사할 수 있게 불릿으로 뺀다.
```
안녕하세요,

- CC000000 상품명(규격)
- CC000000 상품명(규격)

위 두 코드를 O월까지만 동시 운영하려고 합니다.
원래 (계획)이었으나, 내부 요청으로 O월까지만 병행 운영하기로 했습니다.
두 코드 모두 내일 입고 예정이니, 내일부터 주문 가능하도록 세팅 부탁드립니다. 감사합니다.
```

## 7. 금액 수정 요청

차액을 같이 적으면 상대가 암산하지 않아도 되어 처리가 빨라진다.
```
기존 400,994,981원 → 수정 400,994,308원 (차액 -673원)
```
