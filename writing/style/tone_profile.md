# 내 말투 프로파일

2026-07~08 교정 세션에서 관찰된 패턴. 교정할 때 **이 특징들은 살리는 게 원칙**이고, 표에 "조정"으로 표시된 것만 상황에 따라 손댄다.

## 상대별 톤

| 상대 | 채널 | 톤 | 주의점 |
|---|---|---|---|
| 대표님 | 보고 | 개조식 + 존댓말, 결론 먼저 | 판단 기준·회수 시점을 같이 제시해야 답이 빨리 옴 |
| 구매팀장님 | 카톡/보고 | 존댓말 + 느낌표, 실무 축약어 허용 | — |
| 차장님 | 카톡 | 친근한 존댓말, 느낌표 다수 | **말을 오해하는 경향** → 지시형 금지, 안전장치 문장 필수 |
| 재무팀 (민선아 과장) | 카톡 | 존댓말, 금액·일자 위주 | 거절 답변 받으면 반박 전에 "확인 감사합니다" 한 줄 먼저 |
| 현장/슈퍼바이저 | 공지 | 존댓말, 요청 배경 설명 | 왜 필요한지 알려야 협조가 나옴 |
| 거래처 (산돌식품·한중푸드 등) | 메일/카톡 | 격식 존댓말 | 구어체·감정 표현 제거 대상 1순위 |

## 자주 쓰는 표현

| 표현 | 쓰는 상황 | 유지/조정 |
|---|---|---|
| `~부탁드립니다!` / `~감사하겠습니다` | 요청 마무리 | 유지 (기본 어미) |
| `!!` `!!!!` 연속 느낌표 | 카톡·사내 메시지 | 카톡은 유지, **보고 문서는 1개로** |
| `~인 것 같습니다` / `~할 것 같습니다` | 본인 결정 사항에도 사용 | **조정** — 결정 사항은 단정형(`~하려고 합니다`)이 명확 |
| `~부분입니다` | 설명 마무리 | 조정 (구어체) — 보고문에서는 제거 |
| `우선 들어오는 대로 쳐내고` 류 | 동료에게 상황 설명 | 카톡은 유지, 보고는 순화 |

## 반복되는 글 습관 (교정 시 자동 점검)

1. **용건이 맨 뒤에 온다** — 배경부터 길게 쓰고 마지막 줄에 요청. 결재자·재무팀 대상이면 **제안/문의를 첫 줄로 올린다.**
2. **제목은 "문의"인데 본문에 질문이 없다** — 요청 문장이 실제로 있는지 확인.
3. **감정·체념 표현이 섞인다** — `어쩔 수 없게 되었습니다..`, `컷트 당해서`, `절대 안 된다는 입장`, `씨가 말라서`. 뜻은 살리고 담백한 사실 전달로.
4. **한 문단에 배경·주의·조건이 다 뭉친다** — 3~4덩어리 소제목으로 쪼개면 바로 읽힘.
5. **숫자를 문장 속에 흩뿌린다** — 금액·일자·수량은 불릿으로 빼면 상대가 검증하기 쉬움.
6. **한발 빼는 어미** — `~긴 합니다`, `~할 것 같습니다`. 설득이 목적인 글에서는 힘이 빠짐.

## 카톡 오해 방지 원칙 (차장님 건에서 도출)

- 특정인만 대상으로 보이지 않게 **전사적 정리의 일부로 프레이밍**
- 지시형(`나가주시고`) → 허용형(`편하게 나가셔도 될 것 같습니다`)
- `이제`처럼 재촉으로 읽히는 부사 제거
- 마지막에 **단절이 아니라는 안전장치 한 줄** — "필요한 내용 있으시면 언제든 말씀 주세요"

## 보고문 순화 사전 (부정형 → 조건형)

| 원문 뉘앙스 | 순화 |
|---|---|
| 진행 불가로 확정 | 보류되었던 건 |
| 거래는 불가하다는 입장 | MOQ 이상 거래만 가능하다는 기준 |
| 견적 내는 데 오래 걸린다 | 시간이 다소 소요될 것으로 안내받았습니다 |
| 순서를 기다리라는 입장 | 순차적으로 회신받기로 했습니다 |
| 절대 안 된다는 입장 | 불가하다는 입장을 확인했습니다 |
| 어쩔 수 없게 되었습니다.. | 운영 방식을 정리할 시점이라고 판단됩니다 |
