# 베스크린 냅킨·물티슈 거래 종료 통보

- 발송일: 2026-08-05
- 상대: 베스크린 (부자재 매입처)
- 성격: 거래 종료 통보 — 정산·분쟁 시 근거 자료

## 발송 문안

```
안녕하세요, 블루트렌드입니다.

당사에서 소량 생산 부자재의 가짓수가 늘어남에 따라, 부자재 공급사 통합을 진행하게 되었습니다.
이에 현재 베스크린에서 공급받고 있는 냅킨·물티슈 거래는 2026년 8월 31일부로 종료하고자 합니다.

- 냅킨: 현재 베스크린 보유 재고가 없는 것으로 확인해 주셨습니다.
- 물티슈: 140~150박스 생산 가능한 필름지가 남아 있다고 하셔서, 해당 물량은 8월 마지막 주에 지정 창고로 일괄 입고받겠습니다.

그동안 공급해 주신 점 감사드리며,
물티슈 생산 진행 일정에 특이사항 있을지 확인해 주시면 발주 진행하겠습니다.
```

## 미결 사항

- **물티슈 최종 수량 미확정** — `140~150박스` 범위로 통보. 회신에서 수량을 확정받아야 발주·정산 시 다툼이 없음.
- **필름지 잔량 전량 인수 부담** — 실제 필요량보다 많을 경우 재고 부담이 당사로 이전됨.
- **계약서 해지 통보 기한 미확인** — 물품공급계약에 사전 통보 조항(30일 등)이 있으면 8/5 발송 → 8/31 종료는 26일이라 미달. 9월분까지 유효해질 여지.
