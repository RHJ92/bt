# 인계 — 업무 메시지 교정 세션 (2026-11-05)

## 지금 상태
- 카톡·메일 업무 메시지 교정 세션으로, 요청 건마다 교정문만 코드 블록으로 회신 완료함
- 이번 세션에서 교정한 건(발송 완료 또는 발송 대기)
  - 쌈장 1차 테스트 피드백 + 2차 샘플(된장 배합비 상향, 1통) 요청
  - 축산품 공급가 조정 안내문 일정 지연 사유·양해 요청(11/2 인상 반영)
  - 정자점 리스크 관련 완곡 표현 정리
  - 한돈본양념구이 을지로점 초도 입고 안내(120kg·12박스, 리드타임 영업일 4일)
  - 을지로점 직배송 안전재고 운영 안내(150kg 하한·최대 500kg, 잔여 재고 철산장 F&B 귀속)
  - 정담 대상 을지로점 직배송 운영 방식 확인 요청(당일 요청 → 2~4일 내 매장 입고)
  - 보쌈 완제품 관련 공급사 의견 공유(퀄리티 우려·코스트·족발 마켓컬리 only)
  - 을지로점 석박지 재고 확인 요청(현재고 0 + 입고 2 − 출고 6 = 4박스 부족)
  - 유니폼 선분출 구글 폼 전환 협조 요청(2회 수정)
  - 정자점·판교점 혼합 뼈갈비절단 샘플 테스트 요청(11/5 입고, 10kg 1박스, kg당 14,000원)
  - BT갈비소스 당도 조정·교반 일정 공유(이정혁 이사님 / 을지로점 입고 건)
  - 백립 농(고름) 발생 원인·현장 감수 설명문
  - 모래시계 부품 제공 중단 vs 대체품 탐색 — 차주 월요일 회의 안건 정리
  - 제때(물류센터) 신규 제품 리드타임(입고 후 2일) 수용 회신(2회 수정)
  - 목살 칼집 1mm 조정·자투리 혼입 여부 확인 요청
  - 반한보쌈 목전지·삼겹 수육 지정 두께 슬라이스 가능 여부·견적 상승폭 문의
