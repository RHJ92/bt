# shipping_request — 마켓봄 주문 → 업체별 택배 출고 요청

마켓봄에 들어온 가맹점 주문 중 **매입처·보관처가 직접 택배로 내보내는 건**을 업체별로 나눠 출고 요청서를 만드는 거점.
출고가 끝난 뒤 재고 원장 처리·월말 대사는 이 거점이 아니라 [inventory_management](../inventory_management/README.md)에서 한다.

| 폴더 | 내용 | 파일명 |
|---|---|---|
| `raw/` | 마켓봄에서 내려받은 주문서 원본 (수정 금지) | `YYMMDD_마켓봄_주문서.xls` |
| `requests/` | 업체별 출고 요청서 (발송본) | 업체마다 다름 → 아래 「업체별 양식」 (그 외 `YYMMDD_{업체명}_출고요청.xlsx`) |
| `reference/` | 마켓봄 거래처 목록 (거래처 일괄수정 양식 다운로드) — 배송지·수령인·전화 출처 | `(마켓봄)거래처_일괄수정_엑셀양식_{계정}_...xlsx` |
| `reference/templates/` | 업체별 지난 발송 파일 = 양식 원본 (수정 금지, 복사해서 사용) | 받은 파일명 그대로 |

**마켓봄 계정이 둘이다** — 주문서·거래처 파일 모두 계정별로 따로 내려받는다(파일명의 4자리 숫자).

| 계정 | 거래처 |
|---|---|
| 9517 | 블루트렌드 — 옥된장·석문어·정백선 가맹점 |
| 3802 | 육직구삼겹 등 (배송 담당자 블루푸드랩) |
| 10509 | 철산장 (문래점 등) |

**배송지 찾기** — 주문서 `거래처` = 거래처 파일 `거래처명` (같은 계정 안에서). 같은 이름이 둘이면 `거래상태` = y(거래 중) 행을 쓴다. 수령인 = `거래처 담당자명`, 전화 = `담당자 휴대폰번호`, 주소 = 우편번호 + 배송지 주소 + 상세주소.
거래처 파일은 지점 신규·이전이 있을 때만 새로 받으면 된다.

> 같은 날 같은 업체에 두 번 보내면 파일명 끝에 `_2`. 이미 보낸 요청서를 고칠 때는 원본을 두고 `_수정일자(YYMMDD)`를 붙인 새 파일로 만든다.

## 진행 순서

**1. 원본 저장** — 마켓봄 주문서를 `raw/`에 날짜 접두어로 저장

**2. 출고 대상 추리기**
- `주문상태` = **출고전**인 행만 대상 (출고완료는 제외)
- `대표 매입처` 열로 업체를 나눈다 → 아래 「업체 매칭표」에서 실제 출고처를 찾는다
- 상품명이 `(브랜드)디자인_`으로 시작하는 디자인물은 **구매팀 업무가 아니므로 제외**
- `대표 매입처`가 빈 행, 매칭표에 없는 매입처는 **임의로 넣지 말고 사용자 확인**
- `요청사항` 열은 빠짐없이 옮긴다 (지원건·직배송 사유 등이 여기 적혀 옴)

**3. 업체별 요청서 작성** — 업체 양식이 있으면 그 양식, 없으면 「기본 양식」으로

**4. 검산** — 업체별 요청서 수량 합계 = 원본 출고전 수량 합계 (업체 구분 없이 빠진 행·중복 행 0건)

**5. 발송 후 기록** — 아래 「요청 이력」에 한 줄 추가. 운송장 번호를 회신받으면 요청서 해당 열에 기입

## 업체별 양식

지난 발송 파일을 `reference/templates/`에 보관. **이 파일을 복사해 머리글·서식은 그대로 두고 2행부터 데이터만 바꿔 넣는다.**
**품명·규격은 업체 양식의 지난 표기와 달라도 마켓봄 주문서 값을 그대로 쓴다** (2026-10-20 사용자 지시).

**가야김치** — `1019_가야김치_A-type(일반)_.xlsx` → `requests/YYMMDD_가야김치_A-type(일반).xlsx`

| 열 | 넣는 값 |
|---|---|
| 주문번호 | 마켓봄 주문번호 |
| 받는사람 | 지점명 (마켓봄 거래처) |
| 전화번호1·2 | 담당자 휴대폰, **하이픈 없이**, 같은 번호 두 번 |
| 우편번호 / 주소 | 거래처 파일 우편번호 / 주소 + 상세주소 |
| 상품명1 / 상품상세1 | 마켓봄 상품명 / 마켓봄 판매규격 |
| 수량(A타입) | 수량 |
| 배송메시지 | 마켓봄 요청사항 |
| 운임구분·운임·운송장번호 | 비움 (가야김치 기입) |

**삼보물류** — `삼보_261016_택배리스트.xls` → `requests/YYMMDD_삼보물류_식기류 및 부자재.xls` (**.xls 유지**)

| 열 | 넣는 값 |
|---|---|
| 주문일 | 마켓봄 주문일시의 날짜 (서식 `mm월 dd일`) |
| 주문자 | 지점명 |
| 거래처 담당자 연락처 | 담당자 휴대폰, **하이픈 포함** |
| 우편번호 / 배송지 | 거래처 파일 우편번호 / 주소 + 상세주소 |
| 배송메세지 | 마켓봄 요청사항 |
| 품목코드 · 배송유형 | 비움 |
| 품목명 / 규격 | 마켓봄 상품명 / 판매규격 |
| 수량 | **실제 출고 낱개 수** = 마켓봄 수량 × 단위의 ea 수 (단위 `100ea`·수량 1 → 100). 단위가 `1ea`면 수량 그대로 (2026-10-28 삼보 요청) |
| **주문번호** (L열, 추가) | 마켓봄 주문번호 — 원래 양식엔 없음. 기존 열 위치를 안 건드리려고 맨 끝에 붙임 (2026-10-20 사용자 요청) |

> .xls는 openpyxl로 못 쓴다 → LibreOffice로 xlsx 변환 → 채우기 → 다시 xls 변환 (`soffice --headless --convert-to xls`).

**경인양행** — `경인양행_옥된장20261016.xlsx` → `requests/경인양행_{브랜드}{YYYYMMDD}.xlsx`

`No. / 주문일 / 수령인명 / 전화번호 / 주소 / 품목명 / 수량 / 규격 / 요청사항 / 운송장 번호` — 수령인명에 지점명, 전화 하이픈 포함.
> [inventory_management/warehouse/kyungin_유니폼 README](../inventory_management/warehouse/kyungin_유니폼/README.md)의 발주서 열 설명(A 수령처…)은 옛 양식. **실제 발송은 이 양식.**
> 지난 파일은 품목명 `맨투맨 유니폼` + 규격 `2XL`로 나눠 썼지만, 여기서는 마켓봄 상품명·규격 그대로 넣는다.

**본사 직접 출고(정백선 소모품 등)** — 외부 양식 없음. 아래 기본 양식으로 출고 메모·송장만 남긴다.

**천안축산물유통센터 — 텍스트 주문** (파일 없음, 사용자가 카톡으로 전달)

```
안녕하세요, 철산장 주문 전달드립니다.

■ 주문일: MM/DD(요일)
■ 배송지: {지점명}
  {주소}
  {수령인} {전화}

- {마켓봄 상품명 — 리드타임 문구는 뺌} / {규격} / {수량}{단위}

확인 부탁드립니다.
```

- 날짜는 **배송일이 아니라 마켓봄 주문일시의 날짜** (2026-10-26 사용자 지시)
- 품명은 마켓봄 상품명에서 `/리드타임:…` 부분만 떼고 그대로, 규격·단위도 마켓봄 값
- 한 지점 여러 품목이면 `-` 줄을 늘리고, 지점이 여럿이면 배송지 블록을 반복

## 떠리몰 주문 (마켓봄 외)

떠리몰(임박 할인 판매몰)에서 BT가 파는 상품 — 현재 **한돈 돼지꼬리(스킨제거) 10kg**. 결제완료 리스트를 받아 업체 공유용으로 가공한다.

- 원본: 떠리몰 관리자 「결제완료 리스트_YYYYMMDDHHMM.xlsx」(다운로드는 .zip) → `raw/`
- 양식: `reference/templates/떨이몰_결제완료 리스트_1026.xlsx` (지난 공유본) → `requests/떨이몰_결제완료 리스트_MMDD.xlsx`
- 출고처: 돼지꼬리 보관처 **한솔냉장**(추정 — 확인 필요). 재고는 통합 재고관리 `축·수산·기타 재고 입력` 시트

**원본 → 공유본 가공 규칙** (양식 파일을 틀로 쓰면 열 너비·숨김이 그대로 유지됨)

| 원본 | 공유본 |
|---|---|
| `상품명` | 머리글만 `㈜블루트렌드 상품명`으로, 값 그대로 |
| `배송메모` 뒤 | **3열 추가** — `출하요청일`(공유일, `YYYY-MM-DD` 텍스트) / `규격`(상품명의 kg → `10KG`) / `수량`(`{수량} BOX`) |
| `개인통관인증번호` | 삭제 |
| `우편번호` | 숫자로 |

## 기본 양식 (= 통합 양식, 업체 양식이 없을 때)

위 업체별 양식이 없는 출고처(본사 직접 출고, 신규 업체)는 이 양식을 쓴다.

`requests/YYMMDD_{업체명}_출고요청.xlsx` — 1행 머리글, 1행 1품목. 글꼴은 맑은 고딕(본문 9 / 제목 12).

| 열 | 내용 |
|---|---|
| A 배송요청일 | 마켓봄 `배송요청일` |
| B 주문번호 | 마켓봄 `주문번호` (회신 대조용 키) |
| C 수령처 | 지점명 |
| D 수령인 / E 전화 / F 주소 | 주문서 배송지 |
| G 상품명 | **마켓봄 상품명 그대로** |
| H 규격 / I 수량 | `판매규격`·`단위` / `수량` |
| J 요청사항 | 마켓봄 `요청사항` |
