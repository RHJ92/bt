# inventory_management — 재고자산 관리

외부 냉장·냉동 창고에 보관 중인 자사 재고(비축 원물·기물)의 **수량·평가액·보관료** 관리 거점.
창고사에서 월말 보내오는 보관료 마감 정산서(거래명세표)와 우리 재고 현황표를 대사(對査)한 기록을 남긴다.

## 폴더 구조

| 폴더 | 내용 |
|---|---|
| `octopus/` | 자숙문어 비축 재고 (삼성냉장·삼일냉장 등) — 월별 대사 MD + `raw/` 원본 |
| `tableware/` | 식기류·쇼핑백 (삼보종합물류 평택) — 월별 대사 MD + `raw/` 원본 |

각 폴더: `YYYY-MM_창고사_품목_대사.md`(대사 결과) + `raw/`(정산서 PDF·현황표 xlsx 스냅샷, 날짜 접두어)

## 대사 기본 절차

1. 창고사 거래명세표에서 **로트별 재고수량·일수·단가·소계** 추출
2. 자사 현황표에서 해당 창고 + **미출고** 행만 필터
3. 대조 순서: ① 총수량 → ② 품목·규격별 합계 → ③ 로트(입고일자)별 개별 행
4. 보관료 재계산: 청구 공급가액과 일치하는지 (수량비례형·고정형 구분)
5. 불일치는 **수량 차이**(실물 문제, 즉시 확인)와 **표기 차이**(규격·일자 라벨, 장부 정리)로 구분
