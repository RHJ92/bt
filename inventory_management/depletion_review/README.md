# depletion_review — 품목별 재고 소진·폐기 리스크 검토 (일회성)

특정 품목의 **재고가 언제 소진되는지, 그 전에 유통기한이 먼저 오는지**를 건별로 따져 보는 곳.
정기 루틴이 아니라 **필요할 때 한 건씩** 만든다 — 유통기한이 다가오거나, 추가 매입 여부를 정해야 하거나,
단종·규격 변경으로 남은 재고를 털어야 할 때.

> **월 루틴(재고자산 평가·창고사 대사)은 여기가 아니다.** 그건 [stock/](../stock/)·[warehouse/](../warehouse/) 소관.
> 여기는 **금액이 아니라 시점**을 보는 곳이다.

## 폴더 구조

| 폴더 | 내용 |
|---|---|
| `reviews/` | 건별 검토서 `YYMMDD_품목명_소진폐기검토.md` + 계산 엑셀 `..._계산.xlsx` (요약·시뮬레이션·판단 시트 + 원본 로우데이터 동봉) |
| `raw/` | 출고내역·재고 스냅샷 등 원천 데이터 (마켓봄·ERP 다운로드 원본 그대로) |
| `_템플릿_소진폐기검토.md` | 새 건 시작할 때 복사해서 쓰는 양식 |

## 작업 절차

**1. 재고 확정** — 로트별로 나눠 잡는다. 유통기한이 로트마다 다르면 합산 수량으로 보면 안 된다.
   - 마켓봄 식기류·유니폼: [stock/통합_재고관리(로트기반)_260907.xlsx](../stock/) → 「재고 현황」·「로트 마스터」
   - 축·수산품, 밀키트 등 마켓봄 외: 같은 파일 → 「축·수산·기타 재고 입력」 (조회는 「재고자산 명세」)
   - 창고 실물과 장부가 다를 소지가 있으면 창고사 회신을 먼저 받는다

**2. 출고 실적 뽑기** — 최근 6~12개월. 원본은 `raw/`에 그대로 두고 가공은 검토서에서 한다.
   - **순출고 기준**(출고 − 반품)으로 본다. 총출고로 계산하면 소진이 실제보다 빨라 보인다
   - 월별 표 → 월평균 / **최근 3개월 평균** / 일평균(달력일) 세 값을 다 낸다

**3. 소진시점 산출** — `현 재고 ÷ 일평균 = 잔여일수` → 소진 예정일.
   - 기본은 **최근 3개월 평균**으로 잡는다(전체 평균은 계절성·단가 조정 이력에 끌려간다)
   - 성수기·비수기가 뚜렷한 품목은 전년 같은 기간 지수를 곱해 보정하고, 보정했으면 그 근거를 적는다
   - 예정된 생산·행사 소요분이 있으면 재고에서 먼저 뺀다

**4. 폐기 리스크 판정** — 소진 예정일과 **유통기한(로트별)** 을 나란히 놓는다.

| 등급 | 조건 | 뜻 |
|---|---|---|
| 🟢 안전 | 소진 예정일이 유통기한보다 **60일 이상** 빠름 | 그대로 둔다 |
| 🟡 주의 | 여유 **60일 미만** | 추가 매입 보류 + 소진 촉진 검토 |
| 🔴 위험 | 소진 예정일이 **유통기한을 넘김** | 폐기 발생 확정 — 수량·금액을 산출한다 |

   - 위험 등급은 **폐기 예상 수량 × 취득단가 = 예상 손실액**까지 낸다. 금액이 나와야 조치가 결정된다
   - 유통기한 자체가 불명확하면 그걸 먼저 확인한다. 추정으로 폐기를 판단하지 않는다

**5. 조치 정리** — 판단만 적고 끝내지 않는다. 누가 무엇을 언제까지 하는지로 닫는다.
   (추가 매입 보류 / 선출고 우선순위 조정 / 매입처 반품·교환 협의 / 프로모션·묶음 소진 / 폐기 손실 인식)
