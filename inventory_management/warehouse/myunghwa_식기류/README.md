## 회신 양식 — 단일 파일, 월별 시트

**[명화주방_식기류_월말재고_회신대장.xlsx](명화주방_식기류_월말재고_회신대장.xlsx)** — 현행본. 매달 새 파일을 만들지 않고 **이 파일 하나에 월 시트를 추가**해 쓴다.
작성 예시: [명화주방_식기류_월말재고_회신대장_작성예시.xlsx](명화주방_식기류_월말재고_회신대장_작성예시.xlsx) (명화주방 발송 시 함께 전달)
폐기한 1~3차안은 `archive/`에 보관.

| 시트 | 역할 | 명화주방 기재 | 당사 기재 / 자동 |
|---|---|---|---|
| `2026-10`, `2026-11` … | 월별 회신 | **실사수량**, 비고 | 기준일, 당사 장부잔량 / 순번·생산일·품명·로트번호·생산수량·차이·합계 |
| 로트대장 | 생산 로트 누적 관리 | 신규 생산 시 생산일·품명·생산수량 | 순번, **로트번호** |
| 품목표 | 품명 대조 | 품목 추가 시에만 | 품명(통합) |

**월 시트는 로트대장을 참조해 자동으로 채워진다.** 로트대장에 생산 1줄을 추가하면 그 달 이후 모든 월 시트에 자동으로 나타나고,
**기준일보다 생산일이 늦은 로트는 해당 월 시트에 표시되지 않는다**(11월 생산분이 10월 시트에 끼지 않음).

**다음 달 시트 만드는 법** — 직전 월 시트를 복사 → 시트명을 `YYYY-MM`으로 변경 → 기준일을 그 달 말일로 수정 → 장부잔량·실사수량·비고만 지우고 발송.

- **로트번호 자동 생성** — `생산일(YYMMDD)-순번`, 순번은 11111부터 1씩 증가(파일 전체 통산). 삼보 보관분(`-0…`)과 첫 자리로 구분
- **품명은 「품명(통합)」으로 통일** — 품목표에서 `명화주방 품명 + (당사 약칭)`을 자동 결합. 예: `티타늄찬기 (국그릇)`
- 평소 명화주방이 쓰는 칸은 **실사수량 1칸**. 신규 생산이 있을 때만 로트대장에 3칸 추가
- **출고내역은 받지 않는다** — 출고는 당사가 마켓봄·출고 요청 기준으로 집계(→ `shipping_request/`). 삼보물류 대사와 같은 방식

| 품명(통합) | 명화주방 품명 | 당사 상품명(마켓봄) | 상품코드 | 규격(명화/당사) |
|---|---|---|---|---|
| 티타늄찬기 (국그릇) | 티타늄찬기 | (옥된장)티타늄_국그릇 (304) | 1448335 | Ø135*36 / 133*45 |
| 티타늄접시 (김치찜접시) | 티타늄접시 | (옥된장)티타늄_김치찜 접시_304 | 1448340 | Ø170*17 / 170*15 |

**검산 이력(2026-10-20)** — 로트 3건(10/22·10/27·11/18)으로 확인: 11월 생산분은 10월 시트 제외, 11월 시트에만 표시(순번 11113).
10월 차이 -2(장부 850·실사 848), 11월 차이 0, 합계 정상.

## 월말 루틴

1. **당사 장부잔량 산출** — 통합 재고관리 파일에서 명화주방 창고 로트별 잔량을 뽑는다
2. 회신 양식에 기준일과 장부잔량을 채워 **명화주방에 발송**
3. 회신 수령 → `raw/`에 `YYMMDD_명화주방_N월_재고회신.xlsx`로 보관
4. **차이 열 확인** — 0이면 그대로 확정, 0이 아니면 비고의 사유와 함께 처리(파손·분실은 재고조정, 오출고는 출고 기록 수정)
5. 회신 실사수량을 통합 재고관리 `월말 대사` 시트의 회신 열에 입력 → 차이 0 확인
6. **신규 생산분은 로트 등록** — 통합 재고관리 `입출고 원장 입력`에 `생산입고` 행 추가 (창고 = 명화주방)

**창고 구분** — 통합 재고관리 파일의 창고 값에 `명화주방`을 새로 쓴다(기존: 삼보물류·경인양행·본사창고·삼성냉장·한솔냉장).

같은 품목이 **삼보물류(기존 재고)와 명화주방(신규 생산분)** 두 곳에 있는 기간이 생긴다.

- 2026-10-01 기준 삼보 잔량: 국그릇 316 · 김치찜접시 202
- 삼보 잔량이 소진되면 마켓봄 출고처를 명화주방으로 전환
- 전환 전까지는 **두 창고 합산이 총 재고**이므로 월말 대사도 양쪽 다 받아야 한다

## 남은 확인 사항

- **김치찜접시 규격** — 견적서 Ø170*14 / 10.15 명세서 Ø170*17. 양식에는 명세서 표기(Ø170*17)로 넣어 둠. 명화주방 회신 오면 품목표 수정
- **생산 순번(11111→11112) 기준** — 현재 양식은 **보관처 전체 통산**(품목 구분 없이 생산 순서대로). 품목별로 따로 매겨야 하면 수식 수정 필요
- **회신 주기** — 양식에 "매월 말일 기준 회신"으로 표기
