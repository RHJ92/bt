## 핵심 구조 — 품목코드 2단

마켓봄은 **유니폼을 사이즈별 개별 상품**으로 등록해 두었고(`반팔 유니폼_M`, ok0011 …),
경인양행 매입원가는 **사이즈가 아니라 구매 시기별**로 갈린다. 그래서 두 축을 분리했다.

| 축 | 단위 | 쓰이는 곳 |
|---|---|---|
| **품목코드** | 마켓봄 상품 1:1 (유니폼은 사이즈별) — 64개 | 원장 입력·출고 대사·창고 실사 |
| **원가품목** | 사이즈 통합 (브랜드+품목) — 46개 | 로트·재고자산 평가·선입선출 |

「입출고 원장 입력」 F열 `원가품목(자동)`이 품목 마스터에서 자동으로 끌어온다(수식, 3,000행 미리 채움 — 손대지 말 것).
품목코드를 잘못 적으면 `❌코드확인`이 뜨고 셀이 빨갛게 표시된다.

**왜 이렇게 나눴나** — 경인양행 재고는 사이즈별 수량은 알지만(2026-08-28 실사) 각 사이즈가
어느 매입 시기 원가인지는 알 수 없다. 원가층을 사이즈까지 쪼개면 없는 근거를 지어내야 해서,
**수량은 사이즈별로, 원가는 품목별로** 관리한다.

## 과세 / 면세 구분

- **재고자산은 전부 공급가액(부가세 별도) 기준**이다. 식기류·유니폼 단가 모두 확인 완료
  (예: 디저트접시 2,327.27 × 1.1 = 2,560).
- **품목 마스터 G열 `과세구분`** 이 기준점. 로트 마스터·재고 현황·월말 대사·월마감이 전부 이 값을 자동으로 물어온다.
- 현재 64품목 전부 `과세`. **축산품·수산품이 편입되면 품목 마스터 G열에 `면세`만 입력**하면
  로트 마스터 과세/면세 소계, 재고 현황 브랜드별 과세·면세 자산, 월마감 요약이 자동으로 갈린다.

## 소유법인과 이관 기준일 (2026-09-01)

**2026-08-31까지** 재고는 블루트렌드·옥된장에프엔비·석문어에프엔비·정백선에프엔비 **4개 법인에 나뉘어** 있었다.
**2026-09-01자로** 옥된장·석문어·정백선 재고를 전부 블루트렌드로 이관했다 — 근거는 [transfer_260831](../transfer_260831/) 견적서·명세서.

**이관 대상은 유니폼·기물 16로트뿐이다.** 식기류 35로트(삼보물류)는 **2025-06 블루트렌드가 옥된장에서 인수한 뒤
줄곧 BT 재고자산이었고 앞으로도 그렇다** — 이관 대상이 아니다.
로트 마스터 D열 매입처의 `옥된장 인수(이관)`·`옥된장 구매(유진)→BT 매도`는 **2025년 당시 매입 경로 표기일 뿐
소유법인이 아니다**(20로트). 소유는 G열이 기준이고, 식기류 35로트 전부 `블루트렌드`다.

이관은 **수량이 움직인 게 아니라 소유와 평가액이 바뀐 것**이라 원장에 행을 넣지 않고 로트 속성으로 처리한다.

| 로트 마스터 열 | 내용 |
|---|---|
| `소유법인(~26.08.31)`(G) | 2026-08-31까지의 소유 — 블루트렌드(식기류 35로트) / 옥된장 8 / 석문어 4 / 정백선 4 |
| `브랜드 매입단가`(H) | 브랜드가 경인양행·온라인몰에서 산 원가 → **8월말까지 평가 기준** |
| `BT 취득단가`(I) | 브랜드 원가 ÷ 0.99 (마진 1%) → **9/1부터 평가 기준** |

「월말 대사」 시트의 **B1 기준일**이 스위치다. 기준일이 `2026-08-31` 이전이면 소유법인이 법인별로 갈리고
브랜드 매입단가로, `2026-09-01` 이후면 전부 블루트렌드·BT 취득단가로 자동 전환된다.
「재고 현황」은 항상 현재 시점(이관 후) 기준이라 전액 블루트렌드다.

### 2026-09 마감부터의 귀속 원칙 (확정)

**9월 재고자산부터 영영상점을 뺀 모든 재고가 블루트렌드(BT) 앞으로 귀속된다.**

옥된장·석문어·정백선 3개 법인은 **0원**으로 떨어진다 (행은 대사용으로 남겨 둔다).

| 구분 | ~2026-08 | 2026-09~ |
|---|---|---|
| 마켓봄 재고(식기류·유니폼·기물) | 블루트렌드 / 옥된장 / 석문어 / 정백선 4법인 | **블루트렌드 전액** |

**9월 마감 때 할 일은 「월말 대사」 B1에 `2026-09-30`을 넣는 것뿐이다.** 소유법인·적용단가가 자동으로 갈아탄다.
「축·수산·기타 재고 입력」 시트에 9월 기타 재고를 수기 입력할 때도 **사업자는 `블루트렌드`·`영영상점` 두 값만 쓴다.**
「재무팀 재고자산 명세」는 두 시트를 자동으로 따라오므로 **따로 손댈 게 없다** — 재무팀에는 B2 마감월만 `2026-09`로 바꿔 주면 된다.

## 월마감 붙여넣기 블록 — 「월말 대사」 S1:Y53 (2026-10-01)

「마켓봄_월마감」에 새 달을 만들 때 **아무것도 손으로 치지 않는다.** 「월말 대사」 오른쪽 블록을
통째로 복사해 값으로 붙여넣으면 끝이다.

| 블록 | S | T | U | V | W | X | Y |
|---|---|---|---|---|---|---|---|
| 내용 | **마감월** | 로트번호 | 원가품목 | 소유법인 | 잔량 | 단가(공급가액) | 자산 |
| 출처 | `TEXT(B1,"yyyy-mm")` | 대사 A | B | **D** | E | F | G |

월마감 **A~G와 순서가 똑같다.** 월말 대사는 3번째에 **과세구분**이 끼어 있어 A~G를 그대로 복사하면
한 칸씩 어긋난다 — 그 칸을 뺀 블록이다.

**월마감 만드는 법 (3단계)** — ① 차이(I열) 0 확인 → ② `S3:Y55`(2026-11-03 명화 로트 2행 추가 전에는 S3:Y53) 복사 → ③ 「마켓봄_월마감」 **A열 첫 빈 행**에 **값으로** 붙여넣기.
H·I·J(브랜드·과세구분·카테고리)와 K~S 요약은 자동이다. **요약은 2027-06까지 미리 깔아 놨다.**

> **반드시 「값 붙여넣기」로 할 것.** 월마감은 확정 스냅샷이다. 수식으로 걸어 두면 나중에 원장을 고칠 때
> 이미 재무팀에 보고한 지난달 마감값까지 같이 움직인다. 실제로 「월말 대사」를 수식으로 참조하는 시트는 없다 —
> 월마감으로 넘어가는 지점이 **값 붙여넣기**인 게 설계다.

## 매월 재고 마감 루틴 (2026-10-08 확정)

마감은 **대사 → 마감 → 보충** 세 단계다. 세 번째가 2026-10-08에 추가됐다.

**1단계 — 대사**
1. 삼보물류 자료 수령(거래명세서·택배 발송현황·재고현황 회신) → `warehouse/sambo_식기류/raw/`
2. 「월말 대사」 **B1에 마감월 말일** 입력
3. **H열** 삼보 로트 회신 붙여넣기 → I열 차이 0 확인
4. **O열** 경인양행 실사, **P열** 본사창고 실사 입력 → Q열 차이 0 확인
   - 차이가 나면 「입출고 원장 입력」에 `출고`(누락 선출고) 또는 `실사조정` 행을 넣어 해소한다
5. 삼성냉장 자숙문어 마감장 수량 대사 → `warehouse/samsung_자숙문어/`

**2단계 — 마감**
6. 「월말 대사」 **`S3:Y55` 복사 → 「마켓봄_월마감」 첫 빈 행에 값 붙여넣기** (마감월 포함, 손으로 칠 것 없음)
7. 「축·수산·기타 재고 입력」에 그달 축산·수산·밀키트 입력
   - **입력 후 이 시트 「LS_축산품창고」 탭과 반드시 대조한다** (2026-11-03 「claude_ 축산품」에서 이 시트로 이전).
     이 시트는 **수기 입력이라 입출고 원장이 없다** — 한 줄이 통째로 빠져도 파일 안에서는 안 걸린다.

## 월말 대사 시트 열 구성

**왼쪽(A~J) = 로트별 재고자산 확정 + 삼보물류 로트 대조**
`로트번호 / 원가품목 / 과세구분 / 소유법인(기준일) / 기준일 잔량 / 적용단가 / 자산(기준일) / 삼보물류 로트 회신(입력) / 차이 / 매입일`
삼보물류는 **로트번호 단위로 재고현황을 회신**하므로 H열에 붙여넣고 I열 차이 0을 확인한다(식기류 기존 방식).
경인양행·본사창고는 로트 단위 회신이 없어 이 칸을 비워 둔다.
아래에 **소유법인 4개 소계 + 과세/면세 소계 + 합계** 행이 붙는다.

**오른쪽(L~Q) = 경인양행·본사창고 실사 대조** (유니폼·기물 30품목만)
`품목코드 / 경인양행(장부) / 본사창고(장부) / 경인양행(회신) / 본사창고(회신) / 차이`
두 창고는 **품목(사이즈)별로 실사**하므로 여기서 대조한다.

> 이전 버전에는 오른쪽에 `삼보물류(장부)·삼보물류(회신)` 열이 있었는데, 삼보는 왼쪽 로트 대조로 처리하므로
> **중복이라 삭제**했다. 식기류 34품목도 오른쪽에서 뺐다(경인양행·본사창고에 재고가 없어 전부 0이었음).

## 「재무팀 재고자산 명세」 시트 — 재무팀이 보는 곳 (2026-09-09 신설)

**왜 만들었나** — 재무팀은 매월 사업자별 재고자산을 **품목까지 보이게** 받고 싶은데, 기존 구조는
품목 명세가 두 시트에 쪼개져 있고 둘을 잇는 지점이 총액뿐이라 매달 손으로 붙여 가공해야 했다.

| 시트 | 단위 | 재무팀이 못 쓴 이유 |
|---|---|---|
| 마켓봄_월마감 | 로트 (2026-08 = 51행) | 품목은 보이는데 축산·수산·밀키트가 없다 |
| 전사 재고자산 요약_08 (현 축·수산·기타 재고 입력) | 품목 (2026-08 = 40행) | 마켓봄 재고가 L열 요약에 **총액 한 줄**로만 들어왔다 |

**구조** — 두 시트를 같은 13열로 세로로 이어 붙인 **파생 시트**다. 입력 경로는 그대로고,
행 단위 1:1 참조 수식이라 **매달 추가 작업이 없다.**

| 행 · 열 | 내용 |
|---|---|
| 1~2 | 제목 + `B2 마감월`(드롭다운) — **왼쪽 사업자별 요약만** 이 값을 쓴다 |
| 3~9 · A~H | **사업자별 요약** — 사업자 × **마켓봄 / 축·수산·기타** / 과세 / 면세 / 합계(공급가액) / 합계(VAT 포함) / 행수 |
| 3~6 · J~N | **자가 검증** — 명세 합계를 「마켓봄_월마감」 요약·「축·수산·기타 재고 입력」 합계와 대사. `OK` / `[!] 차이` |
| 3~10 · P~AB | **마감월별 추이** — 사업자 × 마감월 12개(2026-07~2027-06) 크로스탭. B2와 무관하게 전월을 한 줄로 편다 |
| 11 | 명세 머리글 (**자동필터**, 틀 고정 A12) |
| 12~497 | **마켓봄 블록** ← 「마켓봄_월마감」 3~488행 |
| 498~894 | **기타 블록** ← 「축·수산·기타 재고 입력」 4~400행 |

**요약 블록 두 개는 자동필터 위(3~10행)에 둔다.** 필터를 걸면 행이 통째로 숨으므로, 요약이 필터
범위 안에 있으면 재무팀이 사업자를 고르는 순간 사라진다. 그래서 명세 머리글은 11행부터다.

`마감월 / 사업자 / 원천 / 구분 / 브랜드 / 품목명 / 로트번호·근거 / 과세구분 / 단위 / 수량 / 단가(공급가액) / 재고자산(공급가액) / 재고자산(VAT 포함) / 보관처·비고` (14열)

- **명세는 전월 누적**이다. 마감월을 시트로 나누지 않고 **자동필터로 월을 고른다** — 월 비교가 바로 된다
- **`원천`(C) 과 `구분`(D)을 나눠 놨다** — 둘 다 추측이 아니라 원본 시트가 정한 값이다 (2026-09-09)

  | 열 | 마켓봄 블록 | 기타 블록 |
  |---|---|---|
  | `원천` | `마켓봄` 고정 | `기타` 고정 |
  | `구분` | 「마켓봄_월마감」 **J열 카테고리(자동)** ← 품목 마스터 B열 | 「축·수산·기타 재고 입력」 **C열**(드롭다운) |

  **`부자재`가 양쪽에 다 있어서** `원천` 열이 따로 필요하다 — 마켓봄 부자재는 정백선 물티슈·앞치마·수저봉투,
  기타 부자재는 영영상점 냅킨·종이컵 등이다. 요약의 마켓봄/기타 분해를 명세에서 대사하려면 `원천`으로 필터한다.

  2026-08 기준 9종 91행 — 마켓봄: 식기류 34 / 유니폼 11 / 부자재 3 / 쇼핑백 2 / 펌프 1,  기타: 밀키트 20 / 축산품 12 / 부자재 5 / 수산품 3
- 구분이 비면 마켓봄은 **`⚠카테고리 미확인`**, 기타는 **`⚠구분 미입력`** 으로 떠서 필터로 바로 잡힌다
- **숫자 서식은 `#,##0`** — 파일 전체(마켓봄_월마감·축·수산·기타 재고 입력) 관례에 맞췄다.
  `#,##0.##` 은 정수에도 소수점을 찍어(`711,829,212.`) 읽기 나빠서 2026-09-09에 3,640셀을 일괄 교체했다.
  **표시만 반올림이고 저장값·계산은 소수 그대로다** — 디저트접시 단가 2,327.27,
  자숙문어 159,577.5, 축산 kg 1,674.4 등. 그래서 화면의 `수량 × 단가`가 `재고자산`과 1원 안팎으로
  안 맞아 보일 수 있는데, 원본 두 시트도 예전부터 같은 서식이라 재무팀이 보던 그대로다
- 마켓봄 쪽에 없던 3열을 채워 넣는다 — **단위**(`ea` 고정), **VAT 포함액**(과세면 행별 `ROUND(×1.1,0)`), **보관처**(로트 마스터 창고 열에서 `INDEX/MATCH`)
- 「축·수산·기타 재고 입력」 J열이 `확정`이 아닌 행은 비고 끝에 **`· ⚠검증 …`** 이 붙는다

### B2 마감월이 날짜로 변해 요약이 0이 되던 문제 (2026-09-09)

3. **자가 검증을 3상태로** 나눴다 — 마감 전인 달을 골랐을 때 오류처럼 보이던 문구를 분리했다

### 정렬해도 안 깨진다 (2026-09-09)

**증상** — 마감월을 고르고 자동필터에서 사업자를 오름차순/내림차순으로 정렬하면
요약 4~9행의 `마켓봄 재고`·`축·수산·기타` 두 열 값이 튀었다.

**원인** — 그 두 열이 **블록 행 범위**로 갈라져 있었다
(`마켓봄 = L12:L497` / `기타 = L498:L894`). 정렬하면 마켓봄 행과 기타 행이 섞여
497/498 경계가 무의미해진다. 나머지 열(과세·면세·합계·행수)은 전체 범위라 멀쩡했다.

**고친 것 2가지**

1. **요약의 마켓봄/기타를 `원천` 열 조건으로 바꿨다.** 행 위치가 아니라 값으로 가르니 정렬 무관이다
2. **본문 수식의 원본 참조를 전부 절대참조로 바꿨다** (`'마켓봄_월마감'!$A3` → `$A$3`).
   같은 행 참조(`IF($A12="",…)`, `MATCH($F12,…)`)도 전부 원본 셀 직접 참조로 교체해
   **명세 셀은 자기 행의 다른 셀을 일절 보지 않는다.** 엑셀 정렬이 참조를 보존하든 재조정하든
   각 행은 자기 원본 행에 그대로 묶여 있다

**검증** — 사업자 오름차순으로 883행을 실제 재배치한 뒤 재계산해 대조했다.

### 왜 요약을 한 곳으로 몰았나 (2026-09-09)

명세 시트를 만든 뒤에도 **요약이 두 군데 있었고 어느 쪽도 상위집합이 아니었다.**
「전사 재고자산 요약」 L~Q에는 마켓봄/기타 분해가 있고 VAT·행수가 없었으며, 명세 요약은 그 반대였다.
그래서 재무팀이 여전히 두 시트를 오갔다. 세 가지를 한꺼번에 정리했다.

1. **명세 요약을 6열 → 8열**로 넓혀 두 블록의 합집합으로 만들었다 (마켓봄/기타 분해 추가)
2. 중복이 된 **「축·수산·기타 재고 입력」 L~Q 블록을 삭제**했다
3. 시트명 `전사 재고자산 요약_08` → **`축·수산·기타 재고 입력`** — 이름이 역할(입력 전용)을 드러내게 했다.
   참조하던 명세 수식 3,970개를 함께 고쳤고 재계산 결과 `#REF!` 0건·금액 차이 0이다

**"기타 재고를 명세 시트에 직접 입력하게 하자"는 방향은 택하지 않았다.** 498행 아래를 입력칸으로
바꾸면 위쪽 마켓봄 486행은 수식, 아래는 입력값인 한 표가 된다. 필터를 걸어 둔 채 타이핑하다
수식 행을 덮어쓰면 장부가 조용히 깨진다. **입력과 조회를 시트로 가르되 이름으로 그걸 드러내는 쪽**을 택했다.

| 시트 | 역할 | 누가 |
|---|---|---|
| 품목 마스터 / 입출고 원장 / 로트 마스터 / 재고 현황 / 월말 대사 | 마켓봄 원장·마감 | 구매팀 |
| 마켓봄_월마감 | 마켓봄 월 스냅샷 (값 붙여넣기) | 구매팀 |
| **축·수산·기타 재고 입력** | 축·수산·밀키트 수기 입력 | 구매팀 |
| **재고자산 명세** | **조회·보고 (유일한 창구)** | **재무팀** |
