## 「식기류 입출고내역」 입력 규칙

- 열 구조: A 일자 / B 브랜드명 / C 지점명 / D 구분 / E~AL 품목별 수량 / AM 반품사유 / AN 비고
- **일자는 창고 발송일 기준** (주문일 아님)
- 수량 부호: **출고 = 음수(-), 입고 = 양수(+)**. 재고조정·실사도 부호로 처리
- 구분 실사용 값: 입고 / 출고 / 반품입고(폐기) / 반품입고(재판매) / 교환출고 / 재고실사 (드롭다운 4종 외 변형 표기 혼용됨)
- 재고실사 행: 지점명에 "재고실사"/"재고정정" 기입, 차이 수량만 ± 입력
- 지점명 표기: "정백선순대 상암점" 등 (브랜드 = 정백선 / 옥된장 / 석문어 / 기타)
- 입고처 이력: 고려주방(24.09 초도) → 유진(24.10~25.05) → 현대기물(25.06~25.11) → 키친닷·가온건축(복전골냄비) → Shanghai Yangguang(정백선 쇼핑백)

1. 삼보 거래명세서·택배 발송현황·재고현황(원화주) 수취 → `raw/`에 날짜 접두어로 보관

3. 「식기류 입출고내역」에 발송일 기준으로 출고 행 입력
4. 「로트 관리」: K열에 삼보 회신 수량만 붙여넣기 → L열 차이 0 확인 (H열은 원장 입력 시 자동). 신규 입고 시 명세서의 로트번호로 행 추가
5. 「회계팀 재고마감 자료」: **직전월 2행 복사→아래 붙여넣기, 라벨만 「MM.DD」로 수정** (수량 칸이 로트 관리를 SUMIF 자동 참조 — 손 입력 없음) → **지난달 2행은 "값으로 붙여넣기"로 동결**

## 「로트 관리」 시트 설계 메모

- 열: 로트번호 / 품목 / 브랜드 / 창고입고일 / 입고처 / 원가층 / 입고수량(G) / 현재고(H) / 단가(I) / 로트자산(J=H×I) / 삼보 회신 재고(K) / 차이(L=H−K) / 삼보 품명 / 비고 / 회계열키(O)
- **G·H·I는 전부 수식 — 출처 추적 가능** (2026-08-03 수식화):
  - G 입고수량 = `VALUE(RIGHT(로트번호,5))` — 로트번호에서 파싱 (-00000 로트는 공란)
  - H 현재고 = ① 단일로트: `SUM(입출고내역 품목열)` ② 옥→BT/직매입 페어: 직매입행 = `XLOOKUP(본사 단가 C열 매입합계)`(미출고 전량), 옥→BT행 = 원장합계 − 직매입행 ③ 국그릇 260126만: `=K`(창고회신 기준 — 원장 열로는 두 로트 분리 불가)
  - I 단가 = `XLOOKUP(품목, 본사 단가)` — 옥→BT층은 D열, @→BT층은 B열. 본사 단가에 없는 품목(직사각볼·복전골·쇼핑백)은 회계팀 시트 단가행(4행·7행) 참조
- **B열 품목명은 본사 단가 ITEM 표기와 동일** (XLOOKUP 키이므로 변경 금지)
- 품목 총량 검증: 원장 열합계 = 창고 기준과 **전 품목 일치 확인됨** (밥그릇 2종 포함)
- **주의**: 원장 M4·N4(고려주방 초도입고)는 상수가 아니라 **수식**(`=1475-675`, `=1056+675`)으로 입력돼 있음. 엑셀 SUM은 정상 계산하지만, 외부 도구로 검산할 때 수식 셀을 빠뜨리면 −800/−1,731 유령 차이가 생기니 주의 (2026-08-03 오탐 사례)
- 단가는 **회계팀 시트 현행 적용 단가**로 매핑 → 로트자산 합계 = 회계팀 총자산(229,031,603.25)과 일치 검증됨
- **원가층 2개는 모두 정상** (2026-08-03 사용자 확인): 옥→BT = 옥된장이 유진에서 구매 후 BT에 매도한 재고의 매입가 / @→BT = BT가 유진에서 직매입한 매입가. 같은 304 소재라도 구매 주체에 따라 단가가 다름
- **O열 = 회계열키**: 로트마다 회계팀 시트의 대응 열문자(F, G, AD…) 기입. 회계팀 실사수량 행이 이 키로 `SUMIF('로트 관리'!O:O, 키, H:H)` 자동 집계 — 월마감 층별 배분 수작업 제거 (2026-08-03 도입, 07.31 행부터)
- 삼보 로트번호 규칙: `창고입고일(YYMMDD)-입고수량(5자리)`. 일부 로트는 수량 자리가 -00000(미기재), 밥그릇SET/304는 표기(-00055)와 실재고 상이
