## 3단계 로드맵

### Phase 1 — 7/13 ~ 9/6 (약 8주): 국비교육 = 실기 저금통
- 별도 시험공부 없음. **국비교육 태블로 수업이 곧 실기 준비.**
- 단, 수업을 "시험 관점"으로: 배우는 기능마다 노트에 정리 — 계산된 필드, LOD 표현식, 필터/정렬, 매개변수, 대시보드 구성, 차트 유형별 만들기
- 8월 중: 대한상의 관련자료 페이지에서 **공식 출제기준 + 실기 모의문제 다운로드** → 국비교육에서 뭘 더 집중해 들을지 가늠
- [ ] 필기 교재 주문 (9월 초까지)

### Phase 2 — 9/7 ~ 10/2 (4주): 필기
- 후기 기준 필기는 평이 (통상 2주 준비 합격) — 4주면 여유
- W1~W2: 교재 1회독 + 챕터 문제 (경영정보 일반 / 데이터 해석·활용 / 시각화 디자인 영역)
- W3: 공식 공개문제 + 교재 모의고사, CBT 형식 적응
- W4: 오답 정리 → **10/3(토) 필기**
- [ ] 접수 오픈 즉시 등록 (license.korcham.net)

### Phase 3 — 10/4 ~ 11/6 (5주): 실기 (승부처)
- **⚠️ 합격률 경보**: 2024년(첫해) 최종 합격률 약 4.2% — 필기는 쉬우나 실기가 극악이었음. 2회차부터 지문 명확화·부분점수 인정으로 개선 추세지만, 실기를 "어려운 시험"으로 전제하고 준비할 것
- 대응: ① 유선배 기출복원 전부 2회독 ② 부분점수 전략 훈련(다 못 풀어도 70점 합격 사례 있음 — 모든 문제에 흔적) ③ 1트 탈락해도 재도전 비용은 3개월+45,000원(필기 2년 유효, 다음 실기 2027년 2월 초) — 플랜 붕괴 아님
- W1: 필기 발표 확인 → **실기 즉시 접수** + 실기 교재 시작
- W2~W3: 교재 유형별 학습 (데이터 연결·가공 → 차트 제작 → 대시보드 구성 순)
- W4~W5: **공식 모의문제 + 유튜브 풀이 영상으로 70분 타이머 실전 반복** (최소 5회)
- 시험장 프로그램 버전 확인 후 동일 버전으로 연습
- **시험 전략**: ① 전 문제 먼저 훑고 쉬운 것부터 ② 모든 문제에 풀이 흔적 남기기(부분점수) ③ 수시 저장 습관
