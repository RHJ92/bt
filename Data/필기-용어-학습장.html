☐의사결정 3계층전략적(경영진, 장기·비정형) / 관리적(중간관리자, 자원배분) / 운영적(실무자, 일상·정형). 대시보드 유형도 이에 대응.
☐ERP / SCM / CRMERP=전사 자원(재무·인사·생산) 통합관리 / SCM=공급망(조달~배송) 관리 / CRM=고객관계 관리. 구매 데이터의 원천 시스템이 무엇인지 묻는 유형
☐OLTP vs OLAPOLTP=일상 거래 처리(주문 입력, 실시간, 행 단위) / OLAP=축적 데이터 분석(다차원 집계, 조회 중심)
☐DW데이터 웨어하우스분석 목적으로 여러 원천 데이터를 주제별로 통합·시계열 저장한 데이터베이스. 특징: 주제지향·통합·시계열·비휘발.
☐데이터 마트 / 데이터 레이크마트=DW의 부서·주제별 부분집합(구매팀용 등) / 레이크=정형+비정형을 원본 그대로 담는 대형 저장소
☐ETL추출·변환·적재원천에서 데이터를 추출(Extract)→변환(Transform)→적재(Load)하는 과정. 변환을 적재 후에 하면 ELT.
☐메타데이터"데이터에 대한 데이터". 데이터의 정의·구조·출처·생성일 등 설명 정보. (예: 컬럼 정의서)
☐데이터 거버넌스데이터의 품질·보안·표준·책임을 전사적으로 관리하는 체계와 정책. 원칙·조직·프로세스로 구성.

☐가명처리 vs 익명처리가명=추가 정보와 결합하면 재식별 가능(통계·연구 목적 활용 가능) / 익명=재식별 불가능(개인정보 아님, 자유 활용)
☐데이터 리터러시데이터를 읽고·해석하고·비판적으로 판단하고·활용해 소통하는 능력. 이 자격증이 검증하려는 핵심 역량.

과목 영역 2데이터 해석 및 활용

용어핵심 정의
☐척도 4종 ★명목(구분만: 지역, 품목) → 서열(순위: 만족도 상중하) → 등간(간격 동일, 절대0 없음: 온도) → 비율(절대0 있음: 금액, 수량). 매회 출제 단골
☐모집단 / 표본모집단=관심 대상 전체 / 표본=그중 추출한 일부. 표본으로 모집단을 추정하는 것이 통계의 본질.
☐대표값 3형제 ★평균(이상치에 민감) / 중앙값(크기순 가운데, 이상치에 강함) / 최빈값(가장 잦은 값). "이상치가 있을 때 적절한 대표값은?" → 중앙값
☐분산 / 표준편차데이터가 평균에서 얼마나 흩어져 있는지. 표준편차=√분산 (원자료와 단위 동일해 해석 용이).
☐사분위수 / IQR데이터를 4등분: Q1(25%), Q2(중앙값), Q3(75%). IQR=Q3−Q1. 박스플롯의 뼈대.
☐이상치 판정 ★일반 기준: Q1−1.5×IQR 미만 또는 Q3+1.5×IQR 초과. 무조건 삭제가 아니라 원인 확인 후 처리.
☐결측치 처리비어 있는 값. 처리법: 삭제 / 대체(평균·중앙값·최빈값) / 예측 대체. 처리 전 발생 원인 파악이 먼저.
☐정규분포평균 중심 좌우대칭 종 모양. 평균±1σ≈68%, ±2σ≈95%, ±3σ≈99.7%.
☐왜도 / 첨도왜도=분포의 비대칭 정도(오른쪽 꼬리 길면 양의 왜도, 평균>중앙값) / 첨도=분포의 뾰족한 정도
☐상관계수 ★두 변수의 선형 관계 강도. −1~+1. 0이면 선형관계 없음. 함정: 상관관계 ≠ 인과관계 (아이스크림 판매와 익사사고)
☐조인Join공통 키로 두 테이블을 옆으로(열) 결합. 내부조인=양쪽 모두 존재하는 행만 / 왼쪽 외부조인=왼쪽은 전부 유지.
☐유니온Union구조가 같은 테이블을 아래로(행) 이어 붙임. (예: 1월 발주 + 2월 발주). 조인=옆으로, 유니온=아래로
☐피벗 / 언피벗피벗=긴 데이터를 가로로 요약(행→열) / 언피벗=넓은 데이터를 세로로 풀기(열→행). 시각화 도구는 대체로 세로형(Long) 선호.
☐기본키 / 외래키기본키=행을 유일하게 식별(발주번호) / 외래키=다른 테이블의 기본키를 참조(발주의 거래처코드)
☐파생변수(계산된 필드)기존 변수를 가공해 만든 새 변수. (예: 단가×수량=금액, 금액÷총액=구성비)
☐구성비 / 증감률 / YoY구성비=부분÷전체 / 증감률=(당기−전기)÷전기 / YoY=전년 동기 대비 증감률. 계산 문제로 출제 가능 — 공식 손에 익히기
☐이동평균최근 n개 구간의 평균을 이어 계산 — 단기 변동을 완화해 추세를 드러냄. (예: 단가 3개월 이동평균)
☐시계열 구성요소시간 순서 데이터의 4요소: 추세 · 계절성 · 순환 · 불규칙. (예: 여름철 음료 원재료 수요=계절성)

과목 영역 3경영정보시각화 디자인

용어핵심 정의
☐시각적 인코딩데이터 값을 시각 요소(위치, 길이, 색, 크기, 모양)로 변환하는 것. 정확도 순위: 위치·길이 > 각도·면적 > 색.
☐전주의적 속성 ★의식적 주의 이전에 0.5초 내 지각되는 시각 속성 — 색상, 크기, 방향, 움직임 등. 강조(하이라이트)의 이론적 근거.
☐게슈탈트 원칙 ★인간이 형태를 묶어 보는 원리: 근접성(가까우면 한 덩어리) · 유사성(닮으면 같은 그룹) · 연속성 · 폐쇄성 · 공동운명. 각 원칙과 사례 매칭 문제 단골
☐데이터-잉크 비율전체 잉크 중 데이터를 표현하는 잉크의 비율(Tufte). 높을수록 좋음 → 불필요한 장식(3D, 과한 격자선) 제거.
☐차트정크정보 전달에 기여하지 않는 장식 요소. 데이터-잉크 비율을 낮추는 주범.
☐막대 vs 히스토그램막대=범주 비교(품목별 금액, 막대 사이 간격 O) / 히스토그램=연속형 분포(구간별 빈도, 간격 X)
☐선 차트시간 흐름·추세에 최적. 범주 비교에는 부적합.
☐파이/도넛 차트전체 대비 구성비. 항목 5~6개 이하일 때만. 항목 많거나 값이 비슷하면 막대가 낫다.
☐산점도 / 버블산점도=두 연속 변수의 관계·분포(단가 vs 수량) / 버블=크기로 세 번째 변수 추가
☐박스플롯5수치 요약(최소, Q1, 중앙값, Q3, 최대)으로 분포와 이상치를 한눈에. 그룹 간 분포 비교에 강함.
☐히트맵행×열 매트릭스의 값을 색 농도로 표현. (예: 월×품목 단가 변동)
☐트리맵계층 구조의 구성비를 중첩 사각형 면적으로. (예: 카테고리>품목별 구매액)
☐워터폴 차트시작값에서 증감 요인을 단계별로 보여 최종값 도달 과정 표현. (예: 원가 증감 요인 분해)
☐불릿 차트막대 하나로 실적 vs 목표 vs 달성 구간을 압축 표현. 게이지의 공간 효율형. KPI에 최적.
☐간트 차트작업별 기간을 가로 막대로 — 일정 관리용. (예: 발주~입고 리드타임)
☐색상 팔레트 3유형 ★범주형(구분되는 색: 품목별) / 순차형(밝→진: 금액 크기) / 발산형(양극단 강조, 중간 중립: 증감률 ±). 상황-팔레트 매칭 단골
☐색 접근성색각이상(적록 등) 배려: 색에만 의존하지 않고 모양·라벨·패턴 병행, 충분한 명도 대비.
☐대시보드 시선 흐름사람의 시선은 좌상→우하(Z·F 패턴). 가장 중요한 지표(KPI 요약)는 좌측 상단에.
☐대시보드 3유형전략(경영진, KPI 요약·저빈도) / 분석(원인 탐색·드릴다운) / 운영(실시간 모니터링). 의사결정 3계층과 대응.
☐인터랙션 요소필터(범위 좁히기) / 하이라이트(연관 강조) / 드릴다운(상세 계층 이동: 연→월→일) / 툴팁(마우스오버 상세)
☐왜곡된 시각화 ★대표 유형: 축을 0에서 시작하지 않은 막대(차이 과장), 3D 원근 왜곡, 이중축 남용, 체리피킹 구간. "잘못된 것 고르기" 유형
☐데이터 스토리텔링데이터에 맥락·내러티브를 더해 청중의 이해와 행동을 이끄는 것. 구성: 데이터 + 시각화 + 내러티브.
