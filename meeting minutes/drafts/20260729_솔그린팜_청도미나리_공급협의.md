## ⏱ 3줄 요약 (바쁘면 여기만)

- 청도 미나리를 **본사 직거래로 전환**하고 지역상생 마케팅(MOU·기부)까지 묶는 건 — **9월 1일 도입 목표**, 100개 매장 일괄이 아닌 **직영점부터 순차 반영**.
- 최대 쟁점이던 **결제 주기**는 솔그린팜의 "발주 후 1일 정산" 요구와 자사 5일 단위 결제 구조가 충돌 → **매월 10·20·30일 10일 단위 결제**로 합의.
- **단가는 미결** — 솔그린팜 제시안은 비수기 11,000~12,000원 / 성수기 16,000~17,000원이나, 자사 실무 의견은 **연중 11,000~12,000원 고정가**. 그 외 **세금계산서 10% 추가 발행 요청**은 재무·세무 확인이 선행되어야 함.

## 안건별 상세

### ① 도입 목적 — 지역상생 마케팅 (배경)
- 자사 3개 브랜드가 사용하는 농산물을 국내산으로 명확히 전환하고, **지역 경제 살리기 프로젝트** 형식으로 마케팅에 활용하려는 구상. 청도 미나리와 함께 **당진 쌀 계약**도 병행 검토 중.
- 주문 금액의 일정 부분을 **연말 기부**로 연결하는 설계 예정 → 단가가 올라도 참여 매장을 늘릴 명분 확보.
- 기존에는 본사 수익 목적으로 자체 공급했으나 **본사 접수 클레임이 없었던 품목**이라, 차라리 산지와 직접 연결하는 편이 낫다고 판단해 연락하게 된 경위.

### ② 발주 프로세스·결제 주기 (★ 핵심 쟁점 / 결정)
- **발주 단위**: **6kg 기준**(6/12/18/24kg). 리드타임 **총 2일** — 본사가 **17시까지 발주 집계·전달** → 익일 작업·택배 발송 → 그 다음 날 도착.
- **논의**
  - 솔그린팜 요구: **발주 후 1일 내 전체 대금 정산**. 청도 산지 농가 20곳과 독점적으로 물량을 확보하려면 대금 회전이 빨라야 하며, 긴 정산 주기는 농가가 공판장·도매상 쪽을 택하게 만든다는 논리. 작업 비용의 **80%가 인력비**인 점도 근거.
  - 자사 입장: **선입금·즉시 결제 구조 자체가 없음**. 본사 재무 결재 순환에 최소 3일, 결제일은 **매월 5일 단위** 운영. 축산 일부만 선입금. 이번 달 매입만 총 9억 규모라 특정 품목 하나로 자금 회전을 바꿀 수 없음(계란도 15일 단위 결제).
  - 자사 절충안: 한 달 2회(15일 단위) → 솔그린팜이 "보름은 농가가 못 버틴다"며 거절 → 자사가 **10일 단위(월 3회)**까지 제시.
- **결론**: **매월 10일·20일·30일 결제**로 합의. 성수기/비수기 부담은 솔그린팜이 농가와 조율. 자사는 물류 시스템 정산금을 25일·15일에 받으므로 **사실상 선지급 구조**임을 설명.

### ③ 단가 (미결)
- **솔그린팜 제시**: 비수기 **11,000~12,000원**, 성수기 **16,000~17,000원**. 배송비와 혹한·혹서기 아이스박스·아이스팩 포장까지 포함된 단가. 폭염·폭설기 변동은 있으나 범주는 유지.
- **솔그린팜 근거**: 여름 미나리는 농가가 생산을 기피(고온으로 급성장·물러짐, 복숭아 등으로 전환) → 생산 유인 확보에 일정 단가가 필요. 한겨울 경매장 출하 시 kg당 **22,000~27,000원**이 나오는 상황에서 작년 겨울 옥된장에 **15,000원 일괄 공급**한 실적을 제시.
- **자사 실무 의견**(미나리 운영 3년차): 제시 단가는 **비쌈**. 품질 우선 매장과 가격에 타협하는 매장의 중간 지점으로 **연중 11,000~12,000원 고정가**가 롱런 가능한 수준. 단, 대표·팀장 의견이 아닌 개인 데이터 기반 참고 의견임을 명시.
- **결론**: **미결.** 협의 시점에 자사 실무 의견을 참고 자료로 활용.

### ④ 세금계산서·로열티 (확인 필요)
- **세금계산서**: 매월 말 **가맹 매장별로 발행**. 솔그린팜 요청 — 실제 매입액 대비 **10%를 추가한 금액으로 계산서 발행**(1억 매입 시 1억 1천만원 계산서, 지급은 1억). 솔그린팜 측 사유는 면세 사업자로서 농산물 매입 자료 부족을 보전하려는 것.
- 자사는 회의 중 **입금액과 계산서 금액의 차액이 어떻게 처리되는지** 질의했고, **재무·세무 확인이 필요하다**는 선에서 보류.
- **로열티**: **kg당 200원** 적용 — 전체 발주량 대비 차감 정산 또는 페이백 중 협의. 자사는 자체 기준(20)을 감안해 **별도 재산출 후 회신** 예정.
- **커스텀 박스**: 초기 **동판 제작비는 자사 부담**, 이후 박스 단가는 협의(자사 제작 후 발송도 가능).

### ⑤ 배송·클레임 기준 (확인 완료)
- **배송**: 롯데택배 **신선식품 전용 코드**로 발송, 1일 배송 원칙. 아이스박스 + 아이스팩 3개(제주는 4개, 선박 경유에도 신선도 유지). 천재지변·개인 사정으로 인한 클레임은 원물 상태 확인 후 처리. 송장 번호는 발주 익일 일괄 등록해 본사·매장에 공유.
- **클레임 인정 기준**: kg당 적재 비율 **15% 초과**, 포장 불량, 길이 미달, 중량 미달.
- **반품 불가** — 신선도 저하로 재사용 불가하므로 매장 내 자체 폐기. **17시 이전 접수 시 당일 재발송 → 익일 신규 상품 수령**.
- **로스율 비교**: 타 산지 유통 미나리는 소비자 기준 약 30% 폐기. 솔그린팜 소분 입고 기준 로스율 5% → 12kg 사용 시 월 약 20만원 절감, 30개 매장 7천만원 / 50개 매장 1억원 수준 절감 효과 자료 제시.

### ⑥ 도입 일정·계약 특이사항 (결정)
- **9월 1일부로 실행 확정** — 기존 사용분과 병행이라도 도입. 100개 매장 일괄 반영은 어려우므로 **직영점부터 순차 반영**.
- 여름철 최대 출고 500kg 기준으로 **100개 매장 1일 출고량 충당 가능**(옥된장은 여름 매출이 절반 수준으로 감소).
- **계약 특이사항**: 옥된장·석문어 **가맹점 개별 주문 불가**(본사 일괄 컨트롤), 위반 시 **위약금 약 200만원**을 형식상 명시.
- **변수**: 봄·가을 노지 미나리가 4kg 8,000~9,000원까지 떨어지는 시기(연 2~3주)에는 점주 혼용 가능성이 있어 출고량이 일시 감소할 수 있음.
- **발주 코드**: 자사 발주 시스템에 청도 미나리 코드 생성 예정. 매입사를 **블루트렌드로 할지 솔그린팜으로 할지 미결** — 솔그린팜 앞으로 코드를 따면 솔그린팜이 직접 주문 내역을 확인하는 방식. 솔그린팜은 어느 쪽이든 가능.

### ⑦ MOU·현장 촬영 (계획)
- **8월 10일 이후** MOU 일정 조율(자사 담당자가 10일까지 이동 불가). 청도 현장 방문·촬영에 **브랜드 이사** 동행, **솔그린팜·청도 미나리 명칭 사용** 전제.
- 초청 대상 — **군수는 불가**, 대신 **비서실장·군의원·농업기술센터 친환경 담당 과장** 참석 조율 가능. 솔그린팜도 관과 사전 절충 필요.
- 계약 후 **옥된장 유튜브 출연**도 논의(솔그린팜 측 수용).
- 청도군 **지자체 지원 사업** 유무를 솔그린팜이 확인해 함께 활용하는 방안 제안.

### ⑧ 추가 소싱 제안 (신규)
- **우렁이**: 솔그린팜 대표가 미나리 이전에 청도 친환경 우렁이 농법을 정착시킨 이력. 옥된장이 국내산 우렁이를 사용 중이라 현장 방문 시 소개 예정.
- **아이스홍시(미니감)**: 대형 식당 디저트용으로 납품 중 → 자사 본사 **샘플 수령**, 오산 센터 배송 요청.
- **동결건조 미나리**: 솔그린팜이 동결건조 설비 보유. 자사는 1년 반 전 시장에서 동결건조 미나리를 찾았으나 수요 부족으로 구할 수 없었던 경험 — **컵라면형 옥된장 제품의 플레이크 소재**로 활용 가능성. 샘플 요청.
- **스마트팜 미나리**: 자사가 과거 kg당 7,000원에 잠시 운영했으나 **일조 부족으로 맛이 떨어져** 중단. 양측 모두 배제 의견.
