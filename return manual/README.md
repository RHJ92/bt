# 옥된장에프앤비 반품 매뉴얼 — 류호정 담당분

원본 스프레드시트: https://docs.google.com/spreadsheets/d/1jsiFwK_HdXx35xtVcwiUS7V0PZbg0hw4Vb-skwyu2y0/edit
(구매팀장님 예시 시트: 우삼겹슬라이스 — gid=114883913)

시트에 직접 쓰는 도구가 없어서, 이 폴더에 시트 탭과 동일한 구조로 초안을 작성한 뒤 사용자가 구글시트에 복사해 넣는 방식으로 진행합니다. 각 파일이 시트의 새 탭 1개에 대응합니다.

**공급처 정보 외에는 전부 가맹점주에게 공유되는 내용**이므로, 공급처 칸은 회사명 확정 전까지 `(추정)` 또는 `[확인 필요]`로 표기합니다.

## 구글시트 반영 방법 (apps_script/담당품목_탭생성.gs)

드라이브 직접 쓰기 도구가 세션에서 끊겨 있어, 구글시트 안에서 실행하는 Apps Script로 반영한다. 우삼겹슬라이스 탭(팀장 예시=서식 기준)을 품목 수만큼 복제하고 텍스트만 각 품목 최종본으로 교체 → 원본 셀 병합·색·테두리·열너비가 그대로 유지된다.

1. 대상 구글시트 → **확장 프로그램 > Apps Script**
2. `apps_script/담당품목_탭생성.gs` 전체 붙여넣고 저장
3. 함수 `담당품목_탭생성` 선택 후 실행 (최초 1회 권한 승인)
4. ⚠ **반드시 사본(파일 > 사본 만들기)에서 먼저 실행**해 확인 후 원본 반영
5. 스크립트는 5열(A~E) 구조 기준. 원본 우삼겹 탭 열 구조가 다르면 조정 필요
6. 데이터 출처: `output/..._v4_사용자수정.xlsx` (우삼겹 제외 11개 품목 임베드)

## 담당 품목 진행 현황 (담당자 류호정, 총 12개 — 참기름·부각 분리로 11→12)

초안 v4 정비 (2026-07-14, 사용자 엑셀 검토 반영):
- **포장 기준 정리**: 담당 축산품 중 진공 포장은 아롱사태만 → 아롱사태는 "입고 시 진공 풀림 = 상당 시간 공기 접촉"으로 반품 대상. 나머지는 비닐 포장이라 "겉박스 파손 단독은 반품 불가(매장도 배송 리스크 일부 감수), 속비닐 훼손으로 품질 저하 시 반품"으로 통일
- **사실 검증**(웹 서치): 우삼겹 지방 갈변=산화(+겹침 부위 어두움은 펼치면 회복), 계란 난각 맨 앞 4자리=산란일(월·일), 쌀벌레 화랑곡나방 7~8월·도정 후 발생, 소 등급 도장=식용색소 무해, 참기름 냉장 시 굳음은 상온서 회복 → 근거로 보강
- **참기름·부각 분리**: 서로 다른 상품이라 탭 2개로 분리
- 사용자 삭제·수정 반영(아롱사태 손질 불량 사유 삭제, 목전지 뼛조각 사유 추가 등), 뼈갈비 "재냉동 시 뼈-살 분리"→근거 약해 "육질 저하·부서짐"으로 수정

## 확인 필요 항목 (사용자)

- **공급처 회사명 확정**: 코드 접미(S=선우프레시, C=캐틀팜, M=미트이노베이션 등 우삼겹 예시 패턴)와 히스토리로 추정 기입 — 틀린 것 교정 필요. 목전지(SM)·소꼬리 Y코드·냉동혼합야채·수제비(동성식품?)는 미확인
- **규격 확인**: 수제비·냉동혼합야채 내포장 규격, 쌀 포대 중량, 계란 묶음 판수(5판?), 참기름 병·부각 봉 규격
- **비축산 제때코드**: 실운영 단가 시트(축산만 있음)에 없어 미기입
- **검토 요청**: 목전지가 발골(뼈 제거) 상품이 맞는지 — 사용자가 뼛조각 사유를 추가하셨는데, 히스토리상 "목전지 찌개용 뼈 뺀 부위" 언급으로 반영함. 제육용도 해당되는지 확인 필요
