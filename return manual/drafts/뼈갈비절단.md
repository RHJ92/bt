# 뼈갈비 절단 (BBQ 백립)

보관조건 : 냉동 (-18℃ 이하)　　단위 : BOX (10kg/BOX)

■ 공급처
　선우프레시 (추정) — CC311991 뼈갈비절단S
　캐틀팜 (추정) — CC311992 뼈갈비절단C
　※ 가공: 신우미트 / 원산지: 미국산 — 수급 상황에 따라 변동
　※ 회사명은 코드 접미·히스토리 기반 추정 — 확정 전 확인 필요

■ 1. 주요 반품 사유

① 해동 흔적: 배송 중 온도 관리 실패로 고기가 녹아 핏물이 흘러나왔거나, 다시 얼면서 박스 안에 얼음덩어리가 크게 뭉쳐 있는 경우

② 무게 부족: 박스 표기(10kg)보다 실제 무게가 허용 오차를 넘게 부족한 경우

③ 뼛조각 다량 발생: 절단 과정에서 부서진 뼛조각이 광범위하게 다량 섞여 있어 안전이 우려되는 경우 (미세한 뼛조각 일부는 절단 상품 특성상 발생할 수 있음 — 유의사항 참조)

④ 절단 불량: 갈비대 개수·두께 편차가 커서 정해진 규격에 크게 못 미치는 경우

⑤ 포장 파손·진공 풀림: 입고 시점에 박스가 파손되었거나 진공 포장이 풀려 고기가 공기에 닿아 있는 경우

⑥ 변색·냄새 (수령 당일 확인분): 수령 당일 검게 변했거나 이상한 냄새가 확인된 경우

⑦ 도장 색소 묻어남: 원물 표면의 등급 도장(식용 잉크) 색이 막에 배어 조리 시 묻어나는 경우 — 사진 확인 후 처리

⑧ 다른 상품 입고: 주문한 상품·규격과 다른 제품이 입고되었거나, 다른 매장 물량과 뒤바뀐 경우

■ 3. 수령 검수 체크리스트

| No | 검수 항목 | 확인 방법 | 판정 기준 (정상) | 이상 시 조치 |
|---|---|---|---|---|
| 1 | 주문 일치 | 발주 코드·규격과 실물 라벨 대조 (다른 매장 물량 여부 포함) | 주문한 상품과 정확히 일치 | 즉시 보고 후 반품/교환 |
| 2 | 뼛조각 | 절단면·포장 안쪽의 부서진 뼛조각 확인 | 미세 조각 일부 이내 (다량 아님) | 다량 발생 시 사진 보고 후 반품 |
| 3 | 무게 | 박스 표기(10kg) 대비 실제 무게 확인 | 허용 오차 이내 | 저울 사진 보고 후 차액 정산 또는 반품 |
| 4 | 냉동 상태 | 핏물 흘러나옴·박스 안 얼음뭉침 확인 | 완전히 얼어 있고 핏물·얼음뭉침 없음 | 당일 사진 보고 후 반품 |
| 5 | 절단 상태 | 갈비대 개수·두께 편차 확인 | 규격 범위 내 고른 절단 | 사진 보고 후 반품 협의 |
| 6 | 색·냄새 (당일 필수) | 표면 색·냄새·도장 색 배임 확인 | 정상 색, 이상한 냄새 없음 | 당일 사진 보고 후 반품/확인 처리 |

■ 4. 유의사항

⚠ 미세한 뼛조각은 일부 발생할 수 있습니다: 뼈째 절단하는 상품 특성상 톱 절단 과정의 미세한 뼛가루·조각은 수입 검역 기준에서도 정상 범위로 봅니다. 조리 전 절단면을 물로 헹구고 눈에 띄는 조각을 제거해 주세요. 다만 손님 안전에 우려가 될 만큼 큰 조각이 많이 나오는 경우는 다른 문제이므로, 조리·판매를 멈추고 사진과 함께 바로 보고해 주세요 — 확인 후 반품 처리됩니다.

⚠ 등급 도장(식용 잉크)은 인체에 무해합니다: 간혹 도장 색이 막에 배어 조리 시 묻어나는 경우가 있는데, 상품성에 영향이 있는 수준이면 사진과 함께 보고해 주세요.

⚠ 변색·냄새는 수령 당일 보고분만 반품 가능합니다. 뼈 있는 부위는 재냉동 시 뼈와 살이 분리되고 육질이 나빠지므로 당일 사용분만 냉장고에서 해동하고, 보관 중 진공이 풀린 팩은 가장 먼저 사용해 주세요.
