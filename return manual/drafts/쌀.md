# 쌀 (혼합미)

보관조건 : 상온 (서늘하고 건조한 곳, 직사광선 차단)　　단위 : 포대 — [포대당 중량 확인 필요]

■ 공급처
　경기서부미곡처리장 — [제때코드 확인 필요]
　※ 혼합미(수향미 혼합 — 혼합 비율은 시황에 따라 조정될 수 있음)

■ 1. 주요 반품 사유

① 벌레·곰팡이 (입고 직후 확인분): 입고 직후 확인 시 쌀벌레(나방 유충 등)나 곰팡이가 발견된 경우

② 변색·도정 불량: 노랗게 변한 쌀알이 많거나, 밥이 심하게 떡지는 등 밥 품질에 문제가 있는 경우

③ 이물 혼입: 돌·시멘트 조각 같은 딱딱한 이물 등이 발견된 경우 — 발견 시 포대째 보관 필수

④ 싸라기 과다: 부서진 쌀알이 정상 범위를 넘게 많이 섞여 밥 품질이 떨어지는 경우

⑤ 포대 훼손: 포대가 찢어지거나 젖어 내용물이 오염된 경우

⑥ 다른 상품 입고: 주문한 상품과 다른 제품이 입고된 경우

■ 4. 유의사항

⚠ 입고 직후 확인이 가장 중요합니다: 쌀벌레와 곰팡이는 매장의 보관 온도·습도 영향도 크기 때문에, 입고 후 시간이 많이 지나 발견된 경우에는 원인 구분이 어려워 반품 처리가 어려울 수 있습니다. 입고 당일 도정일과 상태를 확인하는 습관을 부탁드립니다.

⚠ 서늘하고 건조한 곳에 보관해 주세요: 쌀벌레(화랑곡나방)는 25~30℃, 습도 70% 이상에서 왕성하게 번식하며 특히 7~8월에 많이 생깁니다. 도정 후 3주가 넘으면 알이 부화할 수 있어 본사 물류센터도 도정 3주 이내로 재고를 돌립니다. 매장에서도 소진 가능한 수량만 주문하시고, 과발주로 오래 보관된 재고는 반품이 어렵습니다.

⚠ 하절기(여름철)에는 특히 서늘한 곳에 보관해 주세요: 기온·습도가 높아지면 쌀벌레와 곰팡이가 훨씬 빨리 생깁니다. 여름철에는 직사광선과 열기를 피해 가장 서늘한 곳에 두시고, 재고를 오래 쌓아두지 않도록 주의해 주세요.

⚠ 벌레·이물 발견 시 버리거나 옮겨 담지 말고 포대째 보관해 주세요. 공급사 확인과 반품 처리에 실물이 필요합니다.
