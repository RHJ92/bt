|---|---|
| `00_전략기획/` | 채널 컨셉, 벤치마킹, 타겟 분석 등 채널 방향성 문서 |

## 원칙

1. **장비 사기 전에 폰으로 10편 먼저.** 초기 투자 최소화.
2. **얼굴 노출 없음.** 손, 뒷모습, 음식 중심 앵글.
3. **완벽보다 발행.** 편집 퀄리티 고민으로 업로드가 늦어지면 그게 실패.
4. **본업(구매 10년차)이 최대 무기.** 남들이 못 하는 이야기를 한다.
