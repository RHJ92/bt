## 유형별 포인트

**① 공급가 조정 안내**
- 표 6열: `상품명 / 과세여부 / 단위 / 기존 단가 / 변경 단가 / 증감율`
- **단가는 판매가(=가맹점 공급가) 기준.** 매입가(jt 매입가)가 아니라 매장이 실제 내는 판매가를 넣는다.
- 증감율은 부호와 방향 표시 — **인상 = 빨강(red), 인하 = 파랑(blue)**. 예: `+2.07% (인상)`, `-2.53% (인하)`
- 인상·인하가 섞이면 목적을 "시세 변동에 따른 조정(인상·인하)"으로 중립 표현.
- **상품명은 매장용 대표명으로 간소화** — 내부코드(ODJ/SM)·규격(10kg)·원산지·변종기호 떼고 대표명만. 예: `뻐갈비절단S(ODJ/10kg)_BOX_(우육:미국산)` → **`뻐갈비절단`**.
- **가격 같은 변종은 한 줄로 합침** — S·C, H·S 등 단가가 동일하면 한 행으로 (예: 7품목 → 4행). 단가가 다르면 행 분리 유지.
- **금액이 들어가는 표는 라벨 옆에 부가세 기준을 괄호로 붙인다** (2026-08-21 확정)
  ```
  - 상품 안내 <span color="gray">(과세 품목 부가세 별도)</span>
  ```
  - **표 아래 `※` 줄이 아니라 표 위 라벨 옆**이다. 표기 기준은 숫자를 읽기 *전에* 알아야 쓸모가 있고, 표가 둘 이상인 안내문에서 어느 표에 걸리는 기준인지도 분명해진다.
  - 이 표기는 **고정**이다. 표에 면세 품목만 있어도 빼지 않는다 — 과세·면세 구분은 **표의 `과세여부` 열이 품목별로 담당**하고, 이 괄호는 "표에 적힌 숫자는 부가세를 포함하지 않은 값"이라는 단가 기준 표기다. 둘은 서로 다른 정보라 충돌이 아니다.
  - 문구는 **`(과세 품목 부가세 별도)`로 확정** (2026-08-21). 조사를 뺀 압축형이라 라벨 옆 괄호에 얹기 가볍다. `(공급가 부가세 별도)` → `(표기 단가는 부가세 미포함)`을 거쳐 이 형태로 정착했으니 **다시 뒤집지 말 것.**
  - `※` 줄과 역할이 갈린다 — **`※`는 점주가 할 행동**(사전 발주, 몰에서 확인), **라벨 괄호는 표 읽는 기준**.

**② 배송 휴무(가락시장 하계휴무 등) 안내**
- 내용 3단: **① 일반 농산품(휴무·재개 일정) → ② 배송일정표 → ③ 주문 불가리스트**
- 배송일정표: 첨부 이미지를 노션 표로 재현 (날짜(요일) 헤더 / ●·X / 제주도 행 `yellow_bg` / X·특이사항 red). 노션 표는 셀 병합 불가 → 세로 병합 항목은 첫 열에 풀어서 표기, 필요 시 UI에서 병합.
- **D-2 선마감 발주**처럼 놓치기 쉬운 핵심 액션은 노란 콜아웃으로 강조.

**③ 주문처 전환(발주처 통합) 안내**
- 내용 3단: **① 전환 일정표 → ② 통합 대상 품목 리스트 → ③ 주문 방법**
- 전환 일정표 2열(`일자 / 내용`). 마지막 주문일·입고 불가 기간은 red + 볼드.
- **입고 불가 기간에 걸리는 마지막 주문**은 노란 콜아웃으로 강조 — "마지막 주문 시 해당 기간 사용분까지 함께 확보".
- 품목 리스트 4열(`No / 상품명 / 규격·용량 / 박스 입수`). **No는 엑셀 상품번호가 아니라 1부터 매기는 일련번호** — 점주가 가짓수를 바로 확인하는 용도라 마지막 숫자가 곧 품목 수가 되게 한다.
- **가격 열은 넣지 않는다** — 전환 안내는 주문 경로 공지지 단가 공지가 아니다. 대신 표 아래에 `※ 품목별 가맹점 공급가는 (주문처)에서 확인해 주시기 바랍니다.` 한 줄을 넣는다 (2026-08-10 확정).
- 상품명은 `[브랜드]` 접두·내부 표기를 떼고 대표명만. 전용 품목만 브랜드명을 앞에 붙여 구분(예: `옥된장 전용 냅킨`).
- 견적서의 `_택배` 표기는 **떼고 쓴다** — 포장보스 통합 품목은 전 품목 택배 운영이라 품목별로 구분할 이유가 없다 (2026-08-10 확인).

## 노션 마크다운 주의

- 상품명 속 `*`(예: `5kg*2pk`)는 `\*`로 이스케이프. 언더스코어 `_`는 그대로 둬도 됨.
- 표는 rich text만 — 셀 안에서 볼드는 `**…**`, 색은 `<span color="red">…</span>`.
- 연회색 **글자색**은 `<span color="gray">…</span>` — 계획 헤더의 회색 **배경** `{color="gray_bg"}`와는 다른 속성이다.
- `update_content`로 **같은 줄에 걸치는 편집 두 건을 한 번에** 보내면 뒤 편집이 앞 편집 결과를 못 찾아 내용이 날아갈 수 있다. 한 건씩 나눠 보내고 결과를 확인할 것.
- 빈 줄은 `<empty-block/>`.
- create-pages 호출 시 `__unparsedToolInput` 래핑 쓰지 말 것(파싱 에러) — 파라미터에 한국어/유니코드 직접 기입.
